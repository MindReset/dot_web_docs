Read Pico is an e-paper development board. You can start using the device with a compatible third-party system. Explore third-party systems for Read Pico below. Check each system’s page for installation availability and usage instructions.

<Callout type="info" title="Before installing">

For a first installation or a switch to another system, use that project's full installation method for Read Pico. Application images, card-based updates, and OTA generally require a compatible system and partition layout already installed. They do not replace a full installation. Do not mix files from different systems or versions.

Save important books, notes, reading records, and settings first, and follow each project's requirements for a full Flash backup. Flashing may recreate internal storage. Before updating, read the target version's release notes to check whether language packs, fonts, or other resources also need updating.

</Callout>
