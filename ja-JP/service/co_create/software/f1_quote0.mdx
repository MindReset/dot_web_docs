F1 Quote/0 は、Mac 上だけで動作する Formula 1 ダッシュボード送信アプリです。ESPN の公開データを主な情報源とし、Jolpica F1 と OpenF1 を組み合わせて、カレンダー、セッション結果、ライブ順位、ドライバーランキング、コンストラクターランキングを取得し、Dot Canvas API から Quote/0 に表示します。

<CustomCloudImage osSrc="dot/docs/632470386-703f295d-04de-4dcb-a57f-69db68cac2c1_1786094292395.png" alt="次戦カウントダウン、デバイスプレビュー、自動ローテーション設定を表示する F1 Quote/0 macOS コンソール" />

### 主な機能

- **レース結果とライブ順位**：全レース、スプリント、決勝結果を表示し、開催中のセッションはライブ上位 3 台と現在の周回数を優先表示
- **カレンダーと次戦カウントダウン**：次の 2 セッションのグランプリ、サーキット、開始時刻と、オフラインのコース輪郭を使った次戦決勝までの日数を表示
- **注目ドライバー**：シーズンポイント、直近の全セッション、決勝とスプリントの順位を確認
- **注目コンストラクター**：チームポイント、両ドライバーの年間順位、最近の成績を表示
- **ダッシュボード自動切り替え**：表示するパネルと送信間隔を選択し、セッション開催中は 15 秒ごとにライブ順位を確認
- **電子ペーパー向けレイアウト**：Quote/0 の実際の横幅に合わせてドライバー結果、ランキング、2 ドライバー表示を拡大し、サーキット素材もアプリに同梱

### セットアップ

macOS で同梱の `Build/F1 Quote 0.app` を開き、設定画面に Dot API Key と Quote/0 のデバイス ID を入力します。続いて、注目するドライバーとコンストラクター、送信間隔、自動切り替えに含めるダッシュボードを選択してください。利用前に Dot App コンテンツ工房で Canvas API コンテンツをデバイス Loop に追加する必要があります。

API Key、デバイス ID、ユーザー設定は現在の Mac のアプリ環境設定にのみ保存され、リポジトリには書き込まれません。自動送信の最短間隔は 60 秒です。アプリの終了、Mac の電源オフ、ディープスリープ中は更新が止まりますが、Quote/0 には最後に送信できた画面が残ります。

ソースからのビルドには macOS 14 以降と Xcode が必要です。`./scripts/package_app.sh` を実行するとアプリをパッケージできます。
