Quote/0 Baby Dashboard は、オープンソースでローカルファーストな育児記録ツールです。コミュニティ製ファームウェアによって Quote/0 を常時表示の電子ペーパーダッシュボードへ変更し、同じ LAN に接続したスマートフォンやパソコンから授乳、睡眠、おむつを記録できます。デバイスには生後日数、最新状態、次回授乳、予防接種リマインダーが表示され、MindReset の公式クラウドサービスには依存しません。

### 主な機能

- **LAN 内のクイック記録**：スマートフォンやパソコンから授乳量、睡眠の開始と終了、尿・便・両方のおむつ状態を記録
- **状態と傾向**：現在の育児状態、最近の履歴、今日、2 日、4 日、6 日、1 か月の授乳・育児傾向を確認
- **リマインダーと生後日数**：授乳後に次回時刻を自動計算し、ローカル日付で生後日数を更新。指定日時の予防接種リマインダーにも対応
- **複数人の同期と取り消し**：ページ表示中は 4 秒ごとにほかの養育者による新しい記録を確認し、直近の誤入力を取り消し可能
- **ローカルバックアップ**：完全検証付きの JSON バックアップを出力・復元。デバイスは最新 32 件を保存し、Hermes Bridge は成功した操作をローカル SQLite にも記録可能
- **Hermes Studio ツール**：MCP Bridge を通じて自然言語で育児イベントを記録し、今日の集計、授乳間隔、リマインダーを操作
- **Wi-Fi 設定と無線更新**：2.4 GHz Wi-Fi の設定、自動復旧アクセスポイント、ブラウザからの OTA ファームウェア更新に対応

### インストール要件

このプロジェクトは ESP32 の書き込み経験があるテスター向けです。ESP32-C3、4 MB Flash、152 × 296 モノクロ電子ペーパー、UC8251D コントローラーを対象としています。初回インストールにはデータ転送対応 USB ケーブルと、ESP-IDF 6.x、Python 3、Git を設定した macOS または Linux が必要です。

Git サブモジュールを含めてリポジトリをクローンし、`idf.py build` でビルドした後、工場出荷状態のデバイスへの初回導入は `idf.py flash` で完全に書き込みます。導入後は `Quote0-Baby-XXXX` 復旧アクセスポイントから家庭の 2.4 GHz Wi-Fi を設定できます。LAN へ接続したら、デバイス IP または `http://quote0-baby.local/` からダッシュボードを開けます。

<Callout type="warn" title="公開 Beta と初回書き込み">
  これはコミュニティが開発する独立した公開 Beta ファームウェアであり、MindReset の公式製品ではありません。GitHub Release の
  `quote0_baby.bin` は本プロジェクト導入後の OTA 更新専用です。工場出荷状態のデバイスへの初回導入には完全な USB
  書き込みが必要です。作業前に工場出荷時のファームウェアを自分でバックアップしてください。リポジトリは工場出荷時のイメージを配布せず、公式クラウドサービスへ復元できることも保証しません。現在の検証は主に 1 台の Quote/0
  で行われており、すべてのハードウェア世代、ルーター、長期運用環境を網羅していません。
</Callout>

<Callout type="warn" title="プライバシー、ネットワーク、利用範囲">
  復旧アクセスポイントは公開された既定パスワードを使用し、LAN トークンはデバイス MAC から生成されます。信頼できる家庭内ネットワークだけで利用し、公開インターネット、ゲストネットワーク、ポート転送へ公開しないでください。トークンや赤ちゃんの記録も公開しないでください。ホスト名の競合を避けるため、同じ LAN
  では 1 台の利用を推奨します。デバイスが保持する履歴は最新 32 件のみなので、定期的にバックアップしてください。このダッシュボードは日常記録を補助するものであり、小児医療、専門的な授乳指導、緊急医療の代わりにはなりません。
</Callout>
