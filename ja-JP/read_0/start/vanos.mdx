Read Pico 向けにシステムを提供してくださった [VanOS 開発者](https://vanos.pages.dev/) に感謝します。

VanOS は Read Pico 向けの読書システムです。本棚から読書を再開し、タップやスワイプでページ送りやメニュー操作を行い、好みに合わせて読書画面を調整できます。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使うパソコン、データ通信対応の USB-C ケーブルを用意してください。端末のシリアルポートを使用している他のページ、書き込みツール、ターミナルは閉じてください。

書籍、フォント、画像を保存する microSD カードを用意してください。Read Pico は最大 512 GB に対応し、FAT32 形式が必要です。

公式サイトの書き込みはフル書き込みです。現在のシステムが置き換わり、端末内部の設定がリセットされます。microSD カード上の書庫には影響しません。残したい設定や大切なデータを先に保存してください。

## 公式サイトからインストールする

<Steps>
<Step>

### 公式サイトを開く

パソコンの Chrome または Edge で [VanOS 公式サイト](https://vanos.pages.dev/)を開き、「USB 刷入」（USB 書き込み）を探します。現在のバージョンと変更内容は「更新日志」（更新履歴）で確認できます。

</Step>
<Step>

### 端末を接続してインストールする

USB データケーブルで Read Pico を接続し、「USB 刷入」を押して、ブラウザーのダイアログで端末のシリアルポートを選びます。ポートを選ぶと書き込みが始まります。

完了まで USB 接続とページを保ち、パソコンをスリープさせないでください。公式サイトの案内では、書き込み完了後に端末が自動リセットされます。

</Step>
<Step>

### 書籍とフォントを用意する

microSD カードを端末に挿入し、端末のファイル転送画面に従って書籍やフォントを取り込んでから、本棚で本を開きます。

内蔵フォントはよく使う文字のみを収録しています。文字が表示されない場合は、[VanOS 公式サイト](https://vanos.pages.dev/)から朱雀仿宋フォントをダウンロードしてください。カード内に `VanOS/fonts` フォルダーを作り、`VanOS/fonts/朱雀仿宋.ttf` として保存します。このファイル名なら起動時に適用されます。名前を変更した場合は「阅读设置 → 字体」（読書設定 → フォント）で手動選択してください。

</Step>
</Steps>

## 主な機能

### 本棚とタッチ操作

ホーム画面に読書中の本と表紙が表示されます。本棚には縦書きの背表紙が並び、左右のスワイプで本を切り替えられます。

読書中は右側のタップで次のページ、左側のタップで前のページに移動します。画面下部から上にスワイプすると読書メニュー、上部から下にスワイプすると目次が開きます。本文を長押しすると 1 行を選択して署名や抜粋の操作ができます。しおりを保存して後から読み返すこともできます。

### フォントと組版

読書メニューは文字、版面、改行、外観、表示のグループに分かれています。フォント、文字の太さ、余白、行間、字間、段落間隔、字下げを調整できます。読書履歴では読書時間と進捗を確認できます。

  <figcaption>読書メニューと組版設定</figcaption>

### 読書背景とシステム設定

読書背景は本ごとに保存できます。PNG または JPG 画像をカード内の `VanOS/BACKGROUND/` に入れ、「阅读菜单 → 显示 → 阅读背景」（読書メニュー → 表示 → 読書背景）で選びます。電源オフ時の壁紙は端末のファイル管理から設定します。

設定画面では、システムフォント、画像のコントラスト、自動スリープ、持ち上げによる復帰を調整し、カードの状態とシステム情報を確認できます。Wi-Fi ファイル転送やネットワーク時刻同期にも対応します。中央のタッチキーを長押しすると、画面全体をリフレッシュして残像を消せます。
