title: How to Change Networks
---

## When the device is online

When the device is online, you can add a new Wi-Fi network directly in the Dot. App.

<Steps>
<Step>

### Select the device and open Device Info

Select the device in the Dot. App and open Device Info.

</Step>

<Step>

### Tap Wireless Network

Tap Wireless Network.

</Step>

<Step>

### Add Wi-Fi to the list

Add your Wi-Fi network to the Wi-Fi list.

</Step>
</Steps>

After you add it, the device saves the new network configuration and can use an available network when it connects.

## When the device is offline

If the device cannot connect to its current network, use the web tool to reset its network configuration, then set it up again in the Dot. App.

### Connect the Device to the Web Tool

<include>../firmware/device_tool_connect.mdx</include>

### Reset the Network and Pair Again

Tap "Reset Network" below. After the device screen changes, use the Dot. App to pair the device with a network again.

<Callout type="info">
	If the screen does not change, try disconnecting, refreshing the page, and reconnecting before attempting the operation again.
</Callout>
