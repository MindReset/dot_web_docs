Dot AI Quota 是一个自托管的 Claude 与 Codex 订阅额度看板。它复用官方客户端的已有登录态，在本地网页显示额度使用比例和重置时间，并更新明确配置的 Quote/0 Canvas 内容槽位。无需安装 Vibe Usage，无需额外的托管账号，也没有 npm 运行依赖。

仓库提供[中英文安装说明](https://github.com/YuHoYe/dot-ai-quota)和[实际运行的软件截图](https://img.yeyuhao.uk/dot-ai-quota/v0.2/quote0-zh-CN.png)。截图使用已标注的演示数据，设备区域为浏览器近似预览，不是实体设备照片。

### 功能特性

- **订阅额度**：显示服务商返回的 5 小时与每周窗口、Claude 专项额度、Codex 套餐和重置额度券
- **中英文本地看板**：展示剩余比例、重置时间、数据获取时间及墨水屏预览
- **明确的数据新鲜度**：按账号隔离本地缓存，区分缓存与过期数据；缺失值显示未知，不推断为不限
- **Canvas 推送**：将简洁黑白卡片发送到一个或多个明确配置的设备／内容槽位
- **向导与定时运行**：中文配置向导，密钥输入不回显；支持 macOS launchd、Linux systemd 用户定时器和 Windows 任务计划程序，默认保持设备正常轮播
- **免账号演示**：运行 `npm run demo` 即可体验，不读取凭据、不查询服务商、不向 Dot 推送

### 使用要求

- Node.js 24.6 或更新版本
- Claude Code 和／或 Codex 的受支持订阅登录态；Codex 使用文件式 `auth.json`
- 推送设备时需要 Dot API Key 与 Quote/0 设备序列号
- 在 Dot App 内容工坊中为设备轮播添加 Canvas API 内容，并取得准确的 `taskKey`

运行 `npm install -g https://github.com/YuHoYe/dot-ai-quota/archive/refs/heads/main.tar.gz` 安装，再运行 `dot-ai-quota setup`。中文向导会检测账号登录、隐藏输入 Dot 密钥、列出设备与画板、保存配置、核验首次推送，并询问是否开启定时更新。无需手写配置文件或启动网页；网页仅作为 `dot-ai-quota serve` 可选功能。默认中文 README 还提供了可直接复制给 AI 的配置提示词。
