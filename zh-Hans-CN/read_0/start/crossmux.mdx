## 开始之前

准备一台电脑、桌面版 Chrome 或 Edge 浏览器，以及一根支持数据传输的 USB-C 数据线。

刷写会替换设备当前的系统，原有设置可能被清除。首次从官方演示系统安装 CrossMux 时无需备份原系统，请保持设备电量充足。

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux 官网" />

<Steps>
<Step>

### 打开刷写页面

在电脑的 Chrome 或 Edge 中打开 [CrossMux 官网](https://crossmux.com/)，找到设备选择区域。

</Step>
<Step>

### 选择你的设备

选择 **MindReset Read Pico**，这是小纸 Pico 在烧录器中的设备名称。

<CustomCloudImage osSrc="dot/docs/corssmux_2_1790790168698.png" alt="选择小纸 Pico" />

</Step>
<Step>

### 选择系统并连接设备

选择 **Nightly** 内测版系统，具体版本号以页面显示为准。

在烧录区域勾选「我确认当前连接的是 MindReset Read Pico」。浏览器会将设备识别为 ESP32-S3，无法自动区分其他使用同一芯片的机型，请确认连接的确实是小纸 Pico。

**首次从官方演示系统安装 CrossMux 时无需备份**，不必勾选备份选项，可以直接安装。你随时可以通过下方的恢复入口刷回官方演示系统。

<CustomCloudImage osSrc="dot/docs/crossmux_3_1790790168698.png" alt="选择 Nightly 系统并确认设备与备份选项" />

用 USB 数据线把小纸 Pico 连接到电脑。

如果不确定哪个是小纸 Pico，可先取消窗口，拔下设备，再重新连接，查看新增的设备。

</Step>
<Step>

### 开始安装

确认设备、系统版本和备份选项后，点击「在线烧录」，在浏览器弹出的窗口中选择设备串口。

页面下方会显示进度，依次下载并校验系统、连接设备、检查分区布局、安装系统、验证安装结果并重置设备。等待「烧录完成」提示，期间不要拔掉数据线、关闭网页，或让电脑进入睡眠。

<CustomCloudImage osSrc="dot/docs/crossmux_4_1790790168697.png" alt="烧录完成与重启提示" />

</Step>
<Step>

### 开始使用

烧录完成后设备会自动重置。如果没有启动，请重新插拔 USB，再使用设备电源键开机。

</Step>
</Steps>
