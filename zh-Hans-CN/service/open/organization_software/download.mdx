先[查询 Desk Clock 的公测版](/docs/service/open/organization_software/version_query)。有 OTA 文件时，从响应中读取 `ota.downloadUrl`、`ota.size` 和 `ota.sha256`。直接对 `ota.downloadUrl` 发送 `GET` 并跟随 HTTP `302`。使用 cURL 时可加上 `--location`。

## 响应示例

下载入口返回 HTTP `302 Found`。`Location` 指向 `cdn.mindreset.tech` 上有效期最长 3 分钟的签名地址。跟随跳转后，HTTP `200 OK` 的响应体是 OTA 文件的二进制内容。

```http
HTTP/1.1 302 Found
Location: https://cdn.mindreset.tech/path/to/ota?sign=example
Cache-Control: private, no-store

HTTP/1.1 200 OK
Content-Type: application/octet-stream
Content-Length: 1176976
Content-Disposition: attachment; filename*=UTF-8''desk-clock-1.2.0-beta.1.bin
```

## 校验和排查

安装前，核对查询返回的设备系列、型号和硬件版本。确认下载文件的字节数和 SHA-256 分别与 `ota.size`、`ota.sha256` 一致。

本例中对应 `1176976` 字节和 `a4b13eb3a234a0446faeed2e1d07a22f52bf06b40b00e22f219e15211eed6b07`。应以实际查询返回的值为准。常规 OTA 更新时，在 `needUpdate` 为 `true`、`ota` 存在且上述校验通过后安装。

- `ota.downloadUrl` 是可重复请求的 Dot. 下载入口。版本仍在分发时，每次请求都会取得新的 CDN 签名。若 `Location` 中的地址已到期，重新访问原 `ota.downloadUrl`。
- 下载入口返回 HTTP `404` 时，确认版本和组织仍可用。停用、撤销或组织不可用时，入口停止签发下载地址。重新查询同一软件 ID 和渠道，再判断是否更新。
- HTTP `503` 表示暂时无法获取签名地址，稍后重试。
- 需要分离烧录包或完整烧录镜像时，在「我的组织 → Field Lab → 软件」打开版本详情，从「软件文件」下载对应的产物。
