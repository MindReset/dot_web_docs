### 开始使用

1. 下载项目，运行 `pip install -r requirements.txt`。将 `.env.example` 复制为 `.env`，填入 [Dot. API 密钥](/docs/service/open/get_api)、设备序列号和所需的数据源配置。
2. 在 Dot. App 的内容工坊里，为每个要显示的页面向设备循环列表添加一项「图像 API」。将对应的内容 Key 填入 `PAGE_OVERVIEW_TASK_KEY`、`PAGE_HEATMAP_TASK_KEY` 或 `PAGE_QUOTA_TASK_KEY`，避免页面覆盖。
3. 运行 `python -m quotadot render` 在 `out/` 预览画面，再用 `python -m quotadot push` 推送一次。需要定时更新时，运行 `python -m quotadot run`。

总览和热力图需要能读取 cc-switch 的本地数据库。只显示额度时，也可以按[项目配置指南](https://github.com/Bhipee/quota_dot/blob/main/docs/configuration.md)在服务器上通过 Docker 运行。
