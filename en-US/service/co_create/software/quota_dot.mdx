quota-dot turns remaining Codex quota, Nexus or LiteLLM team balances, and daily token usage recorded by cc-switch into monochrome images. It sends them to Quote/0 on a schedule through the Image API.

### Get started

1. Download the project and run `pip install -r requirements.txt`. Copy `.env.example` to `.env`, then enter your [Dot. API key](/docs/service/open/get_api), device serial number, and data source settings.
2. In the Dot. App’s Content Studio, add one Image API item to the device loop for each page you want to display. Set the corresponding item key in `PAGE_OVERVIEW_TASK_KEY`, `PAGE_HEATMAP_TASK_KEY`, or `PAGE_QUOTA_TASK_KEY` so pages do not overwrite one another.
3. Run `python -m quotadot render` to preview images in `out/`, then `python -m quotadot push` to send them once. For scheduled updates, run `python -m quotadot run`.

The overview and heatmap need access to the local cc-switch database. If you only want the quota page, follow the [configuration guide](https://github.com/Bhipee/quota_dot/blob/main/docs/configuration.md) to run it on a server with Docker.
