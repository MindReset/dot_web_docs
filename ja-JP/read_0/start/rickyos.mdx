Read Pico 向けに RickyOS を開発してくださった [Ricky Young](https://github.com/chinoryunqin) さんと [RickyOS チーム](https://chinoryunqin.github.io/RickyOS-site/) に感謝します。

## はじめる前に

<CustomCloudImage osSrc="dot/docs/rickyos_1_1791255643903.png" alt="RickyOS の読書と暮らしのシステム" />

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。端末のシリアルポートを使用している他のページ、書き込みツール、ターミナルを閉じます。

先に別のシステムをインストールする必要はありません。サイトが現在のシステムを確認し、インストール方法を選びます。

<Steps>
<Step>

### インストールページを開く

パソコンの Chrome または Edge で [RickyOS 公式サイト](https://chinoryunqin.github.io/RickyOS-site/)を開き、「安装 RickyOS」（RickyOS をインストール）を押してインストール画面へ進みます。システムのバージョンはページで確認してください。

</Step>
<Step>

### 端末を接続する

USB データケーブルで Read Pico をパソコンに接続します。端末の確認項目にチェックを入れ、「连接并检查设备」（端末を接続して確認）を押してください。ブラウザの一覧で Read Pico のシリアルポートを選び、「接続」を押します。

どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示されるポートを確認してください。接続後、「芯片检查通过」（チップの確認に成功）と表示されます。この時点ではシステムは書き込まれていません。

<CustomCloudImage osSrc="dot/docs/rickyos_2_1791255643905.png" alt="RickyOS のインストール画面と端末の接続項目" />

</Step>
<Step>

### 端末を確認し、バックアップを選ぶ

現在のシステムを保存したい場合は、「先备份完整 16 MB Flash」（16 MB の Flash 全体を先にバックアップ）にチェックを入れ、「备份并检查设备」（バックアップして端末を確認）を押します。完了するとファイルが自動でダウンロードされます。ファイルを保管してください。microSD カードの内容は含まれません。

バックアップが不要な場合は、「检查设备」（端末を確認）を押します。サイトがパーティションと起動情報を読み取り、インストール方法を選びます。

- 対応する CrossMux または RickyOS が検出された場合は、アプリケーションのみを更新します。
- 公式デモシステムやその他のシステムからは、システム全体をインストールします。

表示されたインストールの説明を読み、確認が完了してから次へ進んでください。

<CustomCloudImage osSrc="dot/docs/rickyos_3_1791255643905.png" alt="現在のシステムを確認し、バックアップと RickyOS のインストールを選ぶ" />

</Step>
<Step>

### インストールを確認する

<Callout type="warn" title="端末内のデータ">

システム全体をインストールすると、現在のシステムが置き換わり、内部ファイルと設定が消去されます。残したいデータは先にバックアップしてください。サイトは microSD カードを操作しないため、カード内の書籍には影響しません。

</Callout>

インストールの確認項目にチェックを入れ、「安装 RickyOS」（RickyOS をインストール）を押します。USB 接続とページを開いた状態を保ち、ケーブルを抜いたり、パソコンをスリープさせたりしないでください。

</Step>
<Step>

### 完了するまで待つ

ページにダウンロード、書き込み、検証の進捗が表示されます。「校验通过，请确认设备出现 RickyOS 首页。」（検証に成功しました。端末に RickyOS のホーム画面が表示されているか確認してください）と表示されたら、Read Pico が再起動してホーム画面を表示していることを確認してください。

</Step>
</Steps>
