Quote/0 USB EPD Buddy は、Quote/0 に最小構成の USB フレームバッファ受信機能を追加します。macOS、Linux、Raspberry Pi からテストパターン、テキスト、画像、複合レイアウトを USB で送信できます。ローカル HTTP ミドルウェアを使えば、スクリプトや Agent から LAN 経由で画面を更新することもできます。

### 主な機能

- **USB 画像プロトコル**：152 × 296、1-bit の固定フレームバッファをデバイスへ送信
- **複数の入力形式**：テストパターン、テキスト、画像、テキスト・画像・線を組み合わせた JSON レイアウトに対応
- **表示方向の制御**：横向き、縦向き、180° 回転、フレームバッファ反転を用意
- **ローカル HTTP サービス**：Raspberry Pi や PC からテキスト、画像、複合画面のエンドポイントを提供
- **診断ツール**：シリアルポートの自動検出、テスト画面、白画面のトラブルシューティングを収録

### 向いている用途

- ローカル Agent、スクリプト、Raspberry Pi から Quote/0 を直接制御したい
- 小さな USB 画像プロトコルや UC8251D の更新処理を参考にしたい
- クラウドサービスに依存せず、LAN 内で画面を更新したい

<Callout type="warn" title="ファームウェア書き込み時の注意">
  このプロジェクトは Quote/0
  の標準アプリを第三者製ファームウェアで置き換え、現在は UC8251D
  ディスプレイコントローラー搭載機を対象としています。書き込み前に Flash
  全体をバックアップし、ハードウェア版を確認したうえで、復元手順と白画面のトラブルシューティングを読んでください。第三者製ファームウェアは保証に影響する場合があります。
</Callout>
