Pico Manager 是一款面向小尺寸墨水屏阅读设备的原生管理工具，提供 Android 和 iOS 版本。你可以连接设备、无线传入图书、整理文件目录，并管理字体、壁纸及网络与阅读设置。界面与可用功能会根据设备和固件能力自动适配。

### 功能特性

- **无线传书**：支持从系统分享导入图书与字体，自动检查设备支持的文件格式并选择目标目录。
- **文件与目录管理**：浏览设备文件，上传、下载、移动、重命名和批量删除文件，并创建目录。
- **设备配置**：按固件能力动态提供 Wi-Fi 网络管理、字体管理、壁纸上传与管理、OPDS 书源配置及设备参数调节。

### 使用前准备

支持的固件请前往 [Pico Manager 官网](https://pico.cold04.com/)查看。连接前，确认阅读设备已运行兼容固件并打开传书模式，让手机能够访问设备的网络地址。可传输的文件格式及各项管理功能取决于所连接固件的支持情况。
