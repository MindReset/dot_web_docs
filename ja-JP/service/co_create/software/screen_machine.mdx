Screen Machine は部屋の映像・音響と生成ビジュアルを管理するプロジェクトです。`dot_service` は部屋モード、音楽再生、自動運転、シーン情報を Quote/0 のダッシュボードにまとめます。操作ページを開かずに現在の状態を確認できます。

### 主な機能

- **部屋の状態一覧**：部屋モード、自動運転、マイク、AI の状態や、現在の音楽・シーン情報を表示します。
- **Quote/0 向けの画面**：296 × 152 の白黒画像を生成し、Dot 画像 API で送信します。
- **状態に応じた更新**：主要な状態の変化が安定してから送信し、通常時とライブシーン用に別々の更新間隔を設定できます。
- **プレビューと手動送信**：ローカルの画像プレビュー、サービス状態、手動送信の入口を提供します。
- **更新とスリープの設定**：Dot 設定 API で端末の更新間隔を同期し、必要に応じてスリープ時間帯も設定します。

### 使用前の準備

- デプロイ済みの Screen Machine と、必要な部屋・再生・シーン情報のサービス
- Python 環境とリポジトリの依存パッケージ
- 登録済みの Quote/0、端末 ID、Dot API Key
- Dot クラウドと関連データサービスに接続できる実行環境

自分で運用する環境向けの部屋状態ダッシュボードです。使用する機器とシーンに合わせてデータ取得元を設定します。

### 接続方法

1. リポジトリの説明に従い、Screen Machine と必要な関連サービスをデプロイします。部屋や再生の情報を取得できることを確認してください。
2. `config/room/dot.json` で端末と部屋の対応、更新間隔、必要に応じてスリープ時間帯を設定します。Dot API Key はローカルの `~/.config/screen-machine/dot.json` の `api_key` フィールドに保存し、リポジトリにはコミットしないでください。
3. リポジトリのルートで `python -m dot_service --port <PORT>` を実行し、`<PORT>` を使用可能なローカルポートに置き換えます。サービス状態、画像プレビュー、手動送信の入口から結果を確認できます。利用できる設定は現在のリポジトリの説明を参照してください。

Dot 向けの実装は [`dot_service`](https://github.com/gjbm2/screen-machine/tree/main/dot_service) にあります。全体のデプロイと部屋サービスについては、メインの README と `room_service/README.md` を参照してください。

<Callout type="info" title="端末設定">
  サービスは設定に応じて Quote/0 の更新間隔を変更し、スリープ時間帯を有効にする場合があります。接続前に設定を確認し、端末上の他のコンテンツ更新との関係も考慮してください。
</Callout>
