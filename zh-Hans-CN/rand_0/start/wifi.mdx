## Wi-Fi

Rand/0 的联网能力通过 **Wi-Fi 校时** 建立。完成后，设备会记住本次连接的 Wi-Fi，后续需要联网的功能会优先使用已保存的网络。

## Wi-Fi 校时

在 **设定** 中选择 **Wi-Fi** → **连接网络**。设备会先尝试已记忆的 Wi-Fi。如果没有可用记录，或连接失败，设备会启动临时配网并显示二维码。

显示二维码后：

1. 使用**手机系统自带相机/扫码器**扫描二维码；
2. 按照手机系统的 Wi-Fi 页面提示，连接临时网络；
3. 在打开的配网页面中提交 Rand/0 需要记住的 Wi-Fi。

连接成功后，设备会自动校时并返回正常模式。下次使用 Wi-Fi 功能时，设备会优先自动连接已记忆的网络。

请不要优先使用第三方扫码 App。部分第三方扫码 App 可能无法正确唤起系统 Wi-Fi 连接页面。

## Wi-Fi 记忆

完成 Wi-Fi 校时后，设备会将本次已连接的 Wi-Fi 自动添加到“Wi-Fi 记忆”里。设备可以记住多个网络，会在再次显示二维码前依次尝试已记忆的网络。

管理已记忆的网络时，进入 **设定** → **Wi-Fi** → **历史 Wi-Fi**，选中网络后长按下键即可删除。

<Callout type="warn" title="低电量">
电量过低时，设备可能会禁止使用 Wi-Fi 功能。添加网络或校时前，请先将 Rand/0 接入电源。
</Callout>
