## Pomodoro

Pomodoro alternates focus and rest so you can keep a simple rhythm without checking your phone.

## Choose Your Rhythm

1. Open **Pomodoro** and long press the bottom button.
2. On the first use, set the focus time from **15 to 60 minutes** in **5-minute steps**.
3. Set the rest time from **5 to 60 minutes** in **5-minute steps**.
4. Long press the bottom button to start the first focus period.

The default setup is **25 minutes of focus** and **5 minutes of rest**. After a setup has been saved, choose **Repeat last** to start another round with the same durations, or choose **Set new time** to configure them again.

## While Pomodoro Is Running

- Focus and rest alternate automatically and continue until you exit Pomodoro.
- Short press the top or bottom button to view a static remaining-time snapshot. Short press either button again to return to the status view.
- Long press the bottom button to pause. While paused, long press the bottom button to choose **Resume** or **Exit**.
- Long press the top button to leave Pomodoro and return to the More folder.

Each completed focus or rest phase plays a short alert. A focus phase starts the next round. While Pomodoro is running or paused, it is not stopped by the normal sleep timeout.
