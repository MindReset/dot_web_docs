Pico 官方示例是随开发板提供的出厂固件。你可以通过功能菜单逐项检查硬件，也可以参考其中的刷新、交互与电源处理方式开发自己的固件。

<GithubInfo owner="MindReset" repo="read_pico_firmware" />

## 基本操作

功能菜单按页展示各项演示。KEY1 与 KEY3 用于分页页面的翻页；KEY2 用于执行整屏 GC16 刷新。

## 可以体验什么

| 页面 | 内容 |
| :--- | :--- |
| 概览 | I2C 设备检测、识别码、电池与充电状态、构建时间 |
| 墨水屏刷新 | 整屏 GC16、局部 DU、16 灰阶与快速 8 灰阶，以及刷新耗时 |
| 阅读测试 | 内置正文、DU / GL16 / GC16 翻页与字号调整 |
| 触摸 | 两点触控跟手、抬手后整页刷新，以及深睡与自动唤醒 |
| 加速度计与诊断 | 三轴与倾角、敲击计数、朝向、采样参数与自测 |
| 电源与电池 | 电池与充电状态、屏幕电源轨、温度及故障信息 |
| 电源管理协议与电源按键 | PMU 状态、事件、配置、命令和按键事件 |
| 睡眠与唤醒 | 浅睡、按键或拿起唤醒、深睡与关机 |
| TF 卡与蜂鸣器 | 卡容量、挂载、重挂、格式化与蜂鸣 |
| 字体 | 列出并切换卡上的 TTF 字体、查看排版与字重效果 |
| 扩展口与设备功能自检 | IO 电平与中断、触摸复位、设备探活与命令确认 |

<Callout type="warn" title="存储卡格式化">
