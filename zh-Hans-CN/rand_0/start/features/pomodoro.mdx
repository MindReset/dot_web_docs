## 番茄时钟

番茄时钟会自动交替专注和休息，让你不用查看手机也能保持简单的工作节奏。

## 设置节奏

1. 打开 **番茄时钟**，长按下键进入。
2. 首次使用时，将专注时长设置为 **15–60 分钟**，每次调整 **5 分钟**。
3. 将休息时长设置为 **5–60 分钟**，每次调整 **5 分钟**。
4. 长按下键开始第一轮专注。

默认设置为 **专注 25 分钟、休息 5 分钟**。保存过设置后，可以选择 **重复上次** 使用相同的时长开始下一轮，也可以选择 **重新设置**。

## 使用过程中

- 专注和休息会自动交替，直到你退出番茄时钟；
- 短按上键或下键查看静态剩余时间，再短按任意键返回状态页面；
- 长按下键暂停，暂停后再次长按下键选择 **继续** 或 **退出**；
- 长按上键退出番茄时钟，返回更多文件夹。

每个专注或休息阶段结束时会播放短暂提醒音。专注阶段开始时进入下一轮。番茄时钟在运行或暂停时，不会因普通休眠超时而停止。
