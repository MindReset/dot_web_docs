quote0-monitor は、ChatGPT/Codex と GLM の利用量を Quote/0 の二つのループカードに分けて表示します。パソコンで画面をプレビューし、更新間隔を変更できます。ウィンドウを隠して、タスクトレイで更新を続けることもできます。

### 主な機能

- **二つの利用量カード**：ChatGPT/Codex と GLM を個別に送信し、それぞれオン・オフを切り替えられます。GLM カードには、取得できる場合に利用可能なリセットカード数も表示します。
- **設定ウィンドウ**：キーと端末シリアル番号を入力し、端末のカードを自動取得して接続を確認・保存できます。
- **ローカルプレビュー**：パソコンで両方のカードを確認し、プレビュー画像とログを保存します。
- **定期更新**：更新間隔を 1〜60 分から選べます。すぐに更新することもできます。
- **タスクトレイと自動起動**：ウィンドウを閉じた後も動作し、Windows 起動時の自動実行を設定できます。

### 使い始めるには

Windows パソコン、インターネットに接続した Quote/0、[Dot. API キー](/docs/service/open/get_api)、端末シリアル番号を用意してください。GLM カードには智譜オープンプラットフォームの API キーも必要です。

1. [Releases](https://github.com/YuanTutu/quote0-monitor/releases/latest) から `quote0-monitor.exe` をダウンロードします。Python のインストールは不要です。
2. Dot. App のコンテンツ工房で、端末のループに「画像 API」カードを二つ追加します。ChatGPT と GLM に一つずつ割り当て、画面が上書きされないようにします。
3. アプリの「配置」ウィンドウに Dot. API キー、端末シリアル番号、GLM キーを入力します。「获取卡片并自动填入」でカードを取得し、「测试并保存」で接続を確認して保存します。
4. ChatGPT カードを使う場合は、同じパソコンに Codex CLI をインストールし、`codex login` を実行します。GLM だけを使う場合は、メインウィンドウで ChatGPT をオフにできます。

Windows と同時に起動するには、アプリのディレクトリで次を実行します。

```powershell
.\quote0-monitor.exe --install-autostart
```

ソースコードからの実行も可能です。依存関係と詳しい設定は [README](https://github.com/YuanTutu/quote0-monitor#readme) を参照してください。

### 利用上の注意

ウィンドウを閉じるとタスクトレイに隠れ、更新は続きます。完全に終了するにはトレイアイコンの右クリックメニューを使ってください。パソコンの電源を切った場合やアプリを終了した場合、Quote/0 には最後に送信できた画面が残ります。

ChatGPT の利用量はローカルの Codex 認証情報を使って取得します。アプリは認証情報を自動更新しないため、有効期限が切れた場合は再度ログインしてください。キーはアプリと同じディレクトリの `config.json` に保存されます。このファイルを共有しないでください。手動で編集した後は、トレイから終了してアプリを再起動します。
