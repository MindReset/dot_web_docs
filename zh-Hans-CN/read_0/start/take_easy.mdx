感谢 [takeeasy-cui](https://github.com/takeeasy-cui) 为小纸 Pico 提供系统。

Take Easy 是面向小纸 Pico 的第三方阅读系统，提供本地书库、中文输入、天气与日常小工具，可按自己的习惯调整排版和锁屏。

## 开始之前

准备电量充足的小纸 Pico、使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。关闭其他占用设备串口的网页、刷写工具或终端。

建议准备 FAT32 格式的 microSD 存储卡，用于存放书籍和字体。安装前先备份重要数据。

安装会替换当前系统。更新 Take Easy 时，不勾选安装弹窗中的「擦除设备」可保留设备设置与阅读记录；勾选后会清除设备内部数据。microSD 卡上的文件不受影响。

V1.0.2 更新了分区布局。从更早版本升级时，机内书区会重建，保存在机内的书籍需要重新传入。

## 通过官网安装

<Steps>
<Step>

### 打开安装页面

在电脑的 Chrome 或 Edge 中打开 [Take Easy 官网](https://take-easy.pages.dev/)，进入[在线安装页面](https://take-easy.pages.dev/install/)。版本与安装要求以页面显示为准。

</Step>
<Step>

### 连接设备并安装

用 USB 数据线连接小纸 Pico，点击连接按钮，在浏览器弹窗中选择设备串口。确认安装清单和「擦除设备」选项后，按页面提示开始写入。

保持 USB 连接、页面打开和电脑唤醒，等待写入完成、设备自动重启。输入法词库随安装写入，无需另行导入。

找不到串口时，先唤醒设备并保持 USB 连接，退出设备的 USB 读卡模式，关闭占用串口的其他程序；必要时在设备「设置 → 升级和恢复」进入 BOOT 模式后重试。

</Step>
<Step>

### 导入书籍和字体

将 EPUB、TXT 文件放入 microSD 卡的 `Books/` 文件夹，将 TTF、OTF 字体放入 `Fonts/` 文件夹，再从书架打开书籍。

也可开启设备的 USB 文件传输，通过电脑复制文件；或开启 Wi-Fi 传书，让手机或电脑连接同一网络，在浏览器中打开设备显示的地址上传。使用设备热点传书时，按屏幕提示连接并上传。

内置字体只包含部分常用汉字。若文字显示为方框，请将完整的中文字体放入 `Fonts/`，并在阅读排版菜单中切换。

</Step>
</Steps>

## 主要功能

### 本地阅读与排版

阅读 EPUB、TXT，查看书籍封面和阅读进度。可调整字体、字号、字重、行距、段距与页边距，并切换竖屏、横屏、竖排或倒转版式。阅读数据面板可查看阅读时长与进度。

### 天气、便签与小工具

首页可切换天气、黄历、木鱼和随心记小组件，也可打开便签、番茄钟、计算器等应用。天气可选择心知、和风或彩云数据源，并配置地点与密钥。

中文输入支持全拼和九宫格拼音，可翻页选择候选词，并使用联想输入与用户词典。

### 锁屏与个性化

可选择票根、壁纸、时钟或计算器四种锁屏样式，并设置锁屏密码。自选锁屏图片可放入 microSD 卡的 `LockScreens/` 文件夹。

## 使用说明与更新

按键操作、文件目录与配置备份见[官网使用说明](https://take-easy.pages.dev/docs/)。更新系统时，可回到[在线安装页面](https://take-easy.pages.dev/install/)重新安装；请先查看安装提示中的数据保留条件与[更新日志](https://take-easy.pages.dev/changelog/)。

Take Easy 基于 MindReset 小纸 Pico 官方示例固件与 [kiikoread](/docs/read_0/start/kiikoread) 开发，输入法引用 YanReader。
