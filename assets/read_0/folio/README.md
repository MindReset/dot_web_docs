# 页间 Folio 文档配图

这些 PNG 于 2026-11-17 从页间 Folio 公开仓库 `qmqsu/folio` 的 `site/public/images/` 中同名 WebP 原样转换，尺寸均为 684 × 1216。原图由项目的 `tools/tests/run_ui_preview.sh` 使用当前固件的真实 UI 代码渲染，不是实机照片，也不用于证明实体墨水屏的刷新效果。

- `home.png`：首页、继续阅读与阅读统计。
- `library.png`：封面网格书架。
- `reading.png`：正文阅读页。
- `settings.png`：设置入口。

书籍、封面、正文和统计内容均为项目公开的合成测试夹具，不包含真实用户书籍、阅读记录、账号或凭据。原始公开文件及说明见 https://github.com/qmqsu/folio/tree/main/site/public/images 。

MDX 使用主仓库 `main` 分支的公开原始文件地址。图片需与文档一并合入主仓库；PR 预览时可使用对应分支的原始文件地址。
