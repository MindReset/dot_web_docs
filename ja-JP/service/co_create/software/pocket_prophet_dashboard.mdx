Pocket Prophet Dashboard は、200 × 200 の口袋先知電子ペーパー向けローカル Web サービスです。デバイス公式の壁紙エンドポイントとクラウド画像変換機能を使い、占い、奇門遁甲、天気、株価、ニュース、Claude Code の Token 使用量を画像にして送信します。ファームウェアの書き換えや改造は不要です。

### 主な機能

- **易占い**：三枚の硬貨を使う方法で本卦、変卦、短い判断を生成
- **奇門遁甲**：現在時刻から盤を作り、3 × 3 の九宮格で表示
- **天気**：wttr.in から天気アイコン、気温、体感温度、降水確率を取得
- **株価情報**：Yahoo Finance を使い、複数銘柄の概要または 1 銘柄の詳細を表示
- **今日のニュース**：RSS、Atom、今日頭条のトレンドを統合し、情報源を変更可能
- **Token 使用量**：ローカルの Claude Code トランスクリプトを読み、ユーザー設定の予算に対する当日使用量、直近 5 時間、概算コストを表示
- **自動ローテーション**：デバイスが壁紙転送画面を開いている間、選択したページを定期的に切り替え

### 事前準備

- 口袋先知デバイスと、同じ Wi-Fi に接続した PC またはスマートフォン
- Python 3 とプロジェクトの依存パッケージ
- 壁紙転送画面に表示されるデバイスのローカル IP。MAC アドレスを設定すると、IP 変更後の再検出に利用できます
- `config.example.json` から作成したローカル設定

`python3 app.py` を実行した後、ローカルネットワークからポート `5151` へアクセスします。易占いと奇門遁甲は直接送信でき、天気、株価、ニュース、使用量の各ページは送信前にプレビューできます。

<Callout type="warn" title="デバイスの接続条件">
  口袋先知は通常オフラインで、壁紙転送画面を開いている間だけローカルネットワークへ接続します。自動ローテーションにはこの画面を開いたままにする必要があり、その間は他の壁紙更新が上書きされる場合があります。長時間のオンライン状態がバッテリーへ与える影響は確認されていません。
</Callout>

<Callout type="info" title="現在の実行制限">
  現在は macOS
  でのみ検証され、中国語フォントのパスも macOS
  向けに固定されています。内蔵の Flask
  開発サーバーは個人の LAN
  利用を前提としており、インターネットへの公開に必要な認証や並行処理の強化はありません。天気、株価、ニュースは無料の公開データ源を利用するため、タイムアウトやレート制限が発生する場合があります。
</Callout>
