## Before you start

Prepare a computer, desktop Chrome or Edge, and a USB-C cable that supports data transfer.

Flashing replaces the current system and may clear its settings. No system backup is needed when installing CrossMux from the official demo for the first time. Make sure the device has enough charge.

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux website" />

<Steps>
<Step>

### Open the flashing page

Open the [CrossMux official website](https://crossmux.com/) in Chrome or Edge on your computer. Find the device selection area.

</Step>
<Step>

### Select your device

Select **MindReset Read Pico** in the device list.

<CustomCloudImage osSrc="dot/docs/corssmux_2_1790790168698.png" alt="Select Read Pico" />

</Step>
<Step>

### Select a system version and connect the device

Select the **Nightly** beta release. Check the page for the current version number.

Confirm that the connected device is MindReset Read Pico in the flashing section. The browser identifies it as an ESP32-S3 and cannot distinguish it from other models using the same chip, so check the connected hardware yourself.

**No backup is needed when installing CrossMux from the official demo for the first time.** Leave the system backup option unchecked and proceed with installation. You can restore the official demo system at any time using the restoration card below.

<CustomCloudImage osSrc="dot/docs/crossmux_3_1790790168698.png" alt="Select Nightly, confirm the device, and choose whether to back up" />

Connect Read Pico to your computer with the USB data cable.

If you are unsure which entry is Read Pico, cancel the picker, unplug the device, and reconnect it. Look for the newly added entry.

</Step>
<Step>

### Start installation

Check the device, system version, and backup option, then click the online flashing button and select the device serial port in the browser picker.

The progress area below shows system download and verification, device connection, partition checks, installation, result verification, and device reset. Wait for the completion message. Keep the cable connected and the page open, and prevent your computer from going to sleep.

<CustomCloudImage osSrc="dot/docs/crossmux_4_1790790168697.png" alt="Flashing complete and restart instructions" />

</Step>
<Step>

### Start using your device

The device resets automatically when flashing finishes. If it does not start, unplug and reconnect USB, then turn it on with the power key.

</Step>
</Steps>

<Callout type="info" title="Other installation options">

Besides the website's web flasher, you can clone or fork the CrossMux repository and follow its instructions to build and flash from source. You can also download system packages from its Releases page and follow that release's installation notes. Choose releases and installation instructions that explicitly support Read Pico.
