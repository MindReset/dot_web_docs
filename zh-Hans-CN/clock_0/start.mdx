## 安装电池

1. 找到背面的小盖，按下右下角箭头指示的位置，沿箭头方向打开小盖。
2. 将随附的 CR2032 电池装入电池座，**正极（+）朝外，面向后盖**。
3. 将磁吸小盖装回原位。

CR2032 是不可充电的锂电池。更换时使用同型号电池。

## 第一次设置

第一次使用时，屏幕会显示引导信息，并指示当前需要设置的项目。上面的按键是 **SET**，下面的按键是 **BACK**。

1. 查看屏幕指示的日期或时间项目。
2. 短按 **SET** 增加数值，短按 **BACK** 减少数值。
3. 长按 **SET** 确认当前数值，指示器会跳转到下一项。
4. 按屏幕提示完成全部设置，设备会自动进入工作模式。

## 按键速查

| 按键 | 短按（设置时） | 长按 |
| :--- | :--- | :--- |
| 上键 SET | 增加当前数值 | 工作模式下进入设置；设置时确认当前数值并跳到下一项 |
| 下键 BACK | 减少当前数值 | 刷新屏幕，清除残影 |

需要校准日期或时间时，长按 **SET**，再按首次设置的方法逐项调整。

## 清除屏幕残影

快速刷新后，墨水屏可能会留下上一幅画面的痕迹。长按 **BACK** 进行一次完整刷新，可以清除这些残影。

## 显示与放置

设备进入工作模式后，显示内容会随日出日落自动切换。

后盖采用磁吸固定，也可以让 小钟 吸附在磁性表面。
