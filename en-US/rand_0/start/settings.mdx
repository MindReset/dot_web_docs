title: Settings

---

## Open Settings

From the main menu, select **SETUP** and long press the bottom button to enter.

Use the same controls throughout Settings:

- Short press the top or bottom button to move between options;
- Long press the bottom button to enter, confirm, or save;
- Long press the top button to go back.

## Settings Menu

### Lock Now

Lock the device immediately. You can also long press the top button from the main menu for a quick lock.

### Wallpaper

Open the wireless wallpaper flow. See [Custom Wallpaper](/docs/rand_0/start/wallpaper) for the complete procedure.

### Wi-Fi

Choose **Connect** to add a network or sync the device time. Choose **History** to view remembered networks and long press the bottom button to delete the selected network. See [Wi-Fi](/docs/rand_0/start/wifi) for connection behavior and power requirements.

### Home Screen

Use **Reorder** to change the order of apps on the main menu. Select an app, long press the bottom button to move it, use the short presses to change its position, and long press the bottom button again to save it.

Use **Edit Folder** to move apps between the main menu and the **More** folder. Long press the bottom button to move an app out of the folder, or select **Add App** to move an app in. A folder can contain up to 9 apps.

### Lock Rotate

Turn the lock-screen wallpaper rotation on or off. This changes the lock-screen orientation only; it does not rotate normal menus.

### Sleep Time

Choose how long Rand/0 waits without interaction before entering the lock screen. Available options are **1, 2, 3, 5, or 10 minutes**.

### Key Sound

Turn device sound feedback on or off. This setting also affects the sounds used by timers and alerts.

### Guide Pages

Choose whether to show the guide pages when entering MBTI Guide. Turn this off to go directly to the personality guide.

### Language

Choose **Simplified Chinese**, **Traditional Chinese**, or **English**. Long press the bottom button to save the language.

### Reset Guide

Clear the saved MBTI personality. The next time you open MBTI Guide, you can choose a personality again. See [MBTI Guide](/docs/rand_0/start/features/mbti_guide).

### Reset Merit

Set the Wooden Fish merit counter back to zero. See [Wooden Fish](/docs/rand_0/start/features/merit).

<Callout type="warn" title="Factory Reset cannot be undone">
**Factory Reset** clears user settings, the home-screen layout, remembered Wi-Fi networks, and the custom wallpaper, then restarts Rand/0. Use it only when you want to set up the device again from the beginning.
</Callout>

### System Version

View the firmware version, battery level, and device information. Long press the bottom button on this page to enter Wi-Fi OTA. See [Update Device](/docs/rand_0/firmware/update_firmware) before starting an update.
