### はじめるには

1. プロジェクトをダウンロードし、`pip install -r requirements.txt` を実行します。`.env.example` を `.env` にコピーし、[Dot. API キー](/docs/service/open/get_api)、端末のシリアル番号、使用するデータソースの設定を入力します。
2. Dot. アプリの創造所で、表示したい画面ごとに「画像 API」を 1 件ずつ端末のループリストに追加します。画面が上書きされないよう、対応するコンテンツのキーを `PAGE_OVERVIEW_TASK_KEY`、`PAGE_HEATMAP_TASK_KEY`、`PAGE_QUOTA_TASK_KEY` に設定します。
3. `python -m quotadot render` を実行して `out/` の画像を確認し、`python -m quotadot push` で一度送信します。定期更新する場合は `python -m quotadot run` を実行します。

概要とヒートマップの表示には、cc-switch のローカルデータベースへのアクセスが必要です。利用枠の画面だけを表示する場合は、[設定ガイド](https://github.com/Bhipee/quota_dot/blob/main/docs/configuration.md)に従ってサーバー上で Docker を使って実行することもできます。
