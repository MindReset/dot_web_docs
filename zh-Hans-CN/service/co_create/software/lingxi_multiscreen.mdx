多屏灵犀是一套 macOS 应用，用一套软件管理灵犀68 键盘屏、口袋先知（Rand/0）墨水屏与摘录（Quote/0）墨水屏。你可以组合时钟、系统监控、正在播放、Codex 用量、千问办公额度、番茄钟和少数派推荐等模块，再将画面推送到对应设备。

### 功能特性

- **三类设备统一管理**：分别保存灵犀68、口袋先知和 Quote/0 的连接信息与画板设置，也可以管理多台设备。
- **灵犀画板与卡片轮播**：组合时钟、日期、系统监控、正在播放、用量、番茄钟、自定义图片和少数派推荐等模块，控制侧栏显示与自动轮播顺序。
- **口袋先知画板**：为 200 × 200 的 Rand/0 组合模块，支持亮色或深色底色、旋转、黑白或 4 级灰阶，以及多种灰阶和抖动方式，并通过局域网推送。
- **Quote/0 画板**：为 296 × 152 的 Quote/0 墨水屏使用单列或双列布局，可旋转画面、自动推送图片，并选择由本地或 Dot 服务端完成图像处理。
- **键盘快捷控制**：为番茄钟自定义全局快捷键，也可以通过设备按键切换画板、翻页或更新内容。
- **多屏联动**：系统监控、正在播放、Codex 用量和千问办公额度等信息可以在不同画板与卡片中复用。

### 安装要求

- macOS 26 或更高版本
- Apple 芯片（M1 或更高版本）
- 需要使用灵犀68、口袋先知或 Quote/0 时，设备与 Mac 应处于可互相访问的网络环境；Quote/0 还需要在 Dot App 中准备 API Key 与设备序列号
