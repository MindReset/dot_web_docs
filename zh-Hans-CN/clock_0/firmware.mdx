你可以编写自己的固件，通过电路板上引出的 SWD 接口刷写，尝试自己的时钟画面、按键交互与低功耗应用。小钟 不提供设计窗口，自定义显示需要通过固件开发实现。

## 芯片资料

小钟 搭载 CW32L010，处理器、存储与时钟参数见[技术规格](/docs/clock_0)。芯片的外设与封装信息见武汉芯源的 [CW32L010 数据手册](https://www.whxy.com/shujushouce.html)。

## 连接 SWD

按[安装电池](/docs/clock_0/start)的方法打开磁吸后盖。电路板引出了五个焊盘：**GND、GND、CLK、DIO、3V**。按信号标记接线。

| 板上焊盘 | 调试器连接 | 用途 |
| :--- | :--- | :--- |
| GND（两个焊盘） | GND | 设备与调试器共地 |
| CLK | SWCLK | SWD 时钟 |
| DIO | SWDIO | SWD 双向数据 |
| 3V | 目标电压参考端，如 Vref / VTref | 为支持电压检测的调试器提供目标板电压参考 |

<Callout type="warn" title="供电与接线">

设备额定供电为 3 V。调试器的电压参考端与电源输出端用途不同，不要把 5 V 电源接到 3V 焊盘。

接线前断开供电；使用外部电源供电时先取出 CR2032 电池，避免外部电源向不可充电电池回灌。接好后确认共地、极性与目标电压，再接通供电。

</Callout>

## 准备开发环境

准备兼容 CW32L010 的 SWD 调试器、连接线，以及适配该芯片的编译和调试环境。

- [CW-DAPLINK](https://www.whxy.com/kaifagongju.html) 是芯片厂商提供的 SWD 调试工具，可配合 Keil 或 IAR 使用，接口电平参考来自目标板。
- 从[官方固件库](https://www.whxy.com/gujianku.html)获取 CW32L010 标准外设库。
- 参考 [CW32L010 用户手册](https://www.whxy.com/yonghushouce.html)配置 RTC、GPIO、低功耗模式等外设。

## 编译与刷写

开发前需核对对应硬件版本的屏幕控制器型号、分辨率、引脚分配和电气连接。芯片外设库示例需适配这些连接后，才能用于 小钟。

1. 从 CW32L010 的芯片示例工程开始，选择与实物一致的型号，配置启动文件、内存容量与下载算法。
2. 选择 SWD 调试方式，按上述信号表接线并确认调试器能够识别芯片。
3. 根据 小钟 的硬件连接适配按键、时钟与屏幕驱动，再编译固件。
4. 准备好恢复方式后，将编译产物写入设备，按自己实现的交互检查计时、按键与屏幕刷新。

<Callout type="warn" title="保留出厂固件">

刷写会替换设备现有固件。若希望保留恢复出厂功能的能力，请在刷写前准备可恢复的固件或有效备份。

芯片读保护可能使固件无法读取；降低保护等级可能触发整片擦除，具体行为见[芯片数据手册](https://www.whxy.com/uploads/files/20250604/CW32L010_DataSheet_EN_V1.0.pdf)。

</Callout>

## 实现自己的时钟

| 功能 | 实现方法 |
| :--- | :--- |
| 日期与时间 | 以已配置的 32.768 kHz LSE 作为 RTC 时基，按显示需求安排唤醒 |
| 按键交互 | 为 SET 与 BACK 做按键去抖，区分短按和长按 |
| 墨水屏显示 | 按实际屏幕控制器的初始化序列与时序驱动，分别处理快速刷新与完整刷新 |
| 日出日落切换 | 在固件中计算或保存切换时间，按时更新画面 |
| 低功耗 | 完成计时、按键处理与屏幕刷新后进入低功耗模式，按需唤醒 |
| 内存使用 | 按实际 SRAM 容量规划绘图缓冲，必要时按行或分块输出；固定字库和图案可放在 Flash |

## 无法连接时

先确认设备供电、共地以及 CLK / DIO 接线，再检查调试器的目标电压参考与 SWD 配置。连接不稳定时可尝试降低 SWD 时钟。

如果仍无法识别芯片，先核对芯片型号与保护状态，避免直接执行解锁或整片擦除。
