Read Pico は電子ペーパー開発ボードです。

Read Pico は、ネイティブ 16 階調の 4.7 インチ電子ペーパー、2 点タッチ、3 つのタッチキーを搭載しています。ESP32-S3 デュアルコアプロセッサー、microSD カードによるストレージ拡張、USB-C ポートを備えています。

## Read Pico の技術仕様

| 項目 | 仕様 |
| :--- | :--- |

| MCU | ESP32-S3、Xtensa® 32 ビット LX7 デュアルコアプロセッサー |

## 使用とお手入れ

- 画面はガラス製です。破損や傷に注意して保護してください。
- 清掃時は製品内部に水が入らないようにしてください。製品や画面表面の汚れは、中性洗剤を含ませた柔らかい布で拭き取れます。
- 高温、多湿、極端な低温などの過酷な環境を避けてください。
- 製品を水中に浸さないでください。
