## 設定を開く

メインメニューで **SETUP** を選び、下ボタンを長押しして入ります。

設定内では、次の操作を使います。

- 上ボタンまたは下ボタンを短押しして項目を移動する;
- 下ボタンを長押しして入る、確定する、保存する;
- 上ボタンを長押しして戻る。

## 設定メニュー

### Lock Now

すぐにロック画面へ移動します。メインメニューで上ボタンを長押ししてクイックロックすることもできます。

### Wallpaper

ワイヤレス壁紙変更フローを開きます。詳しい手順は[カスタム壁紙](/docs/rand_0/start/wallpaper)を参照してください。

### Wi-Fi

**Connect** でネットワークを追加または時刻を同期します。**History** で記憶済みネットワークを確認し、対象を選んで下ボタンを長押しすると削除できます。接続の流れと電源条件は [Wi-Fi](/docs/rand_0/start/wifi) を参照してください。

### Home Screen

**Reorder** でメインメニューのアプリ順を変更します。アプリを選び、下ボタンを長押しして移動を開始し、短押しで位置を変更して、もう一度下ボタンを長押しして保存します。

**Edit Folder** では、メインメニューと **More** フォルダーの間でアプリを移動できます。フォルダー内のアプリを選んで下ボタンを長押しすると外へ移動できます。**Add App** を選ぶと、アプリをフォルダーへ移動できます。フォルダーには最大 9 個のアプリを入れられます。

### Lock Rotate

ロック画面壁紙の回転をオンまたはオフにします。通常のメニューの向きは変わりません。

### Sleep Time

操作がないときにロック画面へ移行するまでの時間を選びます。**1、2、3、5、10 分**から選択できます。

### Key Sound

端末の操作音をオンまたはオフにします。タイマーやアラートの音にも反映されます。

### Guide Pages

MBTI Guide を開くときにガイドページを表示するか選びます。オフにすると、人格ガイドへ直接進みます。

### Language

**簡体字中国語**、**繁体字中国語**、**English** から選択できます。下ボタンを長押しして保存します。

日本語ドキュメントの説明は日本語ですが、端末の UI は日本語には対応していません。

### Reset Guide

保存済みの MBTI 人格を消去します。次に MBTI Guide を開くと、人格を選び直せます。[人格ガイド](/docs/rand_0/start/features/mbti_guide)も参照してください。

### Reset Merit

木魚の功徳カウンターを 0 に戻します。[木魚](/docs/rand_0/start/features/merit)も参照してください。

<Callout type="warn" title="Factory Reset は取り消せません">
**Factory Reset** を実行すると、ユーザー設定、ホーム画面のレイアウト、記憶済み Wi-Fi、カスタム壁紙が消去され、Rand/0 が再起動します。最初から端末を設定し直す場合にのみ使用してください。
</Callout>

### System Version

ファームウェアバージョン、バッテリー残量、端末情報を確認します。この画面で下ボタンを長押しすると Wi-Fi OTA に進みます。更新前に[デバイスを更新](/docs/rand_0/firmware/update_firmware)を確認してください。
