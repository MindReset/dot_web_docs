組織では、メンバー、権限、リソースをチームで管理できます。ここでは `Field Lab` を例に説明します。

## 組織の作成を申請する

1. ログインして [マイアカウント → 自分の組織](/panel?tab=my-account&accountTab=organizations)を開き、「組織の作成を申請」を選びます。
2. 組織名に `Field Lab` を入力し、任意でアイコンや説明を追加して申請します。
3. 「自分の申請」で審査状況と審査結果を確認します。修正が必要な場合は「修正して再申請」を選びます。
4. 承認されたら、サイドバーの組織一覧から `Field Lab` を開きます。

サポートに組織 ID を伝えるときは、組織ページ上部の操作メニューから「組織 ID をコピー」を選びます。

## メンバーを招待する

「組織 → 招待」で招待方法を選びます。招待を承諾すると、組織に参加できます。

| 方法 | 招待された人の操作 |
| --- | --- |
| メール | 招待メールのリンクを開き、対象の認証済みメールアドレスでログインして承諾します。 |
| 電話番号 | 対象の電話番号を登録・認証した Dot. アカウントでログインします。ウェブサイトの「マイアカウント → 自分の組織 → 受け取った招待」から承諾します。 |
| 参加リンク | 共有されたリンクを開き、Dot. アカウントでログインして参加を確認します。 |

招待と参加リンクの有効期間は 48 時間です。「招待」で未承諾の招待を確認・取り消したり、参加リンクを無効にしたりできます。

参加リンクは複数の人と共有できます。組織に参加できるのはオーナーを含めて最大 100 人です。招待を承諾したりリンクから参加したりする時点で空きが必要です。

## 権限を管理し、所有権を移譲する

| 役割 | できること |
| --- | --- |
| メンバー | メンバーを確認し、ウェブサイトでデバイスソフトウェアのプロジェクトやバージョンを管理できます。組織から退出できます。 |
| 管理者 | メンバーの操作に加えて、組織情報の編集、招待と認証情報の管理、一般メンバーの削除ができます。 |
| オーナー | 管理者の操作に加えて、管理者権限の付与・解除、他のメンバーの削除、所有権の移譲ができます。 |

組織の操作メニューから「所有権を移譲」を選び、参加済みのメンバーを指定して確定します。選ばれた人がオーナーになり、元のオーナーはメンバーになります。移譲完了後は、元のオーナーも組織から退出できます。

オーナーは同じメニューから組織を削除できます。削除すると、その組織の API とソフトウェアの公開ダウンロードが終了します。

Dot. が組織を停止すると、組織ページに停止状態が表示されます。組織の管理、ソフトウェアの公開、公開ダウンロードも停止します。異議申し立ての方法は[組織・公開者規約](/docs/organization_terms)を確認してください。
