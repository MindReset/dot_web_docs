## 木魚

木魚は、小さな悩みを軽く叩いて流すためのアプリです。

-   下ボタン短押しごとに功徳 +1。
-   合計タップ回数を記録します。
-   **SETUP** → **Reset Merit** から木魚カウンターをリセットできます。

## 操作

1. 下ボタンを長押しして入ります。
2. 下ボタン短押しで功徳 +1。
3. 上ボタン長押しでホームに戻ります。

カウンターのリセットについては[設定](/docs/rand_0/start/settings)を参照してください。
