このオープンソース読書システムを提供してくださった [0x1abin](https://github.com/0x1abin) さんと CrossMux コミュニティ、Read Pico 対応を実装してくださった [Moku Yui](https://github.com/MokuMMk) さんに感謝します。

## はじめる前に

パソコン、デスクトップ版 Chrome または Edge、データ転送に対応した USB-C ケーブルを用意してください。

書き込みによって現在のシステムが置き換わり、設定が消える場合があります。公式デモから初めて CrossMux をインストールする場合、元のシステムのバックアップは不要です。端末を十分に充電してください。

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux 公式サイト" />

<Steps>
<Step>

### 書き込みページを開く

パソコンの Chrome または Edge で [CrossMux 公式サイト](https://crossmux.com/)を開き、端末を選ぶ欄を探します。

</Step>
<Step>

### 端末を選ぶ

端末の一覧から **MindReset Read Pico** を選びます。

<CustomCloudImage osSrc="dot/docs/corssmux_2_1790790168698.png" alt="Read Pico を選択" />

</Step>
<Step>

### システムを選んで接続する

**Nightly** ベータ版を選びます。現在のバージョン番号はページで確認してください。

書き込み欄で、接続中の端末が MindReset Read Pico であることを確認する項目にチェックを入れます。ブラウザは端末を ESP32-S3 として認識し、同じチップを使う他の機種とは区別できません。接続した端末を確認してください。

**公式デモから初めて CrossMux をインストールする場合、バックアップは不要です。** システムのバックアップ項目にはチェックを入れず、そのままインストールできます。下の復元カードから、いつでも公式デモシステムに戻せます。

<CustomCloudImage osSrc="dot/docs/crossmux_3_1790790168698.png" alt="Nightly の選択、端末の確認とバックアップ設定" />

USB データケーブルで Read Pico をパソコンに接続します。

どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示される項目を確認してください。

</Step>
<Step>

### インストールを開始する

端末、システムのバージョン、バックアップ設定を確認し、オンライン書き込みのボタンを押します。ブラウザの一覧で端末のシリアルポートを選んでください。

下の進捗欄に、システムのダウンロードと検証、端末への接続、パーティションの確認、インストール、結果の検証、端末のリセットが表示されます。完了の表示が出るまで、ケーブルを抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。

<CustomCloudImage osSrc="dot/docs/crossmux_4_1790790168697.png" alt="書き込み完了と再起動の案内" />

</Step>
<Step>

### 使いはじめる

書き込みが完了すると端末は自動でリセットされます。起動しない場合は USB を抜き差しし、電源キーで起動してください。

</Step>
</Steps>
