感谢 [PageRest 开发者](https://pico.gofree.kdns.fr/) 为小纸 Pico 提供系统。

PageRest 是面向小纸 Pico 的阅读系统，以本地阅读为核心，提供封面书架、字体管理、无线传书、蓝牙翻页器，以及图片锁屏和摘录锁屏。

## 开始之前

准备电量充足的小纸 Pico、使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。关闭其他占用设备串口的网页、刷写工具或终端。

书籍、字体和自定义锁屏图片可存放在 microSD 卡中。小纸 Pico 最大支持 512 GB，格式为 FAT32。

## 通过官网安装

<Steps>
<Step>

### 打开官网

在电脑的 Chrome 或 Edge 中打开 [PageRest 官网](https://pico.gofree.kdns.fr/)，查看当前版本的安装说明并下载对应系统。

</Step>
<Step>

### 选择安装方式

首次安装或恢复设备时使用完整系统。已有 PageRest 的设备可以选择保留数据升级，以保留设置和阅读记录。

</Step>
<Step>

### 连接设备并刷写

用 USB 数据线将小纸 Pico 连接到电脑，按官网对应版本的说明完成刷写。安装会替换设备当前的系统，请先保存需要保留的数据。

保持 USB 连接、页面打开和电脑唤醒，等待刷写完成，再按官网说明启动设备。

</Step>
</Steps>

## 主要功能

### 首页与书架

首页提供继续阅读、最近阅读、阅读进度和书架入口。

### 阅读工具

阅读器支持字号、字体、行距、页边距、首行缩进、段落间距、目录、书签、百分比跳转和阅读进度显示。

TXT 和 EPUB 均可从本地存储读取，EPUB 支持章节导航以及本地 JPEG / PNG 插图。字体可以使用内置字库，也可以从 TF 卡导入 TTF 字体。

### 图片锁屏与摘录锁屏

PageRest 支持多种锁屏方式：

- 图片锁屏：使用内置图片，或从 TF 卡导入 JPG / PNG 图片作为锁屏壁纸。
- 摘录锁屏：将阅读过程中保存的摘录展示在锁屏界面，并保留书名和来源信息。
- 时钟、日历等信息锁屏：适合在设备休眠时显示简洁的信息页面。

锁屏可以配合浅睡、深睡或关机策略使用，唤醒后返回原来的阅读位置。

### 无线传书与 USB 存储

通过设备热点或已有 WiFi，可以在电脑或手机浏览器中上传 TXT / EPUB 图书、TTF 字体和 JPG / PNG 锁屏图片。

传书页面提供二维码、连接状态、上传进度和失败恢复。设备也支持 USB 连接电脑，将 TF 卡作为磁盘使用。

### 蓝牙翻页器

PageRest 提供 BLE HID 翻页器支持，可连接兼容的蓝牙翻页设备，并配置上一页、下一页、方向反转和锁屏按键。

蓝牙仅在阅读正文中生效，不控制菜单和设置页面。ESP32-S3 只支持 BLE，传统 Bluetooth Classic 设备和需要独立接收器的翻页器不在直接配对范围内。

### 屏幕刷新与电源管理

PageRest 针对小纸 Pico 的 4.7 英寸 16 级灰阶墨水屏设计，提供标准灰阶和快速刷新路径，并支持可配置的清残影周期。

系统支持浅睡、深睡和关机模式，锁屏界面可以使用图片、摘录、时钟或日历。

不同版本的功能、刷新速度、功耗和蓝牙设备兼容性，请以官网发布说明和实际设备表现为准。
