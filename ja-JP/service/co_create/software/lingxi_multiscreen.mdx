Lingxi MultiScreen は、Linx68 キーボード画面、Rand/0 電子ペーパー画面、Quote/0 電子ペーパー画面を 1 つの macOS アプリで管理するソフトウェアです。時計、システムモニター、再生中の情報、Codex 使用量、Qwen Work 使用量、ポモドーロ、レコメンドなどを組み合わせ、目的のデバイスへ画面をプッシュできます。

### 主な機能

- **3 種類のデバイスを一元管理**：Linx68、Rand/0、Quote/0 の接続情報とボード設定を個別に保存し、複数台のデバイスを管理できます。
- **ボードとカードのローテーション**：時計、日付、システムモニター、再生中の情報、使用量、ポモドーロ、カスタム画像、レコメンドなどを組み合わせ、サイドバー表示と自動切り替え順を設定できます。
- **Rand/0 ボード**：200 × 200 の画面を構成し、明暗の背景、回転、白黒または 4 階調、複数のグレースケール処理とディザリング、ローカルネットワーク経由のプッシュに対応します。
- **Quote/0 ボード**：296 × 152 の Quote/0 向けに 1 列または 2 列のレイアウトを作成し、回転、自動プッシュ、ローカルまたは Dot サーバー側の画像処理を利用できます。
- **ショートカットとボタン操作**：ポモドーロのグローバルショートカットを変更したり、デバイスのボタンでボード切り替え、ページ送り、更新を実行したりできます。
- **データの再利用**：システムモニター、再生中の情報、Codex 使用量、Qwen Work 使用量を複数のボードやカードで共有できます。

### 動作要件

- macOS 26 以降
- Apple シリコン（M1 以降）
- デバイスと Mac がローカルネットワーク経由で接続できること。Quote/0 を使う場合は Dot App の API キーとデバイスシリアル番号も必要です
