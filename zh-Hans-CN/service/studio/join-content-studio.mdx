Dot 内容工坊面向希望接入 Dot 设备的内容平台、工具服务和数据来源。提交后，Dot 会根据内容类型、数据来源、授权方式和设备适配情况评估接入方案。

内容类别、内容提供方式、平台用户规模和联系邮箱会在页面底部的表单中选择或填写。下面只列出建议在“详细说明”中补充的资料。

## 适合接入的内容

- 能以固定频率更新，适合在小屏或电子纸设备上浏览的内容。
- 有清晰来源、版权归属和展示授权的内容。
- 可以通过 RSS、REST API、OAuth 授权后的 API，或由平台直接提供的数据完成同步的内容。
- 可以为用户提供摘要、提醒、状态、榜单、日程、收藏、订阅或个性化信息的内容。

## 建议提供的资料

| 资料 | 要求 |
| --- | --- |
| 内容名称 | 根据内容适用国家或地区提供中文、日文、英文名称。每种语言最多 8 个字或短词，建议格式为 `{平台名称} {具体内容}`。 |
| 内容简介 | 根据内容适用国家或地区提供中文、日文、英文简介。中文和日文建议不超过 50 个字，英文建议不超过 25 个词。 |
| 内容来源名称 | 用于在 Dot 内容工坊中展示内容来源。 |
| 内容来源链接 | 必填。建议使用平台官网、产品页或内容来源主页。 |
| 内容工坊卡片图标 | 建议为 PNG，透明背景，100 x 100 px，用于卡片左上角图标。 |
| 内容工坊卡片颜色 | 提供 1 到 3 个 Hex 色值，用于卡片背景从上到下的渐变。只提供 1 个颜色时，卡片使用单色背景。 |
| OAuth 展示图标 | 如果内容需要 OAuth 授权，请提供 PNG 透明背景图标，200 x 200 px，并确认在黑色背景和白色背景下都清晰可辨。 |
| 适用国家、地区和语言 | 说明内容适用的国家、地区和语言。当前文档建议提供中文、日文、英文资料。 |
| 内容排版和布局 | 如果已经有布局设想，可以提供文字说明、草稿图、Canvas API 布局结构，或 Dot Skill 生成的结果。也可以只提供内容资料，由 Dot 完成适配设计。 |
| 碰一碰动作 | 可选择显示文本、打开网页、打开 Scheme URL 或打开 Universal Link。 |
| 设备或屏幕限制 | 如内容只适合特定设备、屏幕方向或画面比例，请提前说明；否则由 Dot 判断适配范围。 |
| 内容展示和使用限制 | 如有署名要求、缓存限制、二次分发限制、商用限制或地区限制，请提前说明。 |

## 内容获取方式

Dot 内容工坊可以通过以下方式接入内容。请在表单中选择最接近的内容提供方式，并在详细说明中补充必要信息。

| 方式 | 建议说明 |
| --- | --- |
| RSS | 提供 RSS 地址、更新频率、内容字段说明，以及是否需要特殊请求头。 |
| REST API | 提供 API 基础地址、认证方式、请求方法、参数、响应结构、错误格式和速率限制。 |
| OAuth 授权后的 API | 用户授权后，由 Dot 使用 Access Token 获取用户相关内容。需要提供 OAuth 参数和内容 API 说明。 |
| 直接提供数据内容 | 如果暂时没有在线接口，可以说明可提供的数据格式、更新方式和更新频率。 |

如果内容通过 RSS 或 REST API 获取，建议同时提供推荐缓存时间和最小抓取间隔，帮助 Dot 在内容新鲜度和请求压力之间取得平衡。

建议附上一份原始响应样例。REST API 可提供一次请求后得到的未修改完整 JSON；RSS 可提供一次未修改的完整 feed 响应。

## OAuth 认证资料

如果内容需要用户登录或授权，建议使用 OAuth 2.0 Authorization Code Flow。请准备以下资料；涉及 Client Secret 的内容应在接入确认后通过安全渠道提供。初次提交时可以说明已准备 Client Secret，不需要在表单说明中直接粘贴密钥。

| 资料 | 要求 |
| --- | --- |
| Client ID | OAuth 应用的公开客户端标识。 |
| Client Secret | OAuth 应用的客户端密钥。请说明是否需要服务端保密保存，以及是否支持轮换。 |
| Authorization URL | 用户授权页地址，以及需要的 query 参数。 |
| Token URL | 用于交换 Access Token 和 Refresh Token 的接口地址。 |
| Redirect URI 规则 | 说明是否需要提前登记 Redirect URI，以及登记数量、域名或 HTTPS 要求。 |
| Scope | 说明每个 Scope 的用途，以及读取内容所需的最小 Scope。 |
| Token 有效期 | 说明 Access Token 有效期、Refresh Token 有效期，以及是否支持刷新。 |
| 用户信息接口 | 如果需要展示账号标识，请提供用户信息接口和返回字段。 |
| 内容 API | 提供授权后读取内容的接口、请求方法、参数、响应结构和错误格式。 |
| 频率限制 | 说明授权、刷新 Token 和读取内容接口的速率限制。 |
| OAuth 展示图标 | PNG 透明背景，200 x 200 px，需要兼顾黑色背景和白色背景。 |

如果 OAuth 流程需要 PKCE、特殊签名、固定请求头、IP 白名单或额外安全校验，请在说明中一并写明。
