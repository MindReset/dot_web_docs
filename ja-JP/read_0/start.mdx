公式サンプルは Read Pico に付属する出荷時ファームウェアです。機能メニューからハードウェアを個別に確認でき、画面更新、操作、電源管理の実装を独自ファームウェアの参考にできます。

<GithubInfo owner="MindReset" repo="read_pico_firmware" />

## 基本操作

機能メニューは複数ページに分かれています。KEY1 と KEY3 は複数ページの画面でページを切り替え、KEY2 は GC16 による全画面更新を実行します。

## サンプルの内容

| ページ | 内容 |
| :--- | :--- |
| Overview | I2C デバイス検出、識別情報、電池と充電状態、ビルド日時 |
| EPD Refresh | 全画面 GC16、部分 DU、16 階調と高速 8 階調、更新時間 |
| Reading | 内蔵テキスト、DU / GL16 / GC16 でのページ切り替え、文字サイズ調整 |
| Touch | 2 点タッチ追従、指を離した後の全画面更新、ディープスリープと自動復帰 |
| Accel・IMU Lab | 3 軸、傾き、タップ回数、向き、サンプリング設定、セルフテスト |
| Power | 電池と充電状態、画面の電源レール、温度、障害情報 |
| PMU・Power Key | プロトコルの状態、イベント、設定、コマンド、キーイベント |
| Sleep | ライトスリープ、キーや持ち上げによる復帰、ディープスリープ、電源オフ |
| Storage | カード容量、マウント、再マウント、フォーマット、ブザー |
| Font | カード内の TTF フォントの一覧と切り替え、組版とウェイトの確認 |
| IOE・Device | IO レベルと割り込み、タッチリセット、デバイスの応答とコマンド確認 |

<Callout type="warn" title="カードのフォーマット">

フォーマットするとカード内のデータが消去されます。必要なファイルを先にバックアップしてください。

</Callout>
