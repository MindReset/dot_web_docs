---
title: コンテンツモード
description: Quote/0 の表示を循環コンテンツと固定コンテンツで整理する方法を説明します。
---

Quote/0 には、表示の仕方に合わせて選べる 2 つのコンテンツモードがあります。

循環コンテンツは順番に表示し続ける用途に、固定コンテンツは指定した時間帯に特定の内容を表示する用途に適しています。以下からモードを選び、設定方法と動作を確認してください。

<Cards>
	<Card href="/docs/quote_0/start/content_mode/loop" title="循環コンテンツ">
		リストの順番に従って表示を繰り返し、切り替え間隔を調整できます。
	</Card>
	<Card href="/docs/quote_0/start/content_mode/fixed" title="固定コンテンツ">
		指定した曜日や時間帯に特定の内容を表示できます。
	</Card>
</Cards>
