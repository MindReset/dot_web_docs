Quote/0 API 是一个基于 AWS Lambda 和 DynamoDB 的无服务器微服务。你可以通过受 Bearer Token 保护的 HTTP API 创建日程，服务会整合 Reading Council 的垃圾回收时间表，并通过官方 Quote/0 Text API 主动更新设备。

### 功能特性

- **主动推送**：Lambda 通过官方 Text API 更新 Quote/0，设备不需要回调该服务
- **日程管理**：支持创建单条日程或一次提交最多 100 条日程
- **垃圾回收集成**：获取 Reading Council 的垃圾回收信息并存入 DynamoDB
- **定时更新**：EventBridge 默认每天 01:10（UTC）触发同步与设备刷新
- **接口鉴权**：所有 HTTP 接口都需要 `Authorization: Bearer <API_AUTH_TOKEN>`
- **无服务器部署**：使用 API Gateway、Lambda、DynamoDB 与 EventBridge

### API

| 方法   | 路径                | 用途                                 |
| ------ | ------------------- | ------------------------------------ |
| `POST` | `/api/events`       | 创建一条日程并立即更新 Quote/0       |
| `POST` | `/api/events/batch` | 批量创建最多 100 条日程并更新 Quote/0 |

开发环境还提供 `POST /test/scheduled-update`，用于手动触发定时任务。

### 使用前准备

- 可部署 Lambda、API Gateway、DynamoDB 与 EventBridge 的 AWS 账号
- Node.js 18 或更高版本与 Serverless Framework
- Quote/0 Text API 地址与 Token
- 用于保护项目 HTTP API 的独立 Bearer Token
- Reading Council 地址对应的 UPRN

主要环境变量包括 `QUOTE0_TEXT_API`、`QUOTE0_AUTH_TOKEN`、`API_AUTH_TOKEN`、`UPRN` 和 `READING_API_URL`。

<Callout type="warn" title="适用范围与密钥">
  垃圾回收功能面向 Reading Council 服务区域，并依赖房产 UPRN。请将 UPRN、AWS
  凭证、Quote/0 Token 与 API Bearer Token 作为敏感信息管理，不要提交到仓库。
</Callout>
