---
title: 安装 CrossMux
description: 用电脑和 USB 数据线，跟着步骤为小纸 Pico 安装阅读固件。
---

为小纸 Pico 安装 CrossMux，让它成为一块阅读屏。安装过程称为「刷写」：把新的固件写入设备，不需要编写代码。

## 开始之前

准备一台电脑、桌面版 Chrome 或 Edge 浏览器，以及一根支持数据传输的 USB-C 数据线。

刷写会替换设备当前的固件，原有设置可能被清除。请先备份需要保留的内容，并保持设备电量充足。

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux 官网" />

<Steps>
<Step>

### 打开刷写页面

在电脑的 Chrome 或 Edge 中打开 [CrossMux 网页烧录器](https://crossmux.com/#flash-tools)，找到设备选择区域。

</Step>
<Step>

### 选择你的设备

选择 **小纸 Pico / Read Pico**，再按页面提示选择固件版本。

如果列表中还没有小纸 Pico，请先停止操作，等对应选项出现后再继续。不要选择其他机型的固件。

<CustomCloudImage osSrc="dot/docs/crossmux_2_1790759301829.png" alt="选择小纸 Pico" />

</Step>
<Step>

### 连接设备

用 USB 数据线把小纸 Pico 连接到电脑。在刷写页面发起连接，从浏览器弹出的设备列表中选择小纸 Pico 对应的 USB 串口，再确认连接。

如果不确定哪个是小纸 Pico，可先取消窗口，拔下设备，再重新连接，查看新增的设备。

{/* 截图：浏览器的串口选择窗口。 */}

</Step>
<Step>

### 开始安装

确认机型正确后，按页面提示开始刷写。如果页面要求确认擦除，请先确认需要保留的内容已经备份。

等待页面提示完成。期间不要拔掉数据线、关闭网页，或让电脑进入睡眠。

{/* 截图：刷写进度与完成提示。 */}

</Step>
<Step>

### 开始使用

刷写完成后，按页面提示重启设备。看到新固件的界面后，跟随屏幕提示完成初始设置。

如果设备没有自动重启，请在网页确认刷写完成后再手动重启。

{/* 截图：设备首次启动界面。 */}

</Step>
</Steps>

## 遇到问题

| 问题 | 处理方式 |
| --- | --- |
| 找不到设备 | 换一根支持数据传输的数据线，尝试另一个 USB 接口，并关闭占用设备的其他刷写工具。 |
| 浏览器无法连接 | 使用电脑上的 Chrome 或 Edge；手机浏览器和微信内置浏览器不适用于这套步骤。 |
| 刷写失败 | 检查连接，按刷写页面的提示重新连接并重试。如果页面要求进入下载模式，请按对应机型的说明操作。 |
| 完成后仍显示旧画面 | 墨水屏断电后会保留画面。重启设备，确认是否进入新固件。 |

需要恢复官方示例时，查看[DIY 你的系统](/docs/read_0/firmware)。

<Callout type="info" title="其他安装方式">

除了使用官网的网页烧录器，你也可以前往 [CrossMux 仓库](https://github.com/0x1abin/crossmux)，克隆或 Fork 源码后按仓库说明编译、刷写，或从 [Releases](https://github.com/0x1abin/crossmux/releases) 下载固件，按对应版本的说明安装。请选择明确支持小纸 Pico 的固件与安装方式。

</Callout>
