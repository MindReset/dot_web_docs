感谢 [Yana-Hangabina](https://github.com/Yana-Hangabina) 为小纸 Pico 提供系统。

脆皮鸭 CPYOS 是基于 [CrossMux](/docs/read_0/start/crossmux) 开发的阅读系统，将本地图书、晋江文学城和微信读书集中在同一书架中，并提供中文输入、阅读统计与自定义排版。

## 开始之前

准备电量充足的小纸 Pico、使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。关闭其他占用设备串口的网页、刷写工具或终端。

请准备 microSD 存储卡，用于保存书籍、字体与阅读数据。小纸 Pico 最大支持 512 GB，格式为 FAT32。

首次安装会重建分区表并擦除设备内部 Flash。请按官网说明，提前备份完整的 16 MiB Flash，并保存重要数据。网页安装不会删除 microSD 卡中的书籍与设置。

## 通过官网安装

<Steps>
<Step>

### 打开官网并选择安装方式

在电脑的 Chrome 或 Edge 中打开[脆皮鸭 CPYOS 官网](https://yana-hangabina.github.io/cpyos/)，进入「刷机」区域。

首次安装或从其他系统切换时，选择「首次安装 / 恢复」。已经运行 CPYOS 的设备可选择「从 CPYOS 升级」，保留设备设置与分区表。

</Step>
<Step>

### 连接设备并安装

用 USB 数据线连接小纸 Pico，点击对应安装按钮，在浏览器弹出的串口列表中选择设备。设备可能显示为 `USB JTAG/serial debug unit`。

首次安装时，确认备份完成后，按页面要求擦除并安装。保持 USB 连接、页面打开和电脑唤醒，等待写入完成及设备自动重启。

</Step>
<Step>

### 导入书籍并开始阅读

插入 microSD 卡后，从书架打开本地图书，或使用设备的浏览器传书功能导入内容。阅读器支持 EPUB、TXT、CBZ 和 FB2。

可从存储卡导入 TTF、OTF、TTC 字体，也可以使用 EPUB 内嵌字体，并为不同书籍单独选择字体。

使用晋江文学城或微信读书时，先连接 Wi-Fi，再按设备上的对应入口登录账号、浏览书架与获取书籍。微信读书支持扫码登录，下载后可离线阅读。

</Step>
</Steps>

## 主要功能

### 统一书架与在线阅读

首页提供继续阅读、最近阅读、近七天阅读记录和晋江更新。书架集中展示本地图书、晋江与微信读书书籍，并用来源标识区分。

晋江文学城支持书架、发现、书籍与作者搜索、收藏夹、章节购买、段评互动和阅读进度同步。微信读书支持书架浏览、下载 EPUB 离线阅读与进度同步。

晋江文学城与微信读书为非官方适配，内容可用范围取决于账号权限和服务接口。

### 中文输入与阅读排版

支持离线拼音输入、书名搜索、断词与中文回退字体。可以调整字体、字号和阅读版式，并使用书签、批注、词典与阅读统计。

### 翻页与显示

提供水波纹翻页、黑白快速翻页和屏幕残影清理。除触控操作外，也可以倾斜或左右摇晃设备翻页。

## 连接与更新

可通过浏览器传书与调整设置，也支持 WebDAV、OPDS 和 Calibre 无线连接。

已经安装 CPYOS 时，连接 Wi-Fi 后，打开「设置 → 系统 → 检查更新」进行 OTA 更新；也可按官网说明使用存储卡更新。更新期间保持供电，等待设备重启。从其他系统首次切换时，请使用官网的完整安装方式。

## 其他安装方式

你也可以从仓库 Releases 下载完整安装包，按包内的 `FLASH.md` 与 `SHA256SUMS` 完成离线安装与校验，或克隆、Fork 仓库后自行构建和刷写。首次安装需要完整安装包，不能仅使用应用镜像。
