quote0-desk は、Quote/0 を一方向の表示パネルから NFC で操作できるデスクデバイスへ拡張します。表示中のコンテンツカードにスマートフォンをタップすると、ローカルサービスが対応する操作を実行し、新しい結果をすぐに画面へ送信します。すべて公式の Text API と Image API を使用し、ファームウェアの書き換えや変更は行いません。

<CustomCloudImage osSrc="dot/docs/dashboard_1786093380914.png" alt="Quote/0 のデバイス状態と用途別コンテンツカードを表示する quote0-desk ローカルコンソール" className="mx-auto w-full max-w-xl rounded-xl object-contain" />

### 主な機能

- **NFC 操作の閉ループ**：タップしてデスクトップペットをなでる、箴言を切り替える、今日のタスクを完了する、ポモドーロを開始する、占い結果を生成するなどの操作に対応
- **16 種類のコンテンツカード**：デスクトップペット、六爻、奇門遁甲、日課、箴言、タスク、集中時間、ステータスボード、Claude Code 使用量、Hermes メッセージ、壁紙などを収録
- **ローカル Web コンソール**：デバイス状態と現在の画面を確認し、カードごとのプレビューや送信、NFC アドレス、自動切り替えを設定
- **バックグラウンド常駐**：macOS ではサービスと Cloudflare Tunnel を LaunchAgent として登録し、異常終了後の再起動とトンネルアドレスの更新を自動化
- **Claude と Agent 向けツール**：独立した MCP Server からカード固有の操作を呼び出し、buddy-bridge や Hermes Agent とも任意で連携
- **公式 API のみを使用**：Dot が公開するデバイス状態、Loop、Text API、Image API のみを利用し、ファームウェアにはアクセスしません

### 事前準備

- Python 3.9 以降と `requirements.txt` の依存パッケージ
- Dot API Key と接続済みの Quote/0。アカウントにデバイスが 1 台だけの場合は ID を自動検出可能
- Dot App コンテンツ工房のデバイス Loop に追加した Text API と Image API コンテンツ
- スマートフォンから到達できるコールバックアドレス。同じ LAN のアドレス、または Cloudflare Tunnel を利用可能

依存パッケージをインストールして `DOT_API_KEY` を設定したら、`python3 cli.py hello` で送信を確認し、`python3 server.py` でサービスを起動します。Web コンソールは既定で `http://localhost:5252` から開けます。`NFC_BASE_URL` を設定すると、対応カードの NFC リンクにコールバックアドレスが保存されます。

<Callout type="info" title="ローカルデータと任意の連携">
  タイムカプセル、ペットの活動状態、トレーディングビーコンは、ローカルにある別プロジェクトのデータを読み取ります。既定パスは作者の環境向けなので、自分のデータソースへ変更してください。データがない場合は未取得として表示されます。buddy-bridge、Hermes
  Agent、MCP Server は任意であり、基本カードと NFC コンソールの動作には影響しません。
</Callout>
