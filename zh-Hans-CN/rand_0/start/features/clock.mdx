## 时钟

时钟用于显示日期、时间与星期。

-   显示日期、时间、星期。
-   如果时间未校准，设备会先显示提示，然后引导你完成 Wi-Fi 校时。
-   首次使用时，设备可能会显示耗电提示，按任意键即可继续。

## 操作

1. 长按下键进入。
2. 查看当前日期、时间与星期。
3. 如设备提示需要校时，请按照提示完成 Wi-Fi 校时；长按上键可以取消并返回菜单。
4. 长按上键返回主界面。

时钟会持续显示并在时间变化时刷新。与普通锁屏相比，时钟模式会消耗更多待机电量，但不会按普通休眠时长自动锁屏。
