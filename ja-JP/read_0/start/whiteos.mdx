## はじめる前に

<CustomCloudImage osSrc="dot/docs/whiteos_0_1791539395253.png" alt="WhiteOS 公式サイトと読書画面のイメージ" />

インストールには、十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルが必要です。ローカル書籍やフォントを保存する microSD カードは別途用意してください。Read Pico は最大 512 GB に対応し、フォーマットは FAT32 です。

## 公式サイトからインストールする

[WhiteOS 公式サイト](https://446599.github.io/whiteos/)から[インストールページ](https://446599.github.io/whiteos/install/)を開きます。ページでは次の二つの方法が紹介されています。

- **全新烧录**（新規インストール）：初回のインストール用です。起動プログラム、パーティションテーブル、システムアプリケーションを書き込みます。残したいファイルと読書記録を保存し、ページのデータに関する説明を確認してください。
- **固件更新**（システム更新）：対応する WhiteOS がインストール済みの場合に、アプリケーションのみを更新します。パーティション構成に互換性がない場合は更新を停止します。

## 読書と学習

以下の機能と操作は公式サイトの紹介に基づきます。利用できる範囲は公開版で確認してください。

### 微信読書

微信読書の本棚を表示し、書籍をダウンロードできます。読書進捗の同期は手動で確認します。端末からクラウドへの進捗と読書時間のアップロードは、現在利用できることが確認されていません。注釈はクラウドと同期しません。WhiteOS の微信読書連携は非公式です。利用権限のあるコンテンツのみ使用してください。

### ローカル読書とレイアウト

Wi-Fi の転送ページや USB ストレージでファイルをコピーし、ローカルの EPUB と PDF を読めます。保存した書籍の読書には常時接続は不要です。

本文の中央をタップするか中央のキーを押すと、読書メニューが開きます。フォント、文字サイズ、行間、余白を調整したり、目次、しおり、読書進捗を確認したりできます。項目はファイル形式によって異なります。

二本の指を広げる、または近づけると表示サイズが変わります。EPUB と TXT は文字サイズ、PDF はページの倍率を調整します。TTF または OTF のフォントファイルをカードにコピーし、レイアウトメニューで選択できます。事前のフォント変換は不要です。

### Anki 学習

旧形式の `.apkg` デッキを取り込み、一問一答、穴埋め、静的な選択問題をオフラインで復習できます。四段階の評価と毎日の復習計画、一般的な画像に対応しています。以前の復習履歴は移行されず、AnkiWeb とも連携しません。複雑なスクリプト、音声、動画を含むテンプレートは対象外です。
