## デバイスを更新

開始前に、Rand/0 に利用可能な Wi-Fi が記憶されていて、バッテリー残量が十分であることを確認してください。残量が少ない場合は電源へ接続します。

1. Rand/0 で **SETUP** を開きます。
2. **System Version** を選びます。
3. 下ボタンを長押しして Wi-Fi OTA に入ります。
4. 更新が完了するまで待ち、再起動を求められたら下ボタンを押します。

更新には記憶済み Wi-Fi を使用します。更新中はネットワークを利用できる状態に保ち、Rand/0 の電源を切らないでください。

## Wi-Fi を追加または変更する

記憶済みネットワークがない場合、または別のネットワークを使う場合：

1. **SETUP** → **Wi-Fi** → **Connect** を開きます。
2. Wi-Fi の設定と時刻同期を完了します。詳しくは [Wi-Fi](/docs/rand_0/start/wifi) を参照してください。
3. **System Version** に戻り、下ボタンを長押しして更新を開始します。
