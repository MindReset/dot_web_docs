QuotaFrame turns Read Pico into an AI coding usage display for your desk. See Codex and Claude usage percentages and quota reset countdowns on the e-ink screen, without switching windows to check your limits.

Visit the [QuotaFrame website](https://quotaframe.com/) for setup instructions. Select **MindReset Read Pico** and install through desktop Chrome or Edge.

### Features

- **Usage overview**: View Codex and Claude short-term and weekly usage together, with reset countdowns for each.
- **Bluetooth sync**: QuotaFrame Bridge updates usage automatically from your computer. The screen retains the last received data when disconnected.
- **Usage trends**: Track changes in usage. Trend recording requires a microSD card.
- **Read Pico controls**: Use the touchscreen and three touch keys, with a clock, four-way automatic rotation, and on-screen settings.

### Before you start

Install the QuotaFrame system for Read Pico and run QuotaFrame Bridge on your computer. Bridge is available for Windows and macOS; macOS requires version 14 or later and an Apple Silicon Mac.

Usage comes from CodexBar on macOS or Win-CodexBar on Windows. Set up your accounts and confirm that usage can be retrieved. Keep the computer and Bridge running to receive updates.

Download Bridge from the [repository's Releases page](https://github.com/eMUQI/QuotaFrame/releases).
