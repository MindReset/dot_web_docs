InkCanvas は ESP32-C3 電子ペーパーデバイス向けのブラウザベース編集・送信システムです。USB Web Serial で接続すると、Chrome または Edge からファームウェアのバックアップと書き込み、画面編集、単一フレームまたは複数ページのプレイリスト送信を行えます。デスクトップアプリのインストールは不要です。

### 主な機能

- **初回バックアップ**：第三者製ファームウェアを入れる前に 4 MB Flash を読み出して保存
- **ビジュアル編集**：テキスト、画像、長方形、区切り線を追加し、ピクセル単位で移動・拡大縮小
- **複数ページ再生**：ページごとに表示時間を設定
- **モノクロ調整**：しきい値と Bayer ディザリング、反転、180° 回転に対応
- **USB と Wi-Fi 送信**：Web Serial で直接送信するほか、Wi-Fi / AP モードの HTTP API を提供
- **プロジェクト移行**：画面プロジェクト全体を JSON で入出力

<Callout type="warn" title="ブラウザとファームウェアの制限">
  全機能にはデスクトップ版 Chrome 90+ または Edge 90+
  が必要です。Firefox と Safari は Web Serial
  に対応していません。第三者製ファームウェアを書き込むため、先に Flash
  をバックアップし、ESP32-C3、UC8251D、4 MB Flash
  の条件を確認してください。電子ペーパーの全画面更新には数秒かかり、連続動画には適しません。
</Callout>
