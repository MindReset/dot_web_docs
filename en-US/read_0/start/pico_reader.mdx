## Before you start

<CustomCloudImage osSrc="dot/docs/kiiko_1_1791023749070.png" alt="kiikoread web installation guide" />

Prepare the following:

- A Read Pico with sufficient charge
- A computer running desktop Chrome or Edge
- A USB-C cable that supports data transfer. A charge-only cable cannot flash the device.

<CustomCloudImage osSrc="dot/docs/kiiko_2_1791023749071.png" alt="Prepare Read Pico, a browser, and a USB-C data cable" />

<Steps>
<Step>

### Open the flashing page

Open the [kiikoread website](https://wegooo-cell.github.io/read-pico-reader/) in Chrome or Edge on your computer and find **连接 Pico，开始刷机** (Connect Pico and start flashing). The website installs the system version supplied by the project. Check the page for the exact version number.

</Step>
<Step>

### Connect the device and select its serial port

Connect Read Pico to your computer with the USB data cable, then click **连接 Pico，开始刷机**.

In the browser's serial port picker, select the port for Read Pico and click **Connect**. If you are unsure which entry to use, cancel the picker, unplug and reconnect the device, and look for the newly added port.

</Step>
<Step>

### Confirm installation

<Callout type="warn" title="Device data">

On first installation, the confirmation dialog states **All data on the device will be erased.** Installation erases the device's internal data, including the previous system's settings and reading records. Back up any data you want to keep before confirming installation. Book files on the microSD card are not deleted by flashing.

</Callout>

Once connected, select the **Install** option for Read Pico in the installer dialog. On the **Confirm Installation** screen, read the data erasure warning, then click **Install** to begin.

<CustomCloudImage osSrc="dot/docs/kiiko_3_1791023749072.png" alt="Connect Pico, select its serial port, and confirm installation" />

</Step>
<Step>

### Wait for installation to finish

Progress is shown during installation. Keep USB connected and the page open. Do not unplug the cable or let your computer go to sleep.

Wait for **Installation complete!**, then click **Next** to finish. The device restarts. If it does not start, unplug and reconnect USB, then turn it on with the power key.

</Step>
<Step>

### Start reading

No books are included with the system. When the microSD card is first mounted, the system creates the `books`, `fonts`, and `pictures` folders as needed.

Put EPUB or TXT books in `books`, then open them from the device's bookshelf. You can also manage files using the system's Wi-Fi, device hotspot, or USB book transfer features.

</Step>
</Steps>
