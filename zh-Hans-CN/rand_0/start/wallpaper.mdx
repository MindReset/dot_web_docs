## 自定义壁纸

1. 至少完成一次 [Wi-Fi 校时](/docs/rand_0/start/wifi)，让设备记住可用网络。
2. 打开 **设定**，选择 **更换壁纸**。
3. 设备会自动连接已记忆的 Wi-Fi 并显示二维码，使用手机扫描二维码。
4. 在手机浏览器页面中选择 PNG 或 JPG 图片，生成预览后保存到 Rand/0。
5. 壁纸保存成功后，设备会自动返回主页面。

壁纸页面也支持恢复内置壁纸。

如果还没有保存就想退出，长按上键返回。

在主菜单长按上键即可快速锁屏并显示当前壁纸，也可以进入 **设定** → **立即锁屏**。

图片格式仅支持 **jpg**、**jpeg**、**png**，体积不大于 **5 MB**。

更换壁纸需要已有可用的 Wi-Fi 记忆。如果设备电量过低，请先接入电源。
