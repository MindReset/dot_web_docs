Read Pico 向けに Pico Reader 読書システムを開発・公開してくださった [Kiiko厂长](https://github.com/wegooo-cell) さんに感謝します。

## はじめる前に

<CustomCloudImage osSrc="dot/docs/kiiko_1_1791023749070.png" alt="Pico Reader の Web インストールガイド" />

次のものを用意してください。

- 十分に充電した Read Pico
- デスクトップ版 Chrome または Edge を使えるパソコン
- データ転送に対応した USB-C ケーブル。充電専用のケーブルでは書き込めません。

<CustomCloudImage osSrc="dot/docs/kiiko_2_1791023749071.png" alt="Read Pico、ブラウザ、USB-C データケーブルの準備" />

<Steps>
<Step>

### 書き込みページを開く

パソコンの Chrome または Edge で [Pico Reader 公式サイト](https://wegooo-cell.github.io/read-pico-reader/)を開き、「连接 Pico，开始刷机」（Pico に接続して書き込みを開始）のボタンを探します。サイトからはプロジェクトが提供するバージョンのシステムがインストールされます。具体的なバージョン番号はページで確認してください。

</Step>
<Step>

### 端末を接続してシリアルポートを選ぶ

USB データケーブルで Read Pico をパソコンに接続し、「连接 Pico，开始刷机」を押します。

ブラウザのシリアルポート一覧で Read Pico に対応するポートを選び、「接続」を押してください。どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示されるポートを確認します。

</Step>
<Step>

### インストールを確認する

<Callout type="warn" title="端末内のデータ">

初回インストール時の確認画面には **All data on the device will be erased.** と表示されます。インストールによって端末の内部データが消去され、以前のシステムの設定や読書記録も失われます。残したいデータを先にバックアップしてから、インストールを確認してください。microSD カード内の書籍ファイルは、書き込みによって削除されません。

</Callout>

接続できたら、インストールのダイアログで Read Pico の **Install** を選びます。**Confirm Installation** の確認画面でデータ消去の案内を読んでから、**Install** を押して開始してください。

<CustomCloudImage osSrc="dot/docs/kiiko_3_1791023749072.png" alt="Pico に接続し、シリアルポートを選んでインストールを確認" />

</Step>
<Step>

### 完了するまで待つ

インストール中は進捗が表示されます。USB 接続とページを開いた状態を保ち、ケーブルを抜いたり、パソコンをスリープさせたりしないでください。

**Installation complete!** と表示されたら、**Next** を押して終了します。端末は再起動します。起動しない場合は USB を抜き差しし、電源キーで起動してください。

</Step>
<Step>

### 読書をはじめる

システムには書籍が含まれていません。microSD カードを初めてマウントすると、必要に応じて `books`、`fonts`、`pictures` フォルダーが作成されます。

EPUB または TXT の書籍を `books` に入れ、端末の本棚から開いてください。システムの Wi-Fi、端末のアクセスポイント、USB による書籍転送機能でファイルを管理することもできます。

</Step>
</Steps>
