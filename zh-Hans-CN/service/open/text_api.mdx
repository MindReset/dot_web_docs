## 快速指引

### 必要条件

1. 确保您已在 Dot. App 中<Link href="/docs/service/studio/api/get_api">获取并保存了 API 密钥</Link>；
2. 确保您至少有一台所属于自己的设备并已<Link href="/docs/service/studio/api/get_device_id">获取设备序列号</Link>；
3. 确保您的设备已接入电源；
4. 确保您的设备已接入网络；
5. 确保已从 Dot. App 内容工坊中添加 `文本 API` 内容到设备的**循环列表或固定列表**中。

<Callout type="info" title="文本 API 的用途">
	文本 API 适合把提醒、灵感、签名和小图标组合成一张适合设备阅读的文字卡片。您可以用它发送自动化消息、轻量通知、每日摘录或需要立即看到的一段文本。
</Callout>

<Callout type="info" title="选择内容列表与显示时机">
	可选择循环列表或固定列表，省略时使用循环列表。任务唯一标识只在所选列表中查找；省略时更新该列表中的第一个同类 API 内容，不会查找其他列表。

	立即显示设置仅对循环内容有效：开启时请求立即显示，关闭时仅保存。设备需要在线；电池供电且睡眠时，内容先保存，待设备自动唤醒后获取。固定内容始终按 App 中设置的时间显示，即使当前正在显示该固定内容，也要等下一次计划刷新。API 不改变固定内容的时间设置。详见<Link href="/docs/quote_0/faq/refresh_timing">时间机制</Link>。
</Callout>

<Callout type="info" title="关于图标输入">
	图标为可选内容，可使用 PNG Base64 数据或完整的在线 `http(s)` 图片 URL。PNG Base64 可传裸 Base64，也可带 `data:image/png;base64,` 前缀，解码后最大 1MB，建议使用 40px×40px 小图标。远程图标链接必须可匿名访问、无需鉴权或特殊 Referer，URL 长度不超过 2048 个字符，响应体最大 3MB，并直接返回 `image/*` 内容。
</Callout>

<Callout type="info" title="可用于调试的测试图标链接">
	以下链接当前可直接匿名访问，并返回可用于 Text API `icon` 的图片内容：

	- `https://placehold.co/40x40/png`
	- `https://httpbin.org/image/png`

	如果您想先验证自己的图标链接是否可用，可以先执行：

	```bash
	curl -I 'https://your-icon-url'
	```

	通常需要确认响应中至少满足两点：

	- HTTP 状态码为 `200`
	- `Content-Type` 为 `image/*`，例如 `image/png` 或 `image/jpeg`
</Callout>

### 更新固定列表中的内容

先查询固定列表，从返回数组中找到 `TEXT_API` 内容，并将它的 `key` 作为 `taskKey`：

```bash
curl 'https://dot.mindreset.tech/api/authV2/open/device/{{deviceId}}/fixed/list' \
  -H 'Authorization: Bearer dot_app_{{apiKey}}'
```

再调用同一接口，在请求顶层传入 `taskType: "fixed"` 和该 `taskKey`。以下请求只保存内容，`refreshNow: true` 不会提前显示或刷新固定内容：

```bash
curl -X POST 'https://dot.mindreset.tech/api/authV2/open/device/{{deviceId}}/text' \
  -H 'Authorization: Bearer dot_app_{{apiKey}}' \
  -H 'Content-Type: application/json' \
  -d '{
  "taskType": "fixed",
  "taskKey": "{{taskKey}}",
  "refreshNow": true,
  "title": "今日提醒",
  "message": "会议改到 10:30。"
}'
```

### 文本中的换行与制表符

Text API 会保留 `message` 中的换行和制表符。

- 在 JSON 请求体中，使用 `\n` 表示换行，使用 `\t` 表示制表符。
- 如果您的 JSON 外面还包了一层 shell、JavaScript、Python、模板引擎或工具配置字符串，通常需要在外层写成 `\\n` 和 `\\t`，让最终发出的 JSON 仍然包含 `\n` 和 `\t`。
- 如果您希望设备显示字面量字符 `\n` 或 `\t`，请让最终 JSON 载荷中包含 `\\n` 或 `\\t`。

```json
{ "message": "第一行\n\t缩进后的第二行" }
{ "message": "显示字面量 \\n 和 \\t" }
```

### 响应结构

### 响应说明

| HTTP 状态码 | 含义             | 描述                                           |
| ----------- | ---------------- | ---------------------------------------------- |
| `200`       | 成功             | 设备文本 API 内容已切换/数据已更新但未切换内容 |
| `400`       | 参数错误         | 内容列表类型无效<br/>无效的图标格式 |
| `403`       | 权限不足         | 您没有权限操作此设备                           |
| `404`       | 设备或内容不存在 | 设备不存在或未注册<br/>所选列表中未添加对应 API 内容，或任务唯一标识与该列表中的对应 API 内容不符 |
| `500`       | 设备响应失败     | 设备文本 API 内容切换失败                      |

### 列表与显示时机排查

- `400`：确认 `taskType` 只使用 `loop` 或 `fixed`。
- `404`：确认请求的 `taskType` 与查询列表一致，且 `taskKey` 来自该列表中的对应 API 内容；省略 `taskType` 会查询循环列表。
- 固定内容已保存但画面未变化：检查 App 中的时间设置，并等待下一次计划刷新；`refreshNow: true` 不会触发固定内容立即刷新。
