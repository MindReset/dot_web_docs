感谢 [一凡可回收](https://github.com/yiifanrecyclable) 为小纸 Pico 提供系统。

if-ink OS 基于 [kiikoread](/docs/read_0/start/kiikoread) 开发，保留 EPUB 与 TXT 阅读，并增加 Markdown 文档阅读、坚果云下载和首页个性化功能。

## 开始之前

准备电量充足的小纸 Pico、使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。关闭其他占用设备串口的网页、刷写工具或终端。

请准备 microSD 存储卡，最大支持 512 GB，格式为 FAT32。

## 通过官网安装

<Steps>
<Step>

### 打开官网

在电脑的 Chrome 或 Edge 中打开 [if-ink OS 官网](https://yiifanrecyclable.github.io/if-ink-OS/)，进入[在线刷机页面](https://yiifanrecyclable.github.io/if-ink-OS/#install)。

</Step>
<Step>

### 连接设备并安装

用 USB 数据线将小纸 Pico 连接到电脑，按官网教程选择设备和版本并完成安装。网页安装无需自行安装 Python 或 esptool。

刷写会替换设备当前的系统，请先备份需要保留的数据。从其他系统迁移时，内部设置与阅读记录不保证兼容。保持 USB 连接、页面打开和电脑唤醒，等待刷写完成。

</Step>
<Step>

### 放入书籍、文档和字体

在 microSD 卡中，将 EPUB 与 TXT 放入 `books`，Markdown 放入 `markdown`，字体放入 `fonts`。首次安装时，可在项目下载页获取字体与拼音词库资源包。

</Step>
</Steps>

## 主要功能

本页图片为项目提供的模拟器运行画面与设备外观合成展示图，阅读数据为演示数据。实际墨水屏灰度与刷新效果以实机为准。

### 首页与个性化

首页支持自定义 Banner 背景、日期与文字，显示阅读记录热力图、每日或每周阅读时长，以及左右分栏的最近阅读。可以调整系统字号、字体，并使用锁屏壁纸轮播。

### 图书与 Markdown 文档

支持 EPUB、TXT 和 Markdown 离线阅读。Markdown 支持标准管道表格、标题字号、粗体、斜体与高亮。

通过阅读控制面板访问目录、书签、字体与版式，可按需配置快捷手势，保留逐书阅读进度。

### 坚果云下载与 Obsidian 推送

系统可以读取指定 WebDAV 文件夹中的 MD、TXT 与 EPUB 列表，按需下载到 microSD 卡。

在「设置 → 坚果云同步」填写账号、应用密码和坚果云根目录下已存在的同步文件夹，再进入坚果云同步页选择文件下载。应用密码需在坚果云的第三方应用管理中生成。

配套的 Sent to E-ink Reader 插件可从 Obsidian 将选中的笔记手动推送到坚果云指定文件夹，再由设备下载。插件需单独安装，推送内容为 Markdown 纯文本，图片与笔记嵌入转为文字说明，不会持续自动同步笔记。

### 传输与维护

支持 Wi-Fi 与热点传书、USB 连接、Wi-Fi 密码记忆，以及设置备份与恢复。

## 其他安装方式

除了通过官网安装，也可以从系统仓库的 Releases 获取正式系统、microSD 卡升级包、离线刷机包及对应源码。安装与升级要求请以[仓库安装说明](https://github.com/yiifanrecyclable/if-ink-OS/blob/main/docs/%E5%AE%89%E8%A3%85%E8%AF%B4%E6%98%8E.md)和所选版本说明为准。

已安装兼容版本的用户，可按说明使用 microSD 卡升级包，或在「设置 → 固件信息 → 在线升级」检查新版本。
