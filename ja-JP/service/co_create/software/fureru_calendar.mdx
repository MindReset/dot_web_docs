ふれるカレンダーは、1 つ以上の公開 iCal から予定を読み取り、今日と次に予定がある日の内容を Quote/0 向けの画像に変換し、Dot Image API でデバイスを更新します。玄関やデスクなど、直近の予定をひと目で確認したい場所に向いています。

### 主な機能

- **直近の予定に集中**：今日と、次に予定がある日の内容だけを表示
- **複数カレンダー**：カンマ区切りで複数の公開 iCal URL を指定可能
- **画像の自動生成**：予定を解析し、Quote/0 向けの PNG に変換
- **定期更新**：cron を使って決まった時刻に生成と送信を実行
- **ローカル診断**：デバイス一覧の取得と手動送信のコマンドを用意

### 事前準備

- Python 3.12
- 1 つ以上の公開 iCal URL
- Dot API Token と Quote/0 のデバイス ID
- Python スクリプトを定期実行できるホスト。リポジトリには Linux と cron の配置例があります

`.env` で `ICAL_URLS`、`DOT_API_TOKEN`、`DOT_DEVICE_ID` を設定します。参考構成は毎日 00:00（JST）に実行されます。利用地域に合わせてホストのタイムゾーンと cron を調整してください。

<Callout type="warn" title="カレンダーのプライバシー">
  このプロジェクトは公開 iCal URL を読み取ります。URL
  を知っている人は予定を閲覧できる可能性があります。表示してもよい情報だけを含む専用カレンダーを使い、URL
  を適切に管理してください。
</Callout>
