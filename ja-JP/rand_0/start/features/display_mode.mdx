## 表示モード

表示モードでは、同じローカルネットワーク上の対応ツールから Rand/0 の電子ペーパーにカスタム画面を送信できます。画面サイズは `200 × 200` ピクセルで、白黒と 4 階調の画像に対応しています。

<Callout type="warn" title="使用前の注意">
表示モードはローカルネットワーク内でのみ利用でき、追加のログイン認証はありません。信頼できる Wi-Fi ネットワークでのみ使用し、機密情報を送信しないでください。
</Callout>

## 使用前の準備

次のことを確認してください。

1. [Wi-Fi 時刻同期](/docs/rand_0/start/wifi)を一度完了し、Rand/0 に利用可能な Wi-Fi を記憶させます。
2. 端末のバッテリーが十分にある、または電源に接続されていること。バッテリー残量が少ない場合、表示モードは起動しません。
3. 画面を送信するスマートフォンまたはコンピューターが、Rand/0 と同じローカルネットワークに接続されていること。
4. Rand/0 の表示モードに対応したツールを用意していること。

## 表示モードに入る

初期状態では、次の場所から入ります。

- メインメニュー → **More** → **Display** → 確定

ホーム画面を変更している場合は、現在のホーム画面に配置した **Display** を開きます。

Rand/0 は再起動し、記憶済みの Wi-Fi に自動接続します。接続に成功すると、画面中央に端末の IP アドレスが表示されます。

準備完了画面には、この表示モードガイドを開く QR コードも表示されます。接続方法やプロトコルを確認するときに読み取ってください。

## 接続して画面を送る

1. Rand/0 の表示モードに対応したツールを開きます。
2. 端末に表示された IP アドレスを入力し、接続を開始します。
3. ツールの案内に従って画像を選び、Rand/0 に送信します。

同時に接続できるツールは 1 つだけです。新しい接続が確立すると、以前の接続は自動的に切断されます。

<Callout type="info" title="接続ツールについて">
表示モードは、ローカルネットワーク経由で Rand/0 が画面を受信できるようにします。接続と画面の送信には対応ツールが必要で、具体的な操作方法はツールによって異なる場合があります。
</Callout>

<Callout type="info" title="公式サンプル">
GitHub の[公式 Rand/0 表示モードサンプル](https://github.com/MindReset/dot_open_platform/tree/main/capabilities/rand_0_display_mode)を利用できます。追加の依存関係なしで、ブラウザから画像を送信し、端末のボタンイベントを受信できます。
</Callout>

## ボタン操作

| 操作 | 結果 |
| --- | --- |
| 上ボタンまたは下ボタンを短押し | 現在接続しているツールに対応するボタンイベントを送信します。 |
| 上ボタンを長押し | 表示モードを終了し、Rand/0 を再起動して通常モードに戻ります。 |

電子ペーパーは更新速度が遅いため、静止画の表示に適しています。画像を連続して送信した場合、Rand/0 は最新の画像だけを保持し、途中の画像は表示されないことがあります。

表示モードを終了すると、Rand/0 は通常モードに戻ります。端末が予期せずリセットされた場合も、表示モードに自動で入り直すことはありません。

## 対応ツール向けプロトコル

表示モードは、端末のローカル IP アドレス上で次の WebSocket エンドポイントを提供します。

| エンドポイント | バイナリフレーム | 形式 |
| --- | ---: | --- |
| `ws://<IP>/display/bw` | 正確に 5,000 バイト | 1 ピクセル 1 bit、白黒 |
| `ws://<IP>/display/gray4` | 正確に 10,000 バイト | 1 ピクセル 2 bit、4 階調 |

画像ごとに 1 つのバイナリフレームを送信します。ピクセルは左から右、上から下の行順で並び、高位ビットが左端のピクセルを表します。白黒モードでは `1` が白、`0` が黒です。4 階調モードでは `00` が白、`01` が薄いグレー、`10` が濃いグレー、`11` が黒です。

同時にアクティブにできるクライアントは 1 つだけです。新しい接続が以前の接続を置き換えます。画像の送信が画面の更新より速い場合、端末は最新のフレームだけを保持します。

端末はボタンイベントとエラーをテキスト JSON で送信します。例：

```json
{"type":"key","key":"up","action":"short"}
```

バイナリ形式または長さが正しくない場合は、`expected_binary_5000` や `expected_binary_10000` などのエラーが返ります。

## よく表示されるメッセージ

| 画面の表示 | 対処方法 |
| --- | --- |
| 電源を接続してください | 電源に接続してから再試行するか、バッテリーが十分に充電されるまで待ちます。 |
| 記憶済み Wi-Fi がありません | [Wi-Fi 時刻同期](/docs/rand_0/start/wifi)を一度完了し、端末に利用可能なネットワークを記憶させます。 |
| Wi-Fi 接続失敗 / IP アドレスを取得できません | 記憶済みの Wi-Fi が利用できるか、端末が Wi-Fi の通信範囲内にあるかを確認します。 |
| WebSocket の起動に失敗しました | 表示モードを終了して端末を再起動し、もう一度表示モードに入ります。 |
