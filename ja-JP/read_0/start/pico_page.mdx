Read Pico 向けにシステムを提供してくださった [eMUQI](https://github.com/eMUQI) に感謝します。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。端末のシリアルポートを使用しているほかのページ、書き込みツール、ターミナルを閉じます。

最大 512 GB、FAT32 形式の microSD カードを用意してください。

<Steps>
<Step>

### インストールページを開く

[Pico Page 公式サイト](https://picopage.wulu.zone/)の「安装固件」（システムをインストール）から[インストールページ](https://picopage.wulu.zone/install/)を開き、案内を読んでください。

</Step>
<Step>

### 接続してインストールする

USB で Read Pico を接続します。「连接设备」（端末を接続）を押し、ブラウザの一覧からシリアルポートを選びます。「我确认连接的是 Read Pico」（接続した端末が Read Pico であることを確認）にチェックし、「安装 Pico Page」（Pico Page をインストール）を押します。

端末のフラッシュ全体が上書きされ、既存のシステムや Wi-Fi などの内部設定は消去されます。microSD カードの書籍には影響しません。フラッシュ暗号化またはセキュアブートが有効な端末への書き込みは拒否されます。

USB 接続とページを開いた状態を保ち、パソコンをスリープさせないでください。完了後、端末が再起動して本棚を表示するまで待ちます。

</Step>
<Step>

### 書籍とフォントを追加する

microSD カードの `Books/` に EPUB と TXT を、`Fonts/` に中国語対応の TTF または OTF フォントとライセンスをコピーします。内蔵の文字セットは限られているため、文字が四角く表示される場合は完全な中国語フォントを使用してください。

カードを戻して端末を再起動し、本を開きます。本文中央をタップし、「排版」（組版）でフォントを選びます。詳しくは[公式サイトのドキュメント](https://picopage.wulu.zone/docs/)をご覧ください。

</Step>
</Steps>
