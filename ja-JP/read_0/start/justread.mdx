Read Pico 向けにシステムを提供してくださった Algorithnm & 酷丁 に感謝します。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。端末のシリアルポートを使用しているほかのページ、書き込みツール、ターミナルを閉じます。

初回起動にはシステムフォントが必要です。microSD カードを用意し、端末に挿入してください。Read Pico は最大 512 GB のカードに対応し、FAT32 形式を使用します。

インストールすると現在のシステムが置き換わり、設定が消去される場合があります。残したいデータを先に保存し、インストール画面の案内を読んでください。

<Steps>
<Step>

### 公式サイトを開く

パソコンの Chrome または Edge で [Just Read 公式サイト](https://flasher.smn.icu/)を開きます。

</Step>
<Step>

### 端末を接続する

USB データケーブルで Read Pico をパソコンに接続し、「设备」（端末）の選択ボタンを押します。ブラウザの一覧で Read Pico のシリアルポートを選び、「接続」を押してください。

どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示されるポートを確認してください。

</Step>
<Step>

### システムを選んで書き込む

「固件」（システム）の一覧から Just Read のバージョンを選びます。画像では **V0.0.1 Dongting** が表示されています。現在のバージョンはサイトで確認してください。「MindReset 原厂固件」（MindReset 出荷時システム）は別の選択肢です。

「开始刷入」（書き込みを開始）を押し、ページの案内に従ってインストールします。USB 接続とページを開いた状態を保ち、ケーブルを抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。

</Step>
<Step>

### 初回起動用リソースをインポートする

書き込みの完了を確認したら、「资源导入」（リソースをインポート）を押します。microSD カードを挿入し、USB でパソコンに接続した状態で「通过 USB 导入资源」（USB 経由でリソースをインポート）を押し、案内に従ってシステムフォントをインポートしてください。

完了後、ページの案内に従って端末を起動し、Just Read を使い始めます。

</Step>
</Steps>
