## 计时器

计时器让你不用打开手机，也能进行简单的正向计时或倒计时。

## 开始计时

1. 打开 **计时器**，长按下键进入。
2. 首次使用时，选择 **正向计时** 或 **倒计时**。
3. 选择倒计时时，可在 **5–95 分钟**之间设置时长，每次调整 **1 分钟**，然后长按下键开始。
4. 正向计时会从 `00:00` 立即开始，达到 `95:00` 后结束。

保存过设置后，可以选择 **重复上次** 使用上一次的模式和时长，也可以选择 **重新设置**。

## 计时过程中

- 短按上键或下键查看静态时间快照，再短按任意键返回状态页面；
- 计时中长按下键暂停；
- 暂停后长按下键打开 **继续** 或 **退出** 菜单；
- 随时长按上键退出计时器，返回更多文件夹。

## 声音与锁屏

开启声音后，计时中的每秒会交替播放滴答声。倒计时归零或正向计时达到上限时会播放结束提醒，提醒期间第一次按键即可将其静音。

正在运行或已暂停的计时不会因普通休眠超时而停止。离开计时器、重启设备或断电后，计时会结束，不能自动恢复。
