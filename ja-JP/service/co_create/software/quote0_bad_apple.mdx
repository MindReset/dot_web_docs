Quote/0 Bad Apple は、電子ペーパーで動画を再生するハードウェアとソフトウェアの実験です。PC 側で FFmpeg を使って動画を読み取り、設定した間隔でフレームを送信します。専用ファームウェアを書き込んだ Quote/0 は、ローカルネットワーク上の PC を検出し、フレームを受信して画面を更新します。

### 主な機能

- **フレーム単位の再生**：ローカル動画を連続する Quote/0 画面へ変換
- **ローカル自動検出**：PC が UDP でアドレスを通知し、デバイスは TCP でフレームを受信
- **再生オプション**：ループ、向き、反転、更新間隔を設定可能
- **ハードウェアなしのテスト**：Mock Device で検出、転送、応答を PC 上だけで確認
- **オープンな対象構成**：ESP32-C3 と UC8251D 152 × 296 電子ペーパーパネルの組み合わせにも対応

### 事前準備

- Quote/0、または ESP32-C3 + UC8251D 152 × 296 電子ペーパーパネル
- USB-C データケーブル
- Rust と `espflash` v4
- `PATH` から実行できる FFmpeg v8
- PC とデバイスが接続できる 2.4 GHz Wi-Fi

ビルド時に Wi-Fi の SSID とパスワードを渡し、USB-C で `firmware` を書き込みます。デバイスがネットワークへ接続して DHCP アドレスを表示したら、`host` で動画パスを指定してプレイヤーを実行します。初期設定では検出に UDP `18888`、フレーム転送に TCP `8899` を使います。
