## 電池を取り付ける

1. 背面の小さなカバーを確認し、右下の矢印が示す位置を押して、矢印の方向に開きます。
2. 付属の CR2032 電池を、**プラス（+）面を外側、背面カバー側に向けて**取り付けます。
3. マグネット式のカバーを元に戻します。

CR2032 は充電できないリチウム電池です。交換時は同じ型の電池を使ってください。

## 初回設定

初めて使うときは、画面に案内と設定する項目の指示が表示されます。上のボタンが **SET**、下のボタンが **BACK** です。

1. 画面が指示する日付・時刻の項目を確認します。
2. **SET** を短押しすると値が増え、**BACK** を短押しすると値が減ります。
3. **SET** を長押しすると値が確定し、指示が次の項目に移ります。
4. 画面の案内に沿ってすべての設定を終えると、自動で通常動作に入ります。

## ボタン操作

| ボタン | 設定中の短押し | 長押し |
| :--- | :--- | :--- |
| 上：SET | 現在の値を増やす | 通常動作中は設定に入る。設定中は値を確定して次の項目へ進む |
| 下：BACK | 現在の値を減らす | 画面をリフレッシュして残像を消す |

日付や時刻を調整するときは **SET** を長押しし、初回と同じ手順で設定します。

## 画面の残像を消す

高速リフレッシュの後は、電子ペーパーに前の表示が残ることがあります。**BACK** を長押しして全画面をリフレッシュすると、残像を消せます。

## 表示と設置

通常動作中は、日の出・日の入りに合わせて表示内容が自動で切り替わります。

背面カバーはマグネットで固定されており、磁石が付く面にも時計を取り付けられます。
