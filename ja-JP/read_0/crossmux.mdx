---
title: CrossMux をインストール
description: パソコンと USB データケーブルで、Read Pico に読書用ファームウェアをインストールします。
---

CrossMux をインストールすると、Read Pico を読書用の画面として使えます。インストールは「書き込み」とも呼ばれ、端末に新しいファームウェアを保存する操作です。コードを書く必要はありません。

## はじめる前に

パソコン、デスクトップ版 Chrome または Edge、データ転送に対応した USB-C ケーブルを用意してください。

書き込みによって現在のファームウェアが置き換わり、設定が消える場合があります。残したい内容をバックアップし、端末を十分に充電してください。

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux 公式サイト" />

<Steps>
<Step>

### 書き込みページを開く

パソコンの Chrome または Edge で [CrossMux の Web 書き込みツール](https://crossmux.com/#flash-tools)を開き、端末を選ぶ欄を探します。

</Step>
<Step>

### 端末を選ぶ

**Read Pico** を選び、ページの案内に従ってファームウェアのバージョンを選びます。

Read Pico がまだ表示されない場合は、選択肢が追加されるまで操作を止めてください。他の機種のファームウェアを選ばないでください。

<CustomCloudImage osSrc="dot/docs/crossmux_2_1790759301829.png" alt="Read Pico を選択" />

</Step>
<Step>

### 端末を接続する

USB データケーブルで Read Pico をパソコンに接続します。書き込みページから接続を開始し、ブラウザの一覧で Read Pico に対応する USB シリアルポートを選んで接続を確定します。

どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示される項目を確認してください。

{/* スクリーンショット：ブラウザのシリアルポート選択画面。 */}

</Step>
<Step>

### インストールを開始する

機種が正しいことを確認し、ページの案内に従って書き込みを開始します。データの消去を求められた場合は、必要な内容をバックアップ済みか確認してください。

完了の表示が出るまで待ちます。途中でケーブルを抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。

{/* スクリーンショット：書き込みの進捗と完了表示。 */}

</Step>
<Step>

### 使いはじめる

書き込みが完了したら、ページの案内に従って端末を再起動します。新しいファームウェアの画面が表示されたら、画面の案内に従って初期設定を済ませます。

自動で再起動しない場合は、書き込みの完了を確認してから手動で再起動してください。

{/* スクリーンショット：端末の初回起動画面。 */}

</Step>
</Steps>

## 困ったとき

| 問題 | 対処方法 |
| --- | --- |
| 端末が表示されない | データ転送に対応した別のケーブルや USB ポートを試し、端末を使用している他の書き込みツールを閉じてください。 |
| ブラウザで接続できない | パソコンの Chrome または Edge を使ってください。スマートフォンやアプリ内のブラウザでは、この手順を利用できません。 |
| 書き込みに失敗した | 接続を確認し、ページの案内に従って再接続してやり直してください。ダウンロードモードが必要な場合は、機種に対応した説明に従ってください。 |
| 古い画面が残る | 電子ペーパーは電源を切っても画面が残ります。端末を再起動し、新しいファームウェアが起動するか確認してください。 |

公式デモに戻す場合は、[自分だけのシステムを作る](/docs/read_0/firmware)をご覧ください。

<Callout type="info" title="その他のインストール方法">

公式サイトの Web 書き込みツールのほか、[CrossMux のリポジトリ](https://github.com/0x1abin/crossmux)をクローンまたは Fork し、リポジトリの説明に従ってビルド・書き込みすることもできます。[Releases](https://github.com/0x1abin/crossmux/releases) からファームウェアをダウンロードし、そのバージョンの手順でインストールする方法もあります。Read Pico への対応が明記されたファームウェアと手順を選んでください。

</Callout>
