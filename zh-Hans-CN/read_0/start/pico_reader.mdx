以上为项目官网提供的界面示意，刷新效果以实机为准。更多书架与锁屏样式可在[官网界面预览](https://kiikoread.com/#preview)中切换查看。

- **书架与锁屏**：亚克力书架、深色书轨和列表书架；阅读票根、图片壁纸和书架拼贴锁屏。
- **阅读排版**：支持 EPUB 与 TXT，导入自己的字体，调整字号、行距、页边距与首行缩进。
- **翻页操作**：轻点、左右滑动、蓝牙翻页器，以及三键短按与中键长按自定义。
- **刷新选择**：普通、快刷和水波纹三种主页刷新模式；阅读界面可设置全刷间隔或手动全刷。
- **文件传输**：WiFi、热点和 USB 三个独立入口，书籍与字体保存在 TF 卡上。
- **阅读记录与维护**：进度、书签、时长、资料卡与签名；自动休眠、配置备份、TF 卡升级和联网 OTA。

## 开始之前

准备一台电量充足、型号为 **RDP-G01-W** 的墨水屏、一台使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。其他型号不要使用这套刷机包；仅能充电的线缆无法刷写。关闭其他占用设备串口的网页、刷写工具或终端。

首次安装、修复系统或更换基础包时，使用网页完整刷机；已安装兼容基础包的设备也可使用 TF 卡或联网升级。

<Steps>
<Step>

### 打开官网，选择版本

在电脑的 Chrome 或 Edge 中打开 [kiikoread 刷机与下载](https://kiikoread.com/#flash-action)，选择最新正式版或需要的历史正式版。核对版本号、更新时间和更新日志，找到「连接墨水屏，刷入…」按钮；按钮末尾显示所选版本。

</Step>
<Step>

### 连接设备并选择串口

用 USB 数据线连接墨水屏，点击连接按钮。在浏览器弹出的窗口中选择对应的 USB 串口，再点击「连接」。如果无法确定对应条目，可先取消窗口，拔下设备后重新连接，查看新增的串口。

如提示连接失败，可在墨水屏打开「设置 → 升级和恢复 → BOOT 刷机」，进入 BOOT 模式，等待电脑重新识别串口后重试。设备无法进入系统时，参照[官网连接说明](https://kiikoread.com/manual.html#install)处理。

</Step>
<Step>

### 按提示确认安装

连接成功后，选择弹窗中的「安装」，核对目标版本，再按提示确认。

<Callout type="warn" title="先备份需要保留的数据">

刷机会替换当前系统。勾选「擦除设备」会清除设备内部设置与阅读记录；从其他系统迁移时，原有设置也不保证兼容。请先备份需要保留的数据，并阅读安装弹窗中的实际提示。TF 卡中的书籍、字体和图片不会因网页刷写被删除。

</Callout>

</Step>
<Step>

### 等待安装完成

网页会显示安装进度。保持 USB 连接和网页打开，不要拔掉数据线，也不要让电脑进入睡眠。等待弹窗提示安装完成，再按提示结束操作并确认设备重新启动。

</Step>
<Step>

### 导入自己的书籍与字体

系统不预装书籍或额外字体。准备 FAT16 或 FAT32 格式的 TF 卡，将 EPUB / TXT 放入 `books`，字体放入 `fonts`，图片放入 `pictures`；再从书架打开书籍。也可通过「文件管理」中的 WiFi、热点或 USB 传输管理文件。完整操作见[使用说明](https://kiikoread.com/manual.html)。

</Step>
</Steps>

## 已安装用户：TF 卡与联网升级

在[官网刷机与下载](https://kiikoread.com/#flash-action)选择版本，下载 TF 卡升级 Bin，将文件命名为 `Pico-update.bin` 并放在 TF 卡根目录，再打开「设置 → 升级和恢复 → 系统升级 → TF 卡升级」。该文件名用于兼容已有固件，不要更改。

TF 卡升级需要 rc72 或更新的兼容双槽基础包；联网 OTA 需要 rc79 或更新的兼容基础包。连接 WiFi 后，可在系统升级中检查更新、查看日志并确认下载安装。更早版本或其他系统先使用网页完整刷机，具体兼容要求见[升级说明](https://kiikoread.com/manual.html#update)。

应用 Bin 仅用于升级，不能作为完整刷机包写入地址 0。正式固件及校验文件统一在 [GitHub Releases](https://github.com/wegooo-cell/read-pico-reader/releases)提供；具体版本以官网和 Release 为准。
