## Clock/0 是什么

<CustomCloudImage
  osSrc="dot/docs/clock_0_1791859419646.png"
  alt="Clock/0"
  className="h-auto w-full max-w-100"
/>

Clock/0 是一款轻便的墨水屏时钟。2.66 英寸黑白屏没有背光，显示内容随日出日落自动切换。

一颗随附的 CR2032 电池为设备供电。背面的 SET 和 BACK 两个按键用于设置日期、时间与刷新屏幕，磁吸后盖让你可以把它吸附在磁性表面。

## Clock/0 的技术规格

| 项目 | 参数说明 |
| :--- | :--- |
| 产品型号 | CL0-G01 |
| 屏幕 | 2.66 英寸黑白墨水屏，无背光 |
| MCU 处理器 | CW32L010，ARM® Cortex®-M0+ 内核，最高 48 MHz |
| 内部存储 | 多至 64 KB Flash、4 KB SRAM |
| 低速外部时钟 | 32.768 kHz LSE，出厂已配置 |
| 按键 | SET、BACK，支持短按与长按 |
| 供电 | 随附可更换的 CR2032 锂电池，不可充电 |
| 额定电压 | 3 V |
| 计时误差 | 每自然年小于 10 分钟 |
| 开发接口 | SWD；焊盘标记为 GND × 2、CLK、DIO、3V |
| 产品净重 | 26 g |
