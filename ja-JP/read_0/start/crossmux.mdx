## はじめる前に

パソコン、デスクトップ版 Chrome または Edge、データ転送に対応した USB-C ケーブルを用意してください。

書き込みによって現在のファームウェアが置き換わり、設定が消える場合があります。公式デモから初めて CrossMux をインストールする場合、元のファームウェアのバックアップは不要です。端末を十分に充電してください。

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux 公式サイト" />

<Steps>
<Step>

### 書き込みページを開く

パソコンの Chrome または Edge で [CrossMux 公式サイト](https://crossmux.com/)を開き、端末を選ぶ欄を探します。

</Step>
<Step>

### 端末を選ぶ

端末の一覧から **MindReset Read Pico** を選びます。

<CustomCloudImage osSrc="dot/docs/corssmux_2_1790790168698.png" alt="Read Pico を選択" />

</Step>
<Step>

### ファームウェアを選んで接続する

**Nightly** ベータ版を選びます。現在のバージョン番号はページで確認してください。

書き込み欄で、接続中の端末が MindReset Read Pico であることを確認する項目にチェックを入れます。ブラウザは端末を ESP32-S3 として認識し、同じチップを使う他の機種とは区別できません。接続した端末を確認してください。

**公式デモから初めて CrossMux をインストールする場合、バックアップは不要です。** ファームウェアのバックアップ項目にはチェックを入れず、そのままインストールできます。[公式デモの書き込み手順](/docs/read_0/firmware)に従えば、いつでも元のデモに戻せるため、元のデモファームウェアのバックアップは不要です。

<CustomCloudImage osSrc="dot/docs/crossmux_3_1790790168698.png" alt="Nightly の選択、端末の確認とバックアップ設定" />

USB データケーブルで Read Pico をパソコンに接続します。

どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示される項目を確認してください。

</Step>
<Step>

### インストールを開始する

端末、ファームウェアのバージョン、バックアップ設定を確認し、オンライン書き込みのボタンを押します。ブラウザの一覧で端末のシリアルポートを選んでください。

下の進捗欄に、ファームウェアのダウンロードと検証、端末への接続、パーティションの確認、インストール、結果の検証、端末のリセットが表示されます。完了の表示が出るまで、ケーブルを抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。

<CustomCloudImage osSrc="dot/docs/crossmux_4_1790790168697.png" alt="書き込み完了と再起動の案内" />

</Step>
<Step>

### 使いはじめる

書き込みが完了すると端末は自動でリセットされます。起動しない場合は USB を抜き差しし、電源キーで起動してください。

</Step>
</Steps>

## 困ったとき

| 問題 | 対処方法 |
| --- | --- |
| SD カードが検出されない | 別途購入した microSD カードを挿入してください。最大 512 GB に対応しており、FAT32 形式を使用する必要があります。 |
| 端末が表示されない | データ転送に対応した別のケーブルや USB ポートを試し、端末を使用している他の書き込みツールを閉じてください。 |
| ブラウザで接続できない | パソコンの Chrome または Edge を使ってください。スマートフォンやアプリ内のブラウザでは、この手順を利用できません。 |
| 書き込みに失敗した | 接続を確認し、ページの案内に従って再接続してやり直してください。ダウンロードモードが必要な場合は、機種に対応した説明に従ってください。 |
| 古い画面が残る | 電子ペーパーは電源を切っても画面が残ります。端末を再起動し、新しいファームウェアが起動するか確認してください。 |

公式デモに戻す場合は、[自分だけのシステムを作る](/docs/read_0/firmware)をご覧ください。

<Callout type="info" title="その他のインストール方法">

公式サイトの Web 書き込みツールのほか、[CrossMux のリポジトリ](https://github.com/0x1abin/crossmux)をクローンまたは Fork し、リポジトリの説明に従ってビルド・書き込みすることもできます。[Releases](https://github.com/0x1abin/crossmux/releases) からファームウェアをダウンロードし、そのバージョンの手順でインストールする方法もあります。Read Pico への対応が明記されたファームウェアと手順を選んでください。

</Callout>
