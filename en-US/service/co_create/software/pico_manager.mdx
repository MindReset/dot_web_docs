Pico Manager is a book and device management tool for e-paper readers. From an Android phone, you can connect to a device, transfer books in batches, organize files and folders, and manage the network and reading settings provided by compatible firmware.

### Features

- **Device connections:** Enter a device address manually, scan a QR code with the camera, or use a QR code from your photos. Save multiple devices and switch between them as needed.
- **Batch book transfers:** Select multiple book files or share files from other Android apps, and view transfer progress and results.
- **Files and folders:** Browse device files, upload, download, move, rename, and delete files, and create folders.
- **Network and reading settings:** Manage Wi-Fi, view and change device settings, upload or delete fonts, and manage OPDS catalogs.
- **Device information:** View the firmware version, network address, and remaining storage space.

### Before you start

Pico Manager is currently available as an Android preview and requires Android 9 or later. Before connecting, make sure the reader is running compatible third-party firmware with book transfer mode enabled, and that your phone can reach its network address. Supported file formats and available management features depend on the connected firmware.
