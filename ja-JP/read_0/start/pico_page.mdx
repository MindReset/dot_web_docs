Read Pico 向けにシステムを提供してくださった [eMUQI](https://github.com/eMUQI) に感謝します。

Pico Page は Read Pico 向けのオープンソースの読書システムです。microSD カード上の EPUB と TXT をオフラインで読めます。組版の変更はプレビューしてから保存でき、本文を長押しするとオフライン辞書で単語を調べられます。EPUB は KOReader と読書位置を引き継げます。書籍、読書の進み具合、設定は通常のファイルとしてカードに保存されます。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。端末のシリアルポートを使用しているほかのページ、書き込みツール、ターミナルを閉じます。

最大 512 GB、FAT32 形式の microSD カードを用意してください。

Pico Page の公式サイトと端末の画面は、簡体字中国語、繁体字中国語、英語に対応しています。日本語表示はありません。このページでは英語版の表記を使います。

<Steps>
<Step>

### インストールページを開く

[Pico Page 公式サイト（英語）](https://picopage.wulu.zone/en/)の **Install firmware** から[インストールページ](https://picopage.wulu.zone/en/install/)を開き、インストール前の案内を読んでください。バージョンはインストールページの表示に従います。

</Step>
<Step>

### 接続してインストールする

<Callout type="warn" title="端末のデータ">

端末の内部フラッシュ全体が上書きされ、既存のシステムと内部フラッシュに保存された設定は消去されます。microSD カード上の書籍、読書の進み具合、Pico Page の設定（保存済みの Wi-Fi を含む）には影響しません。フラッシュ暗号化またはセキュアブートが有効な端末への書き込みは拒否されます。

</Callout>

USB で Read Pico を接続し、**Connect device**（端末を接続）を押して、ブラウザのダイアログでシリアルポートを選びます。

接続した端末が Read Pico であることを確認するチェックを入れ、**Install Pico Page** を押します。

インストール中は USB 接続とページを開いた状態を保ち、パソコンをスリープさせないでください。完了すると端末が自動で再起動します。初回起動時に **English** を選び、**Continue** をタップします。続く短いガイドでページめくりを練習し、読書ツールを確認できます。**Skip** をタップすると本棚に直接進みます。言語は後から **Settings → Language** で変更できます。

シリアルポートが見つからない、または接続できない場合は、インストールページの説明に従って書き込みモードに入り、もう一度接続してください。

</Step>
<Step>

### 書籍とフォントを追加する

EPUB と TXT ファイルを microSD カードの `Books/` フォルダーにコピーします。

TTF または OTF フォントを microSD カードの `Fonts/` フォルダーにコピーします。

内蔵フォントは中国語の常用漢字 3,500 字のみで、ひらがなとカタカナを含みません。収録されていない文字は四角で表示されます。日本語の本を読む場合は、日本語に対応したフォントを先に追加してください。

microSD カードを抜き差ししたら、端末を再起動してください。電源ボタンを長押しし、メニューで **Restart** を選びます。

カードを取り出さずに、USB または Wi-Fi で本を転送することもできます。手順は [Transfer books](https://picopage.wulu.zone/en/docs/#transfer) をご覧ください。

</Step>
<Step>

### 本を開いて読み始める

本棚で本を開き、本文中央をタップして **Layout** → **Font** を選びます。フォントを選んで **Use this font** をタップします。Layout パネルに戻ったら **Apply to this book** をタップして設定を保存します。プレビューは自動では保存されません。

初期設定の操作：

- **K1**、または本文左側をタップ：前のページ
- **K3**、または本文右側をタップ：次のページ
- **K2**：現在の画面を全面リフレッシュ
- 本文中央をタップ：読書ツールを開く
- フッターの左側または右側をタップ：表示する情報を切り替える、または非表示にする
- 本文を左右にスワイプ：ページをめくる
- 本文を長押ししてドラッグ：単語を選んで調べる（先にオフライン辞書の追加が必要）

閉じる、キャンセル、確定は画面上のボタンで操作します。K2 は現在の画面をリフレッシュするだけです。

電源ボタンを短く押すとスリープし、もう一度短く押すと復帰します。電源ボタンを長押しすると、シャットダウンと再起動のメニューが開きます。

スリープの準備中は、タッチと K1、K2、K3 に反応しません。電源ボタンをもう一度短く押すと取り消せます。電源ボタンの長押しでは、引き続きシャットダウンと再起動のメニューが開きます。

</Step>
</Steps>

<Callout type="info" title="そのほかの機能">

端末の **Settings → Help** で、操作方法をオフラインで確認できます。しおり、組版、本の転送、ロック画面などの詳しい手順は[公式サイトのドキュメント（英語）](https://picopage.wulu.zone/en/docs/)をご覧ください。

オフライン辞書を使うには、StarDict 形式の辞書をフォルダーごと microSD カードの `Dictionaries/` フォルダーにコピーし、**Settings → Reading → Offline dictionaries** で有効にします。公式サイトでは辞書ファイルを提供していません。形式の条件は [Offline dictionaries](https://picopage.wulu.zone/en/docs/#dictionaries) をご覧ください。

KOReader と読書位置を引き継ぐには、両方で内容がまったく同じ元の EPUB ファイル、同じ同期サーバー、同じアカウントを使う必要があります。リモート位置の確認、リモート位置の採用、端末の位置のアップロードはすべて手動です。TXT は位置の引き継ぎに対応していません。設定方法は [Sync with KOReader](https://picopage.wulu.zone/en/docs/#sync) をご覧ください。

Pico Page をインストール済みの端末では、**Settings → Firmware update** で新しいバージョンを確認できます。条件と手順は [Firmware update](https://picopage.wulu.zone/en/docs/#update)、各バージョンの変更点は[更新履歴（英語）](https://picopage.wulu.zone/en/changelog/)をご覧ください。

本を移動するときは、本の横にある対応する `.picopage/` フォルダー（例：`Book.epub.picopage/`）も一緒に移動してください。読書の進み具合、しおり、本ごとの設定が保たれます。

</Callout>
