组织为团队提供管理成员、权限和资源的共享空间。以下步骤以 `Field Lab` 为例。

## 申请创建

1. 登录后打开 [我的账户 → 我的组织](/panel?tab=my-account&accountTab=organizations)，选择「申请创建组织」。
2. 填写组织名称 `Field Lab`，按需添加头像和简介，提交申请。
3. 在「我的申请」查看状态和审核意见。申请未通过时，点「修改后重新申请」。
4. 通过后，从侧栏的「我的组织」打开 `Field Lab`。

在组织页面右上角的更多菜单中选择「复制组织 ID」，可在联系支持时提供这个 ID。

## 邀请成员

在组织的「组织 → 邀请」中选择发送方式。受邀人接受后才加入组织。

| 方式 | 对方如何加入 |
| --- | --- |
| 邮箱 | 打开邀请邮件中的链接，使用对应的已验证邮箱登录，接受邀请。 |
| 手机号 | 登录已绑定并验证该号码的 Dot. 账号，在网页「我的账户 → 我的组织 → 收到的邀请」中接受邀请。 |
| 加入链接 | 打开共享链接，登录 Dot. 账号并确认加入。 |

邀请和加入链接的有效期为 48 小时。可在「邀请」中查看和撤销尚未接受的邀请，也可撤销加入链接。

加入链接可分享给多人。每个组织最多 100 位成员，包括所有者。接受邀请或通过链接加入时会检查剩余名额。

## 管理权限和移交所有权

| 角色 | 可执行的操作 |
| --- | --- |
| 普通成员 | 查看成员、在网页管理设备软件项目和版本，也可主动退出组织。 |
| 管理员 | 可执行成员操作、编辑组织资料、管理邀请和凭据，以及移除普通成员。 |
| 所有者 | 可执行管理员操作、设置或撤销管理员、移除其他成员，以及移交所有权。 |

在组织的更多操作菜单选择「移交所有权」，选中一位已加入组织的成员并确认。对方成为所有者，原所有者成为普通成员。所有者可以在移交完成后退出组织。

所有者也可在同一菜单删除组织。删除后，组织的 API 和公开软件下载入口会关闭。

平台停用组织时，组织页会显示停用状态，组织管理、发布和公开下载暂停。申诉方式见[《组织与发布者协议》](/docs/organization_terms)。
