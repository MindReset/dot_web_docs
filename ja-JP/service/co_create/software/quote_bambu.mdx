Quote Bambu は、Bambu Lab プリンターの状態を Quote/0 の電子ペーパーディスプレイに表示します。
ユーザーのホスト上で Docker コンテナとして動作し、ローカルネットワークの MQTT から
プリンターの状態を読み取り、Quote/0 の Canvas API または Image API で表示を更新します。

![Bambu Lab プリンターと造形物を背景に、印刷状態を表示した Quote/0 を手に持っている様子](https://raw.githubusercontent.com/Aiaid/quote_bambu/main/docs/media/quote-bambu-live-original.jpg)

作者提供の実機写真を元の画像から書き出して縮小したもので、AI によるレタッチは行っていません。
撮影時のレイアウトのため、現在のバージョンで選択できるヘッダー設定とは異なる場合があります。

### 主な機能

- **印刷状態ダッシュボード**：状態、進捗、ノズル・ベッド・チャンバー温度、取得可能な
  AMS・フィラメントトレイ情報、残り時間、レイヤー数、ジョブ名を表示します。
- **任意のカメラスナップショット**：利用可能な RTSPS または JPEG カメラから静止画を取得します。
  カメラを無効にした場合や取得に失敗した場合は、データのみのレイアウトに切り替わります。
- **2 つの表示モード**：標準では Canvas API を使用します。Image API を選ぶと、
  ローカルで描画した 1-bit 画像を送信できます。
- **任意の HMS アラート**：`SHOW_HMS=true` にすると、プリンターのヘルスコードと
  取得可能な英語の説明を全画面で表示します。初期設定では無効です。
- **Docker での実行**：Linux amd64 と arm64 向けのビルドを提供します。
  更新間隔は設定可能で、初期値は 60 秒です。

### 使い始めるには

[英語のセットアップガイド](https://github.com/Aiaid/quote_bambu/blob/main/README.en.md)に従って設定してください。
プリンターの LAN サービスにアクセスできるホスト、プリンターの LAN アクセスコードと
シリアル番号、Quote/0 の API キーとデバイスのシリアル番号が必要です。
Dot. App で、選択した API のコンテンツブロックをデバイスの Loop に追加してください。

主な開発基準機は P2S です。プロジェクトの README に記載された他の機種は互換性の対象であり、
すべての機種・ファームウェアでの実機検証を示すものではありません。
LAN-only または Developer Mode が必要かどうかは、プリンターとファームウェアによって異なります。
MQTT に接続するたびに状態更新を 1 回要求しますが、印刷を制御するコマンドは送信しません。

  提携・推奨関係はありません。描画した状態情報、ジョブ名、任意のカメラスナップショットは、
