Lingxi MultiScreen is a macOS app for managing the Linx68 keyboard display, Rand/0 e-paper display, and Quote/0 e-paper display from one place. Combine clocks, system monitoring, now playing, Codex usage, Qwen Work usage, Pomodoro, and editorial recommendations, then push the resulting screen to the right device.

### Features

- **Three device types in one app**: Keep connection details and board settings separate for Linx68, Rand/0, and Quote/0, with support for multiple devices.
- **Composable boards and card rotation**: Combine clocks, dates, system monitoring, now playing, usage, Pomodoro, custom images, and recommendations, then control sidebar visibility and rotation order.
- **Rand/0 boards**: Build 200 × 200 layouts with light or dark backgrounds, rotation, black-and-white or four-level grayscale, multiple grayscale and dithering options, and local-network delivery.
- **Quote/0 boards**: Build 296 × 152 Quote/0 layouts with single- or two-column modules, rotation, automatic delivery, and local or Dot server-side image processing.
- **Keyboard shortcuts and device controls**: Customize global Pomodoro shortcuts, or use device buttons to switch boards, turn pages, and refresh content.
- **Shared live data**: Reuse system monitoring, now playing, Codex usage, and Qwen Work usage across boards and cards.

### Requirements

- macOS 26 or later
- Apple silicon (M1 or later)
- Devices must be reachable from the Mac over the local network; Quote/0 also requires a Dot App API key and device serial number
