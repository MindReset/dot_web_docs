## Button Controls

Rand/0 uses two physical buttons:

-   Top button: short press to move up, long press to go back;
-   Top button: long press from the main menu to quickly lock the screen;
-   Bottom button: short press to move down, long press to confirm;
-   Bottom button: wake the device when it is asleep.

## Default Home Screen

The default main menu contains **Book of Answers**, **Fortune**, **MBTI Guide**, **Wooden Fish**, **Coin Flip**, **More**, and **SETUP**.

The default **More** folder contains **Bluetooth Remote**, **Pomodoro**, **Clock**, **Timer**, **Dice Roll**, **Number Under Ten**, and **Display**. You can move apps or edit the folder from [Settings](/docs/rand_0/start/settings). The location of an app may change after you customize the home screen.

## Accessories and Design

Rand/0 includes both a wide lanyard hole and a standard lanyard hole, so it can be carried with the included lanyard.

The package includes Rand/0 The Pocket Prophet, a custom lanyard, a custom fragrance card, and a user manual.
