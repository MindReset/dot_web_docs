## Clock/0 とは

<CustomCloudImage
  osSrc="dot/docs/clock_0_1791859419646.png"

Clock/0 は軽量な電子ペーパー時計です。2.66 インチの白黒画面にはバックライトがなく、日の出・日の入りに合わせて表示内容が自動で切り替わります。

付属の CR2032 電池 1 個で動作します。背面の SET と BACK ボタンで日付・時刻の設定や画面のリフレッシュができ、マグネット式の背面カバーで磁石が付く面に取り付けられます。

## Clock/0 の技術仕様

| 項目 | 仕様 |
| :--- | :--- |
| 製品型番 | CL0-G01 |
| 画面 | 2.66 インチ白黒電子ペーパー、バックライトなし |
| MCU | CW32L010、ARM® Cortex®-M0+ コア、最大 48 MHz |
| 内蔵メモリ | 最大 64 KB Flash、4 KB SRAM |
| 低速外部クロック | 出荷時に 32.768 kHz LSE を構成済み |
| ボタン | SET、BACK。短押し・長押しに対応 |
| 電源 | 交換可能な CR2032 リチウム電池付属、充電不可 |
| 定格電圧 | 3 V |
| 計時誤差 | 暦年あたり 10 分未満 |
| 開発用インターフェース | SWD。パッド表記は GND × 2、CLK、DIO、3V |
| 本体重量 | 26 g |
