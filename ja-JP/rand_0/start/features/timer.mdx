## タイマー

スマートフォンを開かずに、正方向の計測またはカウントダウンを実行できます。

## タイマーを開始する

1. **Timer** を開き、下ボタンを長押しします。
2. 初回は **Count up** または **Countdown** を選びます。
3. カウントダウンは **5〜95 分**の範囲を **1 分刻み**で設定し、下ボタンを長押しして開始します。
4. Count up は `00:00` からすぐに始まり、`95:00` で終了します。

設定を保存した後は、**Repeat last** で前回のモードと時間を使うか、**Set new time** で設定し直せます。

## タイマーの動作中

- 上ボタンまたは下ボタンを短押しすると静止した時間表示を確認できます。もう一度短押しすると状態表示へ戻ります。
- 実行中に下ボタンを長押しすると一時停止します。
- 一時停止中に下ボタンを長押しすると **Resume** または **Exit** を選べます。
- 上ボタンを長押しすると、いつでもタイマーを終了して More フォルダーへ戻ります。

## サウンドとロック画面

サウンドがオンの場合、実行中は交互に tick と tock が鳴ります。カウントダウンが 0 になるか Count up が上限に達すると完了アラートが鳴り、アラート中の最初のボタン操作で消音できます。

実行中または一時停止中のタイマーは、通常のスリープタイムアウトで停止しません。タイマーを終了する、再起動する、または電源が切れるとタイマーは終了し、自動的には再開しません。
