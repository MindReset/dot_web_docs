Quote/0 向けの DeepSeek API 残高・利用額ダッシュボードです。DeepSeek アカウントの残高と利用データを読み取り、296 × 152 の白黒電子ペーパー画面に合わせた表示を生成し、Quote/0 API 経由でデバイスにプッシュします。

### プレビュー

#### 残高ダッシュボード

<CustomCloudImage osSrc="dot/docs/demo_1782205743868.jpeg" alt="Quote/0 DeepSeek 残高ダッシュボードのプレビュー" />

標準ビューは 2 カラム構成です。左側に DeepSeek アイコン、アカウント状態、更新時刻を表示し、右側に残高、当日利用額、月間利用額を表示します。DeepSeek API が利用できない場合は、最後に取得できた残高とエラー状態を表示します。

#### 30 日利用額ヒートマップ

<CustomCloudImage osSrc="dot/docs/heatmap_1782205743869.jpeg" alt="Quote/0 DeepSeek 30 日利用額ヒートマップのプレビュー" />

ヒートマップは、直近 30 日の DeepSeek API 利用額を週単位で並べて表示します。点、横線、チェック柄、黒塗りで単色画面上の利用レベルを区別し、今日のセルはリングで強調されます。

#### 統合ダッシュボード

<CustomCloudImage osSrc="dot/docs/dashboard_1782205743870.jpeg" alt="Quote/0 DeepSeek 統合ダッシュボードのプレビュー" />

統合ビューは、残高と利用履歴を 1 画面にまとめます。左側にアイコン、状態、時刻、残高を表示し、右側の 4 × 7 グリッドで直近 28 日の利用傾向を表示します。

### 機能

- **残高ダッシュボード**：DeepSeek の残高、当日利用額、月間利用額、アカウント状態、更新時刻を表示
- **30 日利用額ヒートマップ**：点、横線、チェック柄、黒塗りで単色画面上の利用強度を表現
- **統合ダッシュボード**：残高情報と直近 28 日の利用額ヒートマップを 1 画面に表示
- **利用データのインポートと月間集計**：DeepSeek Usage の ZIP を取り込み、その後は残高スナップショットから月間利用額を継続計算
- **定期プッシュ**：`run_balance_check.sh` と crontab 例により、3 種類の表示を時間帯ごとに切り替え可能
- **ローカル履歴とフォールバック表示**：残高スナップショットを保存し、DeepSeek API が利用できない場合は最後に取得できた残高とエラー状態を表示

### 向いている用途

- DeepSeek API の残高をデスク上で常時確認したい
- Quote/0 で DeepSeek の日次・月間利用傾向を見たい
- 単色電子ペーパー向けのヒートマップ描画や定期プッシュ実装を参考にしたい

<Callout type="warn" title="設定メモ">
  このプロジェクトでは `DEEPSEEK_API_KEY`、`DOT_API_KEY`、`DOT_DEVICE_ID`
  の設定が必要です。`.env` ファイルに認証情報を保存する場合は権限を制限し、
  デプロイ前にソースコードを確認して、認証情報を安全に管理してください。
</Callout>
