## Quote/0 是什么

<CustomCloudImage osSrc="dot/docs/quote_0_hero.png" alt="Quote/0" />

Quote/0 是一款可吸附在金属表面的智能墨水屏设备，旨在通过极简设计帮助用户减少信息过载并提升专注力。

你可以通过 App 灵活设置其显示的内容，包含了 RSS 资讯、待办、日程、天气等丰富内容，并编排属于你的显示策略，甚至可以远程与家人好友一同分享、管理与控制。
借助云端渲染技术，能够呈现丰富的排版和多样化信息。当你对当前内容感兴趣时或需要进一步操作时，只需用支持 NFC 的手机轻轻一碰，即可唤起 iOS Clip App 或 Android App 进行查看或操作。

内容工坊将不断更新与扩展，自定义设计平台与轻代码系统也将在未来上线。

## 起源故事

Quote/0 的构思缘起于一次随意的头脑风暴，却锚定着一份明确的感受——与其被动承受海量却模糊的讯息，不如在日常空间里设立一个“可主动选择”的内容入口。
它被安置在生活的某个角落，像一场持续进行的私人展览。或许你会对它视而不见，也可能在某一瞬间凝神注视。与其他媒介相比，Quote/0 也许显得更笨拙、更缓慢，但正因如此，它将“忽视与凝视”的权利重新交还给你，让每一次相遇或错过，都成为一种带着自觉选择的对话。

## Quote/0 的技术规格

| 项目 | 参数说明 |
| :--- | :--- |
| 产品型号 | QT0-G01 |
| MCU 处理器 | ESP32-C3，32 位 RISC-V 单核处理器 |
| 内部存储 | 400 KB SRAM、4 MB Flash |
| 屏幕 | 2.66 英寸电子墨水屏<br />296 × 152 像素<br />约 125 PPI<br />黑白双色 |
| 面板材质 | 强化塑料涂层 |
| 交互能力 | 手机碰一碰（NFC），唤起 Dot App 或轻 App |
| 电池 | 800 mAh<br />锂电池 |
| 充电时间 | 充满约需 1.5 小时 |
| 外部接口 | USB-C（充电与固件刷写） |
| 无线连接 | Wi-Fi：2.4 GHz，IEEE 802.11b/g/n<br />蓝牙：Bluetooth LE 5.0，用于配网 |
| 产品净重 | 52 g |
| 产品毛重 | 102 g |
| OTA 更新 | 支持 |

<Callout type="warn" title="注意事项">

-   请勿将设备预先粘贴的软磁铁靠近其他磁力源或 MagSafe，否则将会导致磁性意外移除；
-   墨水屏表面使用强化塑料涂层，请勿使用有机溶剂或腐蚀性清洁液擦拭屏幕；
-   部分手机壳包含磁铁或金属片，可能会影响 NFC 功能，请在使用前移除手机壳；
-   电池出厂时预留电量约 70%，建议充满后使用，以获得更长的续航能力。

</Callout>
