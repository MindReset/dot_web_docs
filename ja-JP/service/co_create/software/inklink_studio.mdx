InkLink Studio は Quote/0 向けのローカル Web 制御環境です。ブラウザだけで USB 経由の画面編集、センサーとデバイス設定の確認、Wi-Fi と BLE の管理、Flash バックアップ、内蔵またはローカルファームウェアの書き込みを行えます。クラウドサービスや別のバックエンドは不要です。

### 主な機能

- **ブラウザ画面エディター**：テキスト、画像、センサーレイヤーを自由に配置し、スタイルと重なり順を調整
- **モノクロ画像処理**：切り抜き、拡大縮小、グレースケールから 1-bit への変換、複数のディザリング方式に対応
- **状態確認と設定**：バッテリー、チップ温度、USB 状態、稼働時間、空きメモリを確認し、接続と更新方法を設定
- **プロジェクトの入出力**：画面プロジェクト全体を JSON で保存・移行
- **ブラウザ書き込みとバックアップ**：4 MB Flash 全体を保存し、内蔵またはローカルファームウェアを書き込み
- **自律更新**：画面と動作方針を保存すると、ブラウザを切断してもバッテリー駆動で更新を継続

公開 Web アプリを利用するほか、ローカル起動や Docker 配備も選べます。

<Callout type="warn" title="互換性と書き込み時の注意">
  Web Serial にはデスクトップ版 Chrome または Edge が必要で、ページは HTTPS
  または localhost の安全なコンテキストで実行する必要があります。ブラウザからの書き込みはデバイスのファームウェアを置き換えます。同じ基板ピン配置、UC8251D
  ディスプレイ、4 MB Flash であることを確認し、先に完全なバックアップを保存してください。
</Callout>
