QuotaFrame 将小纸 Pico 变成桌面的 AI 编码额度看板。你可以在墨水屏上同时查看 Codex 与 Claude 的用量百分比和额度重置倒计时，减少切换窗口查询额度。

前往 [QuotaFrame 官网](https://quotaframe.com/)查看安装说明，选择 **MindReset Read Pico** 对应的系统，通过电脑上的 Chrome 或 Edge 完成网页安装。

### 功能特性

- **用量总览**：同屏显示 Codex 与 Claude 的短期、每周用量，以及各自的重置倒计时。
- **蓝牙同步**：电脑端 QuotaFrame Bridge 自动同步用量；断开连接后，屏幕保留最后一次收到的数据。
- **用量趋势**：查看用量变化，趋势记录需要插入 microSD 存储卡。
- **小纸 Pico 交互**：通过触屏与三个触摸按键操作，支持时钟显示、四向自动旋转和屏上设置。

### 使用前准备

使用前，需要在小纸 Pico 上安装 QuotaFrame 对应的系统，并在电脑上运行 QuotaFrame Bridge。电脑端提供 Windows 和 macOS 版本；macOS 需要 14 或以上版本，仅支持 Apple Silicon。

用量来源为 macOS 上的 CodexBar 或 Windows 上的 Win-CodexBar。请先配置账号并确认能正常读取用量。电脑端需持续运行，才能保持数据更新。

电脑端安装包可从[仓库发布页](https://github.com/eMUQI/QuotaFrame/releases)下载。
