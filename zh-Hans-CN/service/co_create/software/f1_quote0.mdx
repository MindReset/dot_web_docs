F1 Quote/0 是一款完全运行在 Mac 本地的 F1 看板推送器。它以 ESPN 的公开数据为主要来源，结合 Jolpica F1 与 OpenF1，读取赛历、赛段结果、实时排名、车手积分和车队积分，并通过 Dot Canvas API 显示在 Quote/0 上。

### 功能特性

- **比赛结果与实时排名**：查看全部比赛、冲刺赛和正赛结果；赛段进行时自动优先显示实时前三名与当前圈数
- **赛历与下一站倒计时**：展示接下来两场赛段的大奖赛、赛道和开始时间，并以离线赛道轮廓显示下一站正赛倒数日
- **关注车手**：查看年度积分、最近全部赛制，以及最近正赛和冲刺赛的名次
- **关注车队**：展示车队年度积分、两位车手的年度排名和近期比赛表现
- **自动轮播推送**：选择需要轮播的面板并设置刷新间隔；比赛期间每 15 秒检查一次实时排名
- **适配墨水屏的布局**：针对 Quote/0 的实际宽度放大车手结果、积分和车队双车手面板，并内置赛道素材

### 使用方式

在 macOS 中打开仓库提供的 `Build/F1 Quote 0.app`，进入设置填写 Dot API Key 和 Quote/0 设备 ID，然后选择关注的车手、车队、推送间隔和参与轮播的面板。使用前需要先在 Dot App 内容工坊中把 Canvas API 内容加入设备 Loop。

API Key、设备 ID 与用户设置仅写入当前 Mac 的应用偏好设置，不会进入项目文件。自动推送最短间隔为 60 秒；应用退出、Mac 关机或进入深度睡眠后不会继续更新，但 Quote/0 会保留最后一次成功推送的画面。

从源码构建需要 macOS 14 或更高版本及 Xcode，可运行 `./scripts/package_app.sh` 生成应用。

<Callout type="warn" title="数据来源与兼容性">
  ESPN 的 F1 数据接口公开可访问，但没有正式文档，也未承诺长期保持字段兼容。Jolpica F1
  用于补充车手与车队关系，OpenF1 用于补充 DNF、DNS 和 DSQ
  等异常完赛状态。数据源发生变化时，应用可能需要更新解析逻辑。
</Callout>
