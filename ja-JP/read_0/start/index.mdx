Read Pico は電子ペーパー開発ボードです。対応するサードパーティ製システムを書き込んで使い始めることができます。以下に、Read Pico 向けのサードパーティ製システムを紹介します。インストールの提供状況と使い方は各システムのページで確認してください。

<Callout type="info" title="インストール前に確認してください">

初回インストールや別のシステムへの切り替えでは、各プロジェクトが Read Pico 向けに案内する完全インストールの手順を使ってください。アプリ更新用イメージ、カード経由の更新、OTA は通常、互換性のあるシステムとパーティション構成が導入済みであることが前提です。完全インストールの代わりにはなりません。異なるシステムやバージョンのファイルを混在させないでください。

大切な書籍、ノート、読書記録、設定を保存し、Flash 全体のバックアップは各プロジェクトの要件に従ってください。書き込みで内部ストレージが再作成される場合があります。更新前には対象バージョンのリリースノートで、言語パックやフォントなどのリソースも更新する必要があるか確認してください。

</Callout>
