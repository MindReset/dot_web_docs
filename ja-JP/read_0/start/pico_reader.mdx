画像はプロジェクトの公式サイトが提供する画面イメージです。画面更新の見え方は実機で確認してください。ほかの本棚・ロック画面は[公式サイトのプレビュー](https://kiikoread.com/#preview)で切り替えて確認できます。

- **本棚とロック画面**：アクリル、ダークレール、一覧式の本棚。読書チケット、画像壁紙、本棚コラージュのロック画面。
- **読書レイアウト**：EPUB と TXT、持ち込みフォント、文字サイズ、行間、余白、段落の字下げを調整できます。
- **ページ操作**：タップ、左右スワイプ、Bluetooth ページめくり機器。三つのボタンの短押しと中央ボタンの長押しを設定できます。
- **画面更新**：メイン画面には通常、高速、波紋の三つのモード。読書中は全画面更新の間隔や手動更新を設定できます。
- **ファイル転送**：WiFi、端末のアクセスポイント、USB の独立した入口。書籍やフォントは microSD カードに保存します。
- **記録とメンテナンス**：進捗、しおり、読書時間、プロフィール、ステータスバーのメッセージ。自動スリープ、設定のバックアップ、microSD 更新、オンライン OTA。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。このインストールパッケージは Read Pico 専用です。充電専用のケーブルでは書き込めません。シリアルポートを使うほかのページ、書き込みツール、ターミナルを閉じてください。

初回インストール、システム修復、基本パッケージの変更には Web からの完全インストールを使います。互換性のある基本パッケージを導入済みなら、microSD や WiFi でも更新できます。

<Steps>
<Step>

### サイトを開いてバージョンを選ぶ

パソコンの Chrome または Edge で [kiikoread の書き込み・ダウンロードページ](https://kiikoread.com/#flash-action)を開き、最新の正式版または掲載された過去の正式版を選びます。バージョン、更新日時、更新履歴を確認し、「连接墨水屏，刷入…」（電子ペーパー端末に接続して書き込む）のボタンを探してください。末尾には選択したバージョンが表示されます。

</Step>
<Step>

### 端末を接続してシリアルポートを選ぶ

USB データケーブルで端末を接続し、接続ボタンを押します。ブラウザの一覧で対応する USB シリアルポートを選び、「接続」を押してください。どの項目か分からない場合は、いったん一覧を閉じて端末を抜き差しし、新しく表示されるポートを確認します。

接続できない場合は、端末で「设置 → 升级和恢复 → BOOT 刷机」（設定 → 更新と復元 → BOOT 書き込み）を開き、BOOT モードに入ります。パソコンがポートを再認識してからやり直してください。システムが起動しない場合は、[公式サイトの接続手順](https://kiikoread.com/manual.html#install)を参照してください。

</Step>
<Step>

### 案内に従ってインストールを確認する

接続できたら、ダイアログの「安装」（インストール）を選び、対象バージョンを確認して案内に従います。

<Callout type="warn" title="残したいデータを先にバックアップ">

書き込みによって現在のシステムが置き換わります。「擦除设备」（端末を消去）を選ぶと、端末内の設定と読書記録が消去されます。別のシステムの設定には互換性が保証されません。残したいデータを先にバックアップし、インストール画面の実際の案内を読んでください。Web 書き込みで microSD カード内の書籍、フォント、画像は削除されません。

</Callout>

</Step>
<Step>

### 完了するまで待つ

サイトにインストールの進捗が表示されます。USB 接続とページを開いた状態を保ち、ケーブルを抜いたり、パソコンをスリープさせたりしないでください。完了の表示を待ち、案内に従って操作を終了し、端末の再起動を確認します。

</Step>
<Step>

### 自分の書籍とフォントを入れる

システムには書籍や追加フォントは含まれていません。FAT32 形式の microSD カード（最大 512 GB）を用意し、EPUB / TXT を `books`、フォントを `fonts`、画像を `pictures` に入れて、本棚から書籍を開いてください。ファイル管理の WiFi、端末のアクセスポイント、USB 転送でもファイルを管理できます。詳しくは[使い方ガイド](https://kiikoread.com/manual.html)を参照してください。

</Step>
</Steps>

## 導入済みの場合：microSD とオンライン更新

[書き込み・ダウンロードページ](https://kiikoread.com/#flash-action)でバージョンを選び、TF カード更新用 Bin をダウンロードします。ファイル名を `Pico-update.bin` にしてカードのルートに置き、「设置 → 升级和恢复 → 系统升级 → TF 卡升级」（設定 → 更新と復元 → システム更新 → TF カード更新）を開きます。既存ファームウェアとの互換性のため、このファイル名を維持してください。

microSD 更新には rc72 以降の互換性のあるデュアルスロット基本パッケージ、オンライン OTA には rc79 以降の互換性のある基本パッケージが必要です。WiFi 接続後、システム更新で新しいバージョンを確認し、更新履歴を読んでダウンロードとインストールを開始できます。古いバージョンや別のシステムでは、先に Web から完全インストールしてください。互換性の詳細は[更新ガイド](https://kiikoread.com/manual.html#update)にあります。

アプリケーション Bin は更新専用です。完全インストール用のファイルとしてアドレス 0 に書き込まないでください。正式ファームウェアとチェックサムは [GitHub Releases](https://github.com/wegooo-cell/read-pico-reader/releases)で公開しています。現在のバージョンは公式サイトと Release で確認してください。
