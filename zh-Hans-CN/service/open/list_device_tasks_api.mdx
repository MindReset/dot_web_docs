### 必要条件

1. 确保您已在 Dot. App 中<Link href="/docs/service/studio/api/get_api">获取并保存了 API 密钥</Link>；

## 问题排查

### 请求路径

`/api/authV2/open/device/:deviceId/:taskType/list`

### 请求方法

`GET`

### 路径参数

<TypeTable

### 请求结构

此接口不需要请求体，仅需在请求头中提供 API 密钥。

- `deviceId`: 设备序列号
- `taskType`: 必填。`loop`（循环列表）或 `fixed`（固定列表）

更新 API 内容时，将本接口返回的 `key` 作为 `taskKey`，并在写入请求顶层传入相同的 `taskType`。例如，从 `/fixed/list` 查询得到的内容，要使用 `taskType: "fixed"` 更新。写入时省略 `taskType` 默认查询循环列表，不会自动查找固定列表。

### 响应结构

返回值为内容数组。

- `type`: 内容类型（返回 `TEXT_API` / `IMAGE_API` / `CANVAS_API` / `GENERAL`）
- `key`: 内容唯一标识（可能为 `null`）
- 其余字段：该内容的输入参数（不同类型的内容字段不同，例如 Text API 的 `title` / `message`，Image API 的 `border` / `ditherType` 等）

### 响应说明

| code  | 含义       | 描述                 |
| ----- | ---------- | -------------------- |
| `200` | 成功       | 成功获取设备内容列表 |
| `401` | 未授权     | API 密钥无效或已过期 |
| `500` | 服务器错误 | 服务器内部错误       |
