Read Pico 向けにシステムを提供してくださった [Yana-Hangabina](https://github.com/Yana-Hangabina) に感謝します。

CPYOS は [CrossMux](/docs/read_0/start/crossmux) を基にした読書システムです。ローカル書籍、晋江文学城、微信読書を同じ本棚にまとめ、中国語入力、読書統計、組版の調整に対応します。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使うパソコン、データ通信対応の USB-C ケーブルを用意してください。端末のシリアルポートを使用している他のページ、書き込みツール、ターミナルは閉じてください。

書籍、フォント、読書データを保存する microSD カードを用意してください。Read Pico は最大 512 GB に対応し、FAT32 形式が必要です。

初回インストールではパーティションテーブルを作り直し、端末内部の Flash を消去します。公式サイトの案内に従い、16 MiB の Flash 全体と大切なデータを事前にバックアップしてください。Web インストールで microSD カード上の書籍や設定は削除されません。

## 公式サイトからインストールする

<Steps>
<Step>

### 公式サイトを開き、インストール方法を選ぶ

パソコンの Chrome または Edge で [CPYOS 公式サイト](https://yana-hangabina.github.io/cpyos/)を開き、「刷机」（書き込み）へ進みます。

初回インストールや他のシステムからの切り替えでは「首次安装 / 恢复」（初回インストール / 復元）を選びます。すでに CPYOS を使っている端末は「从 CPYOS 升级」（CPYOS から更新）で、端末設定とパーティションテーブルを保持できます。

</Step>
<Step>

### 端末を接続してインストールする

USB データケーブルで Read Pico を接続し、対応するインストールボタンを押して、ブラウザーのシリアルポート一覧から端末を選びます。`USB JTAG/serial debug unit` と表示される場合があります。

初回インストールではバックアップの完了を確認し、ページの案内に従って消去とインストールを行います。書き込みが完了して端末が自動再起動するまで、USB 接続とページを保ち、パソコンをスリープさせないでください。

</Step>
<Step>

### 書籍を入れて読み始める

microSD カードを挿入し、本棚からローカル書籍を開くか、端末のブラウザー経由のファイル転送で取り込みます。EPUB、TXT、CBZ、FB2 に対応します。

カード内の TTF、OTF、TTC フォントや EPUB の埋め込みフォントを使えます。フォントは本ごとに指定できます。

晋江文学城や微信読書を使う場合は Wi-Fi に接続し、端末の各サービスの入口からログインして、本棚の閲覧や書籍の取得を行います。微信読書は QR コードログインと、ダウンロード後のオフライン読書に対応します。

</Step>
</Steps>

## 主な機能

### 共通の本棚とオンライン読書

ホーム画面には読書の再開、最近読んだ本、直近 7 日間の読書記録、晋江の更新情報が並びます。本棚にはローカル、晋江、微信読書の書籍をまとめ、入手元をラベルで表示します。

晋江文学城では本棚、作品探し、書名・著者検索、お気に入り、章の購入、段落コメントへの反応、読書進捗の同期を使えます。微信読書では本棚の閲覧、EPUB のダウンロードとオフライン読書、進捗同期に対応します。

晋江文学城と微信読書への対応は非公式です。利用できる内容はアカウントの権限と各サービスのインターフェースによって異なります。

### 中国語入力と組版

オフラインのピンイン入力、書名検索、ハイフネーション、中国語の代替フォントに対応します。フォント、文字サイズ、組版を調整し、しおり、注釈、辞書、読書統計を使えます。

### ページ送りと表示

波紋効果や白黒の高速ページ送りを選び、残像を消せます。タッチ操作のほか、端末を傾けたり左右に振ったりしてページを送ることもできます。

## 接続と更新

ブラウザーで書籍を転送して設定を変更でき、WebDAV、OPDS、Calibre のワイヤレス接続にも対応します。

CPYOS のインストール後は Wi-Fi に接続し、「设置 → 系统 → 检查更新」（設定 → システム → 更新を確認）から OTA 更新を行えます。公式サイトの案内に従ったカード経由の更新も利用できます。更新中は電源を保ち、再起動まで待ってください。他のシステムから初めて切り替える場合は、公式サイトのフルインストールを使います。

## その他のインストール方法

リポジトリの Releases から完全なインストールパッケージを入手し、同梱の `FLASH.md` と `SHA256SUMS` に従ってオフラインインストールと検証を行えます。リポジトリをクローンまたは Fork して、自分でビルド・書き込みすることもできます。初回インストールには完全なパッケージが必要で、アプリケーションイメージだけでは不十分です。
