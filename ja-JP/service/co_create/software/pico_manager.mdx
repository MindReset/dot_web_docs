Pico Manager は、小型の電子ペーパー読書端末向けのネイティブ管理ツールで、Android 版と iOS 版を提供しています。端末に接続して書籍をワイヤレスで転送し、ファイルやフォルダーを整理したり、フォント、壁紙、ネットワーク設定、読書設定を管理したりできます。画面と利用できる機能は、端末とファームウェアの対応状況に合わせて自動的に切り替わります。

### 主な機能

- **書籍のワイヤレス転送：** システムの共有機能から書籍やフォントを取り込み、端末が対応するファイル形式の確認と転送先フォルダーの選択を自動で行います。
- **ファイルとフォルダーの管理：** 端末内のファイルを閲覧し、アップロード、ダウンロード、移動、名前の変更、一括削除、フォルダーの作成ができます。
- **端末設定：** ファームウェアの対応状況に応じて利用できる項目が切り替わり、Wi-Fi ネットワーク管理、フォント管理、壁紙のアップロードと管理、OPDS 書庫の設定、端末パラメーターの調整ができます。

### 使用前の準備

対応ファームウェアは [Pico Manager 公式サイト](https://pico.cold04.com/)で確認してください。接続前に、読書端末で対応ファームウェアが動作し、書籍転送モードが有効になっていることと、スマートフォンから端末のネットワークアドレスにアクセスできることを確認してください。転送できるファイル形式や利用できる管理機能は、接続したファームウェアの対応状況によって異なります。
