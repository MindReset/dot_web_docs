基板の SWD インターフェースでファームウェアを書き込むことで、独自の時計表示、ボタン操作、低消費電力のアプリケーションを作れます。Clock にはビジュアルデザインエディターがなく、独自の表示にはファームウェア開発が必要です。

## チップの資料

Clock は CW32L010 を搭載しています。プロセッサー、メモリ、クロックについては[技術仕様](/docs/clock_0)、周辺機能とパッケージについては武汉芯源の [CW32L010 データシート](https://www.whxy.com/shujushouce.html)を参照してください。

## SWD を接続する

[電池の取り付け](/docs/clock_0/start)と同じ方法でマグネット式の背面カバーを開きます。基板には **GND、GND、CLK、DIO、3V** の 5 つのパッドがあります。信号の表記に合わせて接続してください。

| 基板のパッド | デバッガー側の接続 | 用途 |
| :--- | :--- | :--- |
| GND（2 か所） | GND | デバイスとデバッガーの共通グラウンド |
| CLK | SWCLK | SWD クロック |
| DIO | SWDIO | SWD の双方向データ |
| 3V | Vref / VTref などのターゲット電圧参照端子 | 電圧検出に対応するデバッガーへ基板の電圧を伝える |

<Callout type="warn" title="電源と配線">

デバイスの定格電圧は 3 V です。デバッガーの電圧参照端子と電源出力端子は用途が異なります。3V パッドに 5 V 電源を接続しないでください。

配線前に電源を切ってください。外部電源を使う場合は、充電できない電池への逆流を避けるため、先に CR2032 電池を取り外します。配線後にグラウンド、極性、ターゲット電圧を確認してから電源を入れます。

</Callout>

## 開発環境の準備

CW32L010 に対応する SWD デバッガー、接続線、コンパイラーとデバッグ環境を用意します。

- [CW-DAPLINK](https://www.whxy.com/kaifagongju.html) はチップメーカーの SWD デバッグツールです。Keil または IAR と組み合わせて使え、インターフェースの電圧参照はターゲット基板から供給されます。
- [公式ファームウェアライブラリ](https://www.whxy.com/gujianku.html)から CW32L010 の標準周辺機能ライブラリを入手します。
- RTC、GPIO、低消費電力モードなどの設定は [CW32L010 リファレンスマニュアル](https://www.whxy.com/yonghushouce.html)を参照してください。

## ビルドと書き込み

開発前に、ハードウェアの版に対応する画面コントローラー、解像度、ピン配置、電気的な接続を確認してください。チップライブラリのサンプルは、これらを適合させてから Clock で使用します。

1. CW32L010 のチップ用サンプルプロジェクトから始めます。実物と同じ型番を選び、スタートアップファイル、メモリ容量、書き込みアルゴリズムを設定します。
2. SWD デバッグを選び、上の信号表に沿って接続し、デバッガーがチップを認識できることを確認します。
3. Clock のハードウェア接続に合わせてボタン、クロック、画面ドライバーを実装し、ビルドします。
4. 復元方法を用意してから書き込み、実装した動作に沿って計時、ボタン、画面のリフレッシュを確認します。

<Callout type="warn" title="出荷時の機能を復元するために">

書き込みによって既存のファームウェアが置き換わります。出荷時の機能に戻せるようにするには、書き込み前に復元用ファームウェアまたは有効なバックアップを用意してください。

読み出し保護によりバックアップできない場合があります。保護レベルを下げるとチップ全体が消去される可能性があります。具体的な動作は[チップのデータシート](https://www.whxy.com/uploads/files/20250604/CW32L010_DataSheet_EN_V1.0.pdf)を参照してください。

</Callout>

## 独自の時計を実装する

| 機能 | 実装方法 |
| :--- | :--- |
| 日付と時刻 | 実装済みの 32.768 kHz LSE を RTC の基準にし、表示に合わせて復帰を設定 |
| ボタン操作 | SET と BACK のチャタリングを除去し、短押しと長押しを区別 |
| 電子ペーパー表示 | 実際のコントローラーの初期化手順とタイミングに従い、高速・全画面リフレッシュを処理 |
| 日の出・日の入りでの切り替え | ファームウェアで切り替え時刻を計算または保存し、時刻に合わせて表示を更新 |
| 低消費電力 | 計時、ボタン処理、画面更新の後に低消費電力モードへ入り、必要に応じて復帰 |
| メモリ使用 | 実際の SRAM 容量に合わせて描画バッファを設計し、必要なら行単位・ブロック単位で出力。固定フォントや画像は Flash に保存 |

## SWD 接続ができない場合

まず電源、共通グラウンド、CLK / DIO の配線を確認し、デバッガーのターゲット電圧参照と SWD 設定を確認します。接続が不安定な場合は SWD クロックを下げて試してください。

それでも認識できない場合は、解除やチップ全体の消去を実行する前に、チップの型番と保護状態を確認してください。
