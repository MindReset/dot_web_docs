### 一覧の応答

`items` には現在のページのバージョンが作成日時の新しい順に入り、`totalCount` は一致した全件数です。`status` は公開チャネル、`state` は審査や配布の状態です。

| `state` | 意味 |
| --- | --- |
| `draft` | 下書き。テスト公開または正式版の審査提出ができます。 |
| `pending` | 正式版の審査待ちです。 |
| `rejected` | 要修正です。詳細で審査コメントを確認できます。 |
| `published` | 公開済みです。デバイスから照会できます。 |
| `disabled` | 公開配布は停止中です。 |
| `revoked` | このバージョンの配布は取り消されました。 |

公開済みバージョンのダウンロード URL は、一覧やバージョン詳細の `downloads` に含まれます。同じファイル種別のキーを `artifacts` で参照すると、ファイル名 `name`、バイト数 `size`、チェックサム `sha256` を取得できます。この例のバージョンには 3 種類のファイルがあります。

## バージョンと審査状況を確認する

プロジェクトの `firmwareId` と、一覧またはアップロード完了時に取得したバージョンの `id` を使います。詳細の `releaseNotes` には `zh-Hans-CN`、`en-US`、`ja-JP` が含まれます。正式版が `rejected` の場合は `reviewReason` と今回の `reviewId` を確認し、[修正して再提出](/docs/service/open/organization_software/review)します。

## 使用できるバージョン番号を確認する

<ApiPlayground
  endpoint="/api/authV2/organization/software/versions"
  method="GET"
  auth="organization"
  queryParams={{
    firmwareId: { type: "string", name: "デバイスソフトウェア ID", required: true, example: "000000000000000000000101" },
  }}
/>

### クエリパラメーター

<TypeTable
  type={{
    firmwareId: {
      type: 'string',
      description: 'プロジェクトの作成・一覧取得で返る 24 桁の 16 進数の firmwareId。',
      required: true,
    },
  }}
/>

アップロード前に `GET /versions` で使用できるバージョン番号を確認できます。応答の配列には、デバイスごとに `channels.ALPHA`、`channels.TESTING`、`channels.RELEASED` が含まれます。各チャネルの `latest` は登録済みの最上位バージョンで、登録がなければ `null` です。それより高い番号か、`reusable` にある番号を使います。アップロードが `409` を返した場合は、照会し直して番号を選びます。

使用できるバージョン番号が決まったら、[新しいバージョンをアップロード](/docs/service/open/organization_software/upload)できます。現在配布しているバージョンを調べる場合は、[サーバーから公開済みのバージョンを照会](/docs/service/open/organization_software/organization_version_query)します。
