使用 `POST /api/authV2/device/firmware/query` 查询已发布的设备软件。此接口无需登录或提供 API 密钥。查询组织软件时，传入 [设备软件 ID](/docs/service/open/organization_software/software_ids) 和该软件绑定的设备信息。

## 设备 ID 查询

推荐使用设备 ID 查询。读取设备的 MAC 地址，去掉冒号并将字母转为大写。例如，`02:ab:cd:ef:12:34` 转换为 `02ABCDEF1234`。

将转换得到的设备 ID 填入请求体的 `id`，并传入项目的 `firmwareId`。服务端根据设备 ID 查找系列、型号和硬件版本，并按 `status` 选择发布渠道。

## 响应示例

HTTP `200 OK`。示例请求 `releaseNotes: ["zh-Hans-CN"]` 并选中 `1.2.0-beta.1`。所选版本高于设备当前版本，因此 `needUpdate` 为 `true`。

```json
{
  "series": "read",
  "model": "read_0",
  "edition": 1,
  "status": "TESTING",
  "firmwareId": "000000000000000000000101",
  "version": "1.2.0-beta.1",
  "needUpdate": true,
  "updateVersion": "1.2.0-beta.1",
  "releaseNotes": [
    { "locale": "zh-Hans-CN", "content": "提高从休眠唤醒后画面的刷新稳定性。" }
  ],
  "ota": {
    "downloadUrl": "https://dot.mindreset.tech/download/AwAAAAAAAAAAAAABAwAAAAA",
    "size": 1176976,
    "sha256": "a4b13eb3a234a0446faeed2e1d07a22f52bf06b40b00e22f219e15211eed6b07"
  }
}
```

- `version` 和 `updateVersion` 指向本次选中的版本。
- 只有选中的版本高于 `currentVersion` 时，`needUpdate` 才为 `true`。未提供当前版本时也会返回版本信息，`needUpdate` 为 `false`。
- `ota` 为 `null` 时，选中的版本未提供 OTA 文件。有 `ota` 时，向 `ota.downloadUrl` 发送 GET 请求并跟随 HTTP 302，获取有效期最长为 3 分钟的签名地址。参见[下载与更新](/docs/service/open/organization_software/download)。

为官网或刷写工具提供完整烧录镜像和分离烧录包时，可从[组织版本列表或详情](/docs/service/open/organization_software/organization_versions)取得下载链接。

省略 `firmwareId` 查询官方软件时，`ota` 同时包含原有的 `ota.path` 和授权下载入口 `ota.downloadUrl`。旧设备仍可按 `https://os-cdn.mindreset.tech/` 解析相对路径 `ota.path`。

`GET /api/authV2/device/ota` 已弃用，已部署的设备仍可调用。新接入使用本页的 POST 查询与 `ota.downloadUrl`。

## 排查

请求体无效时，HTTP `400` 响应包含以下错误信息。

```json
{
  "message": "Invalid firmware query."
}
```

| HTTP 状态 | 检查方式 |
| --- | --- |
| `400` | 检查设备标识是否完整、渠道是否有效、版本号是否符合 SemVer。 |
| `404` | 确认设备 ID 对应的设备记录存在，或核对请求中的型号信息。检查软件 ID 与设备绑定是否相符、组织是否可用，以及所选渠道是否有已生效的版本。指定 `version` 时，确认该版本仍在分发。 |
| `429` | 同一 IP 对此接口每秒最多 10 次请求。降低频率后重试。 |
| `500` | 查询未完成，稍后重试。 |

发布服务可[用组织凭据查询已发布版本](/docs/service/open/organization_software/organization_version_query)。需要查看草稿或审核进度时，使用[版本列表与详情](/docs/service/open/organization_software/organization_versions)。
