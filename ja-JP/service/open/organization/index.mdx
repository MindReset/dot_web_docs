組織では、チームでメンバー、デバイスソフトウェア、公開に使う認証情報を管理できます。

## クイックスタート

<Steps>
<Step>
### 組織を作成する

ウェブサイトの「マイアカウント → マイ組織」から[組織の作成を申請](/docs/service/open/organization/membership)します。提出前に[組織・公開者規約](/docs/organization_terms)を読み、同意してください。承認後はサイドバーから組織を開けます。

</Step>
<Step>
### メンバーを招待する

所有者または管理者は、[メールアドレス、電話番号、参加リンクでメンバーを招待](/docs/service/open/organization/membership)できます。招待された人は、招待を承諾すると組織に参加します。

</Step>
<Step>
### 共同作業を始める

メンバーはウェブサイトで[デバイスソフトウェアとバージョン](/docs/service/open/organization_software)を共同で管理できます。CI やリリーススクリプトから API を呼び出すには、[組織の認証情報を設定](/docs/service/open/organization/credentials)します。

</Step>
</Steps>
