感谢 [autumnc](https://github.com/autumnc) 为小纸 Pico 提供系统。

研读 YanReader 将阅读、写作和计划集中在同一设备上。阅读器采用 CrossMux 排版引擎，并结合小纸 Pico 官方示例的屏幕与字体组件，提供本地书库、拼音输入、蓝牙键盘和翻页器支持。

## 开始之前

准备电量充足的小纸 Pico、使用桌面版 Chrome 或 Edge 的电脑，以及支持数据传输的 USB-C 数据线。关闭其他占用设备串口的网页、刷写工具或终端。

请准备 microSD 存储卡，用于保存书籍、字体、笔记与计划数据。小纸 Pico 最大支持 512 GB，格式为 FAT32。

按项目说明，正常网页安装不主动擦除设备设置与 Wi-Fi 凭据所在的 NVS 分区，也不删除存储卡内容；手动擦除整片 Flash 则会清除 NVS。更换系统前，请保存需要保留的书籍、笔记、阅读记录与设置，原系统的设置不保证能在 YanReader 中继续使用。

## 通过官网安装

<Steps>
<Step>

### 打开官网并确认系统

在电脑的 Chrome 或 Edge 中打开 [YanReader 官网](https://autumnc.github.io/YanReader-pico/)，查看页面加载的版本和校验信息。

网页默认安装当前发布的完整镜像。若要安装旧版本或自行构建的版本，可展开本地文件选项。两种发布文件的用途不同：

| 发布文件 | 用途 |
| --- | --- |
| `yanreader-<版本>-full.bin` | 包含引导程序、分区表与应用。首次安装、从其他系统切换或通过网页重装时，选择这个完整镜像。 |
| `pjournal_pico.bin` | 仅包含应用，不更新引导程序与分区表。仅用于已安装兼容 YanReader 分区布局的设备，按对应版本说明手动升级，不能作为网页安装的完整镜像。 |

不要将 `pjournal_pico.bin` 当作完整镜像写入 `0x0`，否则设备将无法正常启动。选择本地文件时，请核对来源、版本与页面显示的校验信息。

</Step>
<Step>

### 连接设备并刷写

用 USB 数据线连接小纸 Pico，点击「连接设备」，在浏览器弹窗中选择 `USB JTAG/serial debug unit`，确认页面识别到 ESP32-S3 后，点击「开始刷写」。

页面会依次写入、读回校验并重启设备。校验期间进度条可能停留在 100%，请等待「刷写完成」提示。期间不要拔线、关闭页面或让电脑进入睡眠。

</Step>
<Step>

### 准备存储卡并开始使用

将图书放入卡内的 `books/` 文件夹，自定义 TTF 字体放入 `fonts/`。插入存储卡并启动设备后，从书架打开图书。

需要网络功能时，在「设置 → WiFi 管理」连接网络。联网校时后，阅读统计与待机时钟可使用正确时间。官网的「使用帮助」提供按键、触控、文件目录与安装说明。

</Step>
</Steps>

### 安装后检查

- 确认存储卡可读取，能从书架打开一本书，并在退出、重新打开后保留阅读进度。
- 打开一条已有笔记，或新建笔记后保存、重新打开，确认需要保留的数据可正常使用。
- 短按电源键进入待机，再短按唤醒，检查是否回到原页面，并确认文字显示与翻页正常。

## 主要功能

### 阅读与标注

阅读 EPUB、TXT 和 XTC，调整字体、字号、行距、段距、缩进和页边距。支持 EPUB 内嵌字体、脚注弹窗、目录、书签和百分比跳转，也可长按正文选取文字，进行标注、记笔记或查询本地 StarDict 词典。

可按书名查找图书，并搜索笔记。笔记页的「导出」可将各书的标注、笔记与书签汇总为一份 Markdown，保存到存储卡的 `exports/` 文件夹。阅读统计包括时长、每日页数、热力图与连续阅读天数。

### 写作与计划

「研墨」提供日记、自由写作、大纲和灵感记录，支持 Markdown 显示、历史版本、竖排书写，以及 Flomo、WebDAV 同步。DeepSeek 润色需自行配置 API Key 并连接网络。

「研行」提供 GTD 任务管理，可整理任务、项目、日历和便签，筛选内容并导出 Markdown。

### 输入与操作

在主界面长按中间触摸按键，可在「研读」「研墨」「研行」之间轮换。三种模式共用虚拟键盘和拼音输入法，支持多种键盘布局，也可以连接 BLE 键盘或兼容的蓝牙翻页器。

阅读时可用左右按键或横滑翻页，点按中间区域打开阅读菜单。晃动设备可进行全屏刷新。设备待机后，使用电源键唤醒。

## 更新与当前支持

当前尚不支持设备 OTA 更新。更新时请通过 USB 使用官网刷写，或在同一页面选择其他版本的完整安装包。

手动使用应用镜像升级前，请查看[对应版本的发布说明](https://github.com/autumnc/YanReader-pico/releases)，确认已安装的分区布局与目标版本兼容。无法确认时，使用该版本的完整镜像，不要混用不同版本的引导程序、分区表与应用文件。

设备界面目前为中文，支持书架和笔记搜索，暂不支持书内全文搜索。

## 其他安装方式

可从仓库 Releases 下载完整安装包，按对应版本说明使用 USB 刷写，也可以克隆或 Fork 仓库自行构建。

自行构建需准备 ESP-IDF v6.1 和 `read_pico_firmware` 依赖。输入法词库等资源的生成与构建选项请按仓库说明准备。
