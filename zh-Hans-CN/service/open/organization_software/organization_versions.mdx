### 列表响应

`items` 为当前页，`totalCount` 为匹配总数。`status` 表示发布渠道，`state` 表示版本的处理和分发状态。

| `state` | 含义 |
| --- | --- |
| `draft` | 草稿，可发布测试版或提交正式版审核。 |
| `pending` | 正式版待审核。 |
| `rejected` | 需修改，详情中可查看审核意见。 |
| `published` | 已生效，可通过设备查询接口获取。 |
| `disabled` | 已停用，暂停公开分发。 |
| `revoked` | 已撤销，当前记录退出分发。 |

下面是列表响应节选。

```json
{
  "items": [
    {
      "id": "000000000000000000000103",
      "firmwareId": "000000000000000000000101",
      "version": "1.2.0-beta.1",
      "status": "TESTING",
      "state": "published"
    }
  ],
  "totalCount": 1
}
```

## 查询版本和审核结果

使用软件项目的 `firmwareId`，以及从版本列表或上传确认响应取得的版本 `id`。详情的 `releaseNotes` 包含 `zh-Hans-CN`、`en-US` 和 `ja-JP`。正式版进入 `rejected` 时，读取 `reviewReason` 和本轮 `reviewId`，再[修改后重新提交](/docs/service/open/organization_software/review)。

<ApiPlayground

/>

## 检查可用版本号

<ApiPlayground
  endpoint="/api/authV2/organization/software/versions"
  method="GET"
  auth="organization"
  queryParams={{
    firmwareId: { type: "string", name: "设备软件 ID", required: true, example: "000000000000000000000101" },
  }}
/>

### 查询参数

<TypeTable
  type={{
    firmwareId: {
      type: 'string',
      description: '设备软件 ID。使用创建软件或项目列表返回的 firmwareId，格式为 24 位十六进制字符。',
      required: true,
    },
  }}
/>

上传前可用 `GET /versions` 检查可用版本号。响应是数组，每项按设备提供 `channels.ALPHA`、`channels.TESTING` 和 `channels.RELEASED`。各渠道的 `latest` 是已记录的最高版本，无记录时为 `null`。请使用比 `latest` 高的版本，或使用 `reusable` 列出的可重用版本。若上传返回 `409`，重新查询后再选版本。

确认可用版本号后，可以[上传新版本](/docs/service/open/organization_software/upload)。如果只需要获取正在分发的版本，使用[服务端查询已发布版本](/docs/service/open/organization_software/organization_version_query)。
