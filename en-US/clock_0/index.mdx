## What is Clock/0?

<CustomCloudImage

Clock/0 is a lightweight e-paper clock. Its 2.66-inch black-and-white display has no backlight, and the content changes automatically at sunrise and sunset.

An included CR2032 battery powers the clock. The SET and BACK buttons on the rear let you set the date and time and refresh the screen. The magnetic rear cover lets you attach it to surfaces that attract magnets.

## Clock/0 technical specifications

| Item | Specification |
| :--- | :--- |
| Model number | CL0-G01 |
| Display | 2.66-inch black-and-white e-paper, no backlight |
| MCU | CW32L010, ARM® Cortex®-M0+ core, up to 48 MHz |
| Internal memory | Up to 64 KB Flash and 4 KB SRAM |
| Low-speed external clock | 32.768 kHz LSE configured at the factory |

| Rated voltage | 3 V |

| Net weight | 26 g |
