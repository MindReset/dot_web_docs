## 共通の問題

| 問題 | 対処方法 |
| --- | --- |
| SD カードが検出されない | 別途購入した microSD カードを挿入してください。最大 512 GB に対応し、FAT32 形式が必要です。 |
| シリアルポートが見つからない | データ転送に対応した別の USB ケーブルやポートを試し、ポートを使用している他のページ、書き込みツール、ターミナルを閉じてください。 |
| 端末に接続できない | パソコンの Chrome または Edge を使ってください。スマートフォンのブラウザや WeChat 内のブラウザでは、この Web 書き込み手順を利用できません。書き込み開始前であれば端末を再接続してください。ダウンロードモードが必要な場合は、そのシステムの説明に従います。 |
| インストール後に動作が遅い、画面が固まる、または古い画面が残る | 書き込みが完了したことを確認してから、電源キーを短く押します。反応がない場合は電源キーを長押しし、画面が切り替わったら離してください。 |
| インストールが中断した、または検証に失敗した | 接続を保ち、書き込みページの案内に従ってやり直してください。書き込みが完了する前にケーブルを抜いたり、強制的に再起動したりしないでください。操作ログを保存できる場合は、保存してシステムの開発者への報告に添えてください。 |

## システムごとの問題

### kiikoread に接続できない

すでに kiikoread が動作している端末では、「设置 → Pico 设备卡片 → 升级 → 进入 BOOT 模式」（設定 → Pico デバイスカード → アップグレード → BOOT モードへ）からダウンロードモードに入れます。パソコンがシリアルポートを再認識してからやり直してください。初回インストール時は、[kiikoread のインストール手順](/docs/read_0/start/pico_reader)に沿って端末を直接接続してください。

### kiikoread の本棚に書籍がない

システムには書籍が含まれていません。EPUB または TXT ファイルを microSD カードの `books` フォルダーに入れ、端末の本棚から開いてください。

### 確認後に RickyOS をインストールできない

インストールページの案内に従ってください。「查看本次操作记录」（今回の操作ログを表示）からログを保存し、[RickyOS 公式サイト](https://chinoryunqin.github.io/RickyOS-site/)で報告先を探して、チームにログを送ってください。
