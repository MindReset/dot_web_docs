## Wi-Fi

Rand/0 can connect to Wi-Fi and remember networks for later use. Online features prefer a saved network whenever possible.

## Connect to Wi-Fi

From **SETUP**, choose **Wi-Fi** → **Connect**. Rand/0 first tries the remembered Wi-Fi networks. If no remembered network is available or the connection fails, it starts a temporary setup network and shows a QR code.

When the QR code appears:

1. Scan it with your phone's **built-in system camera or QR scanner**;
2. Follow the system Wi-Fi page to connect to the temporary network;
3. Complete the setup page to provide the Wi-Fi network Rand/0 should remember.

After a successful connection, Rand/0 returns to normal mode. The next Wi-Fi operation can use the remembered network automatically.

Do not use a third-party QR scanner as the first choice. Some third-party scanner apps may not open the system Wi-Fi connection page correctly.

## Wi-Fi Memory

After connecting to Wi-Fi, the device automatically adds the connected network to Wi-Fi Memory. Rand/0 can remember more than one network and tries remembered networks before opening QR setup again.

To manage remembered networks, open **SETUP** → **Wi-Fi** → **History**, select a network, and long press the bottom button to delete it.

<Callout type="warn" title="Low battery">
Wi-Fi features may be blocked when the battery is too low. Connect Rand/0 to power before trying to connect to Wi-Fi or add a network.
</Callout>
