Install CrossMux to use Read Pico as a reading screen. Installation, also called flashing, writes new firmware to the device. No coding is required.

## Before you start

Prepare a computer, desktop Chrome or Edge, and a USB-C cable that supports data transfer.

Flashing replaces the current firmware and may clear its settings. Back up anything you want to keep and make sure the device has enough charge.

<CustomCloudImage osSrc="dot/docs/crossmux_1_1790759301830.png" alt="CrossMux website" />

<Steps>
<Step>

### Open the flashing page

Open the [CrossMux web flasher](https://crossmux.com/#flash-tools) in Chrome or Edge on your computer. Find the device selection area.

</Step>
<Step>

### Select your device

Choose **Read Pico**, then select a firmware version as directed by the page.

If Read Pico is not listed yet, stop and wait until its option is available. Do not select firmware for another model.

<CustomCloudImage osSrc="dot/docs/crossmux_2_1790759301829.png" alt="Select Read Pico" />

</Step>
<Step>

### Connect the device

Connect Read Pico to your computer with the USB data cable. Start the connection on the flashing page, select Read Pico's USB serial port in the browser's device picker, and confirm.

If you are unsure which entry is Read Pico, cancel the picker, unplug the device, and reconnect it. Look for the newly added entry.

{/* Screenshot: browser serial port picker. */}

</Step>
<Step>

### Start installation

Check that the selected model is correct, then follow the page's instructions to start flashing. If asked to erase data, make sure you have backed up anything you need first.

Wait for the completion message. Keep the cable connected and the page open, and prevent your computer from going to sleep.

{/* Screenshot: flashing progress and completion message. */}

</Step>
<Step>

### Start using your device

Once flashing is complete, restart the device as directed by the page. Follow the instructions on the new firmware's screen to finish setup.

If it does not restart automatically, confirm that flashing has finished before restarting it manually.

{/* Screenshot: first startup screen on the device. */}

</Step>
</Steps>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Device missing | try another data cable or USB port, and close other flashing tools using the device. |
| Browser cannot connect | use desktop Chrome or Edge. These steps do not work in mobile or in-app browsers. |
| Flashing failed | check the connection and follow the flashing page's instructions to reconnect and retry. If download mode is required, follow the instructions for your device model. |
| Old image remains | an e-ink screen keeps its image without power. Restart the device to check whether the new firmware starts. |

To restore the official demo, see [DIY Your System](/docs/read_0/firmware).

<Callout type="info" title="Other installation options">

Besides the website's web flasher, you can clone or fork the [CrossMux repository](https://github.com/0x1abin/crossmux) and follow its instructions to build and flash from source. You can also download firmware from [Releases](https://github.com/0x1abin/crossmux/releases) and follow that release's installation notes. Choose firmware and installation instructions that explicitly support Read Pico.

</Callout>
