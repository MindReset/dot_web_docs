Quote/0 API は、AWS Lambda と DynamoDB を使ったサーバーレスマイクロサービスです。Bearer Token で保護された HTTP API から予定を登録し、Reading Council のゴミ収集予定と組み合わせて、公式 Quote/0 Text API からデバイスを更新します。

### 主な機能

- **プッシュ専用構成**：Lambda が公式 Text API で Quote/0 を更新し、デバイスからこのサービスへのアクセスは不要
- **予定管理**：1 件の予定、または最大 100 件の予定を一括登録
- **ゴミ収集連携**：Reading Council の収集情報を取得して DynamoDB に保存
- **定期更新**：初期設定では EventBridge が毎日 01:10（UTC）に同期とデバイス更新を実行
- **API 認証**：すべての HTTP エンドポイントで `Authorization: Bearer <API_AUTH_TOKEN>` が必要
- **サーバーレス配置**：API Gateway、Lambda、DynamoDB、EventBridge を使用

### API

| メソッド | パス                | 用途                                      |
| -------- | ------------------- | ----------------------------------------- |
| `POST`   | `/api/events`       | 予定を 1 件登録し、Quote/0 をすぐに更新   |
| `POST`   | `/api/events/batch` | 最大 100 件の予定を登録して Quote/0 を更新 |

開発環境では、定期処理を手動実行する `POST /test/scheduled-update` も利用できます。

### 事前準備

- Lambda、API Gateway、DynamoDB、EventBridge を配置できる AWS アカウント
- Node.js 18 以降と Serverless Framework
- Quote/0 Text API のエンドポイントと Token
- プロジェクトの HTTP API を保護する別の Bearer Token
- Reading Council 対象住所の UPRN

主な環境変数は `QUOTE0_TEXT_API`、`QUOTE0_AUTH_TOKEN`、`API_AUTH_TOKEN`、`UPRN`、`READING_API_URL` です。

<Callout type="warn" title="対象地域と秘密情報">
  ゴミ収集機能は Reading Council の対象地域専用で、住所の UPRN が必要です。UPRN、AWS
  認証情報、Quote/0 Token、API Bearer Token
  は秘密情報として管理し、リポジトリへコミットしないでください。
</Callout>
