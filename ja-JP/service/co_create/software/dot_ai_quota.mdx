Dot AI Quota は、Claude と Codex のサブスクリプション使用枠を確認するセルフホスト型ダッシュボードです。公式クライアントの既存ログインを利用して、使用率とリセット時刻をローカルブラウザーに表示し、明示的に設定した Quote/0 の Canvas コンテンツ枠を更新します。Vibe Usage、別のホスト型アカウント、npm の実行時依存パッケージは必要ありません。

[英語と中国語のセットアップ手順](https://github.com/YuHoYe/dot-ai-quota)に沿って設定すると、ローカルで使用枠を確認できます。

![Dot AI Quota の中国語ダッシュボードと Quote/0 の画面プレビュー](https://img.yeyuhao.uk/dot-ai-quota/v0.2/quote0-zh-CN.png)

画像はデモデータを使用しています。Quote/0 の部分は、ブラウザー上の画面プレビューです。

### 主な機能

- **サブスクリプション使用枠**：プロバイダーが返す 5 時間枠・週間枠、Claude のモデル別枠、Codex のプランとリセットクレジット
- **英語・中国語のローカル画面**：残りの割合、リセット時刻、データ取得時刻、電子ペーパープレビュー
- **鮮度の明示**：アカウント別のローカルキャッシュと古いデータの表示。欠落した値を無制限と推測しません
- **Canvas 出力**：設定済みの複数の端末・コンテンツ枠へ、簡潔な白黒カードを送信
- **設定と定期実行**：中国語ウィザードとキーの非表示入力。macOS launchd、Linux systemd ユーザータイマー、Windows タスクスケジューラに対応し、通常の送信では端末のローテーションを維持
- **アカウント不要のデモ**：`npm run demo` で、認証情報の読み取り、プロバイダーへの問い合わせ、Dot への送信を行わずに画面を体験

### 必要なもの

- Node.js 24.6 以降
- Claude Code または Codex の対応サブスクリプションへのログイン。Codex はファイル形式の `auth.json` を使用
- 端末へ送信する場合は、Dot API Key と Quote/0 のシリアル番号
- Dot App のコンテンツスタジオで端末ループに追加済みの Canvas API コンテンツと、正確な `taskKey`

`npm install -g https://github.com/YuHoYe/dot-ai-quota/archive/refs/heads/main.tar.gz` でインストールし、`dot-ai-quota setup` を実行します。中国語のウィザードがログイン確認、キーの非表示入力、端末・Canvas 枠の選択、設定保存、初回送信の検証、定期実行の設定を案内します。設定ファイルの手動編集や Web 画面の起動は不要です。Web 画面は `dot-ai-quota serve` で任意に起動できます。中国語が既定の README には、AI に設定を依頼するためのプロンプトもあります。
