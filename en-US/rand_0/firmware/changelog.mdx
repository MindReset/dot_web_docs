<Timelines>

<Timeline>

### 1.3.3

- Improved text display and fixed cases where some characters were missing or incomplete
- Timer durations can now be adjusted in 1-minute increments for more flexible setup
- Made other small refinements for a smoother overall experience

</Timeline>

<Timeline>

### 1.3.1

- Refreshed the visual experience with a cleaner, more consistent, and more modern interface
- Made the home screen and folders easier to arrange, with more flexible language support
- Added Timer for count-up and countdown; see the [Timer guide](/docs/rand_0/start/features/timer)
- Added Pomodoro for repeating focus and rest; see the [Pomodoro guide](/docs/rand_0/start/features/pomodoro)
- Added Display Mode for sending your own images to Rand/0 over a local network; see the [Display Mode guide](/docs/rand_0/start/features/display_mode)

</Timeline>

<Timeline>

### 1.3.0

- Added Traditional Chinese language support
- Improved overall performance for smoother operation

</Timeline>

<Timeline>

### 1.2.8

- Optimized Wi-Fi and Bluetooth power usage to reduce battery drain during connected and standby use

</Timeline>

<Timeline>

### 1.2.7

- Improved OTA update stability, making firmware downloads and upgrades more reliable

</Timeline>

<Timeline>

### 1.2.6

- Added a lock screen wallpaper flip option in Settings, so you can adjust the wallpaper orientation
- Fixed a rare issue where the clock update could skip ahead, making timekeeping more stable
- Fixed connection issues in multi-Wi-Fi environments and cases where Wi-Fi setup could fail automatically
- Improved battery percentage estimation so the displayed level better matches real use
- Refined Fortune responses with more natural wording and more useful everyday results

</Timeline>

<Timeline>

### 1.2.5

- Wi-Fi can now connect directly to remembered networks for a smoother setup flow
- Fixed mismatches between Bluetooth remote labels and their actual functions, and fixed custom button saving issues
- Added a reading mode for Bluetooth remote control, with better support for apps such as WeChat Reading and Douyin desktop
- Fixed an issue where the Wooden Fish feature could leave unexpected screen ghosting in some cases
- Fixed repeated error loops that could occur when a custom wallpaper image was too large

</Timeline>

<Timeline>

### 1.2.3

- Improved device-wide power management for significantly better battery life
- Fixed an issue where personality guidance entries could display incorrectly

</Timeline>

<Timeline>

### 1.2.1

- Fixed text errors on the onboarding screens
- Added quick lock screen: long press the top button from the main menu to lock the screen
- Fixed an issue where Fortune content could switch multiple times in one day
- Added a reset personality option in Settings so you can choose your personality type again
- Added an option in Settings to reset the Wooden Fish counter
- Improved the screen refresh strategy: after every 9 partial refreshes, the device performs a full refresh to reduce ghosting
- Improved lock screen wallpaper display to reduce ghosting
- Added battery percentage display on the System Version page

</Timeline>

<Timeline>

### 1.2.0

- Improved Bluetooth encrypted verification for Apple devices for better connection compatibility

</Timeline>
