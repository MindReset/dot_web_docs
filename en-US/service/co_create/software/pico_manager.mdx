Pico Manager is a native management tool for small e-paper readers, available for Android and iOS. Connect to a device, transfer books wirelessly, organize files and folders, and manage fonts, wallpapers, network settings, and reading settings. The interface and available features adapt to the capabilities of your device and firmware.

### Features

- **Wireless book transfers:** Import books and fonts through system sharing, with automatic checks for supported file formats and selection of the destination folder.
- **Files and folders:** Browse device files, upload, download, move, rename, and bulk delete files, and create folders.
- **Device settings:** Available options adapt to the firmware's capabilities, including Wi-Fi network management, font management, wallpaper uploads and management, OPDS catalog configuration, and device parameter adjustments.

### Before you start

See the [Pico Manager website](https://pico.cold04.com/) for supported firmware. Before connecting, make sure the reader is running compatible firmware with book transfer mode enabled, and that your phone can reach its network address. Supported file formats and available management features depend on the connected firmware.
