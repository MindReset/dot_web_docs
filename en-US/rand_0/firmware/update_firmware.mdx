## Update Device

Before starting, make sure Rand/0 has a remembered Wi-Fi network and enough battery. Connect it to power if the battery is low.

1. Open **SETUP** on Rand/0.
2. Select **System Version**.
3. Long press the bottom button to enter Wi-Fi OTA.
4. Wait for the update to finish, then press the bottom button when the device asks you to restart.

The update uses a remembered Wi-Fi network. Keep the network available and do not power off Rand/0 during the update.

## Add or Change the Wi-Fi Network

If there is no remembered network, or you want to use another one:

1. Open **SETUP** → **Wi-Fi** → **Connect**.
2. Complete Wi-Fi setup and connect to a network. See [Wi-Fi](/docs/rand_0/start/wifi).
3. Return to **System Version** and long press the bottom button to start the update.
