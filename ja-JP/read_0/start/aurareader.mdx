Read Pico 向けにシステムを提供してくださった Malus / 百变逗比i に感謝します。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使えるパソコン、データ転送に対応した USB-C ケーブルを用意してください。端末のシリアルポートを使用しているほかのページ、書き込みツール、ターミナルを閉じます。

最大 512 GB、FAT32 形式の microSD カードを用意してください。

<Steps>
<Step>

### 公式サイトを開いて接続する

[AuraReader 公式サイト](https://aurareader.cn/)の[書き込みエリア](https://aurareader.cn/#flasher)を開きます。「选择 AuraReader 设备」（AuraReader 端末を選択）を押し、ブラウザの一覧で Read Pico のシリアルポートを選んでください。

**AuraReader** 読書システムを選択します。現在のバージョンはページで確認してください。「小纸 Pico 官方演示 Demo」（Read Pico 公式デモ）は別の選択肢です。

</Step>
<Step>

### データの処理を確認して書き込む

「数据处理」（データの処理）で既定の「完整覆盖」（全体を上書き）、または必要に応じて「先擦除再写入」（消去してから書き込み）を選びます。どちらも完全イメージを書き込み、端末内部のデータを上書きします。通常の書き込みでは microSD カードを操作しません。

「确认执行」（実行の確認）に進み、システム、端末、データの処理方法を確認します。確認項目にチェックして書き込みを開始すると、接続、環境確認、書き込み、データ検証、完了の順に進捗が表示されます。

USB 接続とページを開いた状態を保ち、ケーブルを抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。完了後、ページの案内に従って端末を再起動します。

</Step>
<Step>

### 書籍を追加して読む

カードの書庫ディレクトリに TXT または EPUB をコピーし、端末で再スキャンして本を開きます。

設定から Wi-Fi 転送を開くこともできます。スマートフォンやパソコンを端末と同じネットワークに接続し、画面に表示されたアドレスをブラウザで開いて書籍をアップロードします。転送モードを終了すると書庫が更新されます。詳しくは[公式サイトの使い方](https://aurareader.cn/#guide)をご覧ください。

</Step>
</Steps>
