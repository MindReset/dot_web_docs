## 人格指南

人格指南基于你的 MBTI 人格色彩提供每日指引。

-   根据已选择的 MBTI 人格显示每日指引。
-   可查看匹配人格的对方指引。

## 操作

1. 长按下键进入。
2. 轻按下键继续并选择人格。
3. 轻按上键切换匹配 MBTI 的今日指南。
4. 轻按下键切换下一条。
5. 长按上键返回主界面。

## 切换人格

进入 **设定** → **重置人格指南** 可以清除已保存的人格。重置后重新进入 **人格指南** 即可选择新的人格类型。请参阅[设定](/docs/rand_0/start/settings)。
