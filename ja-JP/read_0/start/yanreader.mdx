Read Pico 向けにシステムを提供してくださった [autumnc](https://github.com/autumnc) に感謝します。

YanReader は読書、執筆、計画を 1 台にまとめたシステムです。CrossMux の組版エンジンと Read Pico 公式デモの画面・フォント部品を使い、ローカル書庫、ピンイン入力、Bluetooth キーボードやページ送り機器に対応します。

## はじめる前に

十分に充電した Read Pico、デスクトップ版 Chrome または Edge を使うパソコン、データ通信対応の USB-C ケーブルを用意してください。端末のシリアルポートを使用している他のページ、書き込みツール、ターミナルは閉じてください。

書籍、フォント、メモ、計画データを保存する microSD カードを用意してください。Read Pico は最大 512 GB に対応し、FAT32 形式が必要です。

プロジェクトの案内では、通常の Web インストールは、端末設定や Wi-Fi 認証情報を保存する NVS 領域を消去せず、カード内のデータも削除しません。ただし、Flash 全体を手動で消去すると NVS も消去されます。システムを切り替える前に、大切な書籍、メモ、読書記録、設定を保存してください。別のシステムの設定を YanReader で引き継げるとは限りません。

## 公式サイトからインストールする

<Steps>
<Step>

### 公式サイトを開き、システムを確認する

パソコンの Chrome または Edge で [YanReader 公式サイト](https://autumnc.github.io/YanReader-pico/)を開き、読み込まれたバージョンとチェックサムを確認します。

標準では現在のリリースの完全イメージをインストールします。旧版や自分でビルドした版を使う場合はローカルファイルの項目を開きます。公開されている 2 種類のファイルは用途が異なります。

| 公開ファイル | 用途 |
| --- | --- |
| `yanreader-<バージョン>-full.bin` | ブートローダー、パーティションテーブル、アプリを含みます。初回インストール、別のシステムからの切り替え、Web での再インストールには、この完全イメージを選びます。 |
| `pjournal_pico.bin` | アプリだけを含み、ブートローダーとパーティションテーブルは更新しません。互換性のある YanReader のパーティション構成を導入済みの端末で、対象バージョンの手順に従って手動更新する場合だけ使います。Web インストール用の完全イメージではありません。 |

`pjournal_pico.bin` を完全イメージとして `0x0` に書き込まないでください。端末が正常に起動できなくなります。ローカルファイルを選ぶ場合は、入手元、バージョン、ページに表示されるチェックサムを確認してください。

</Step>
<Step>

### 端末を接続して書き込む

USB データケーブルで Read Pico を接続し、「连接设备」（端末を接続）を押して、ブラウザーの一覧から `USB JTAG/serial debug unit` を選びます。ESP32-S3 と認識されたことを確認して「开始刷写」（書き込み開始）を押します。

書き込み、読み戻しによる検証、端末の再起動が順番に行われます。検証中に進捗が 100% のままになることがありますが、完了の表示まで待ってください。途中で USB を抜いたり、ページを閉じたり、パソコンをスリープさせたりしないでください。

</Step>
<Step>

### カードを用意して使い始める

カード内の `books/` に書籍、`fonts/` に追加の TTF フォントを入れます。カードを挿入して起動し、本棚から本を開いてください。

ネットワーク機能を使う場合は「设置 → WiFi 管理」（設定 → WiFi 管理）で接続します。時刻を同期すると、読書統計や待機時計に正しい時刻が反映されます。公式サイトの「使用帮助」（ヘルプ）では、操作、フォルダー、インストール方法を確認できます。

</Step>
</Steps>

### インストール後の確認

- カードを読み取れることを確認し、本棚から本を開いてください。閉じてから開き直し、読書位置が保持されるか確認します。
- 既存のメモを開くか、新しいメモを作成して保存・再表示し、必要なデータを使えるか確認します。
- 電源キーを短く押して待機状態に入り、もう一度短く押して復帰します。元のページに戻り、文字表示とページ送りが正常に動くか確認してください。

## 主な機能

### 読書とメモ

EPUB、TXT、XTC を読み、フォント、文字サイズ、行間、段落間隔、字下げ、余白を調整できます。EPUB の埋め込みフォント、脚注ポップアップ、目次、しおり、進捗率での移動にも対応します。本文を長押しして、ハイライト、メモ、ローカルの StarDict 辞書検索を行えます。

書名やメモを検索できます。メモ画面の「导出」（エクスポート）で、全書籍のハイライト、メモ、しおりを 1 つの Markdown にまとめ、カードの `exports/` に保存できます。読書統計では時間、日ごとのページ数、ヒートマップ、連続読書日数を確認できます。

### 執筆と計画

「研墨」（執筆）では日記、自由執筆、アウトライン、アイデアを記録できます。Markdown 表示、変更履歴、縦書き、Flomo と WebDAV の同期に対応します。DeepSeek による文章の推敲には、自分の API Key とネット接続が必要です。

「研行」（計画）は GTD によるタスク管理です。タスク、プロジェクト、カレンダー、付箋、絞り込みを使い、Markdown に書き出せます。

### 入力と操作

メイン画面で中央のタッチキーを長押しすると、「研读」（読書）、「研墨」（執筆）、「研行」（計画）を切り替えられます。仮想キーボードとピンイン入力は全モード共通で、複数のキー配列を選べます。BLE キーボードや対応する Bluetooth ページ送り機器も接続できます。

読書中は左右のキーや横スワイプでページを送り、中央をタップすると読書メニューが開きます。端末を振ると全画面をリフレッシュします。待機状態からの復帰には電源キーを使います。

## 更新と現在の対応範囲

端末上の OTA 更新には現在対応していません。更新時は USB で接続して公式サイトから書き込むか、同じページで別バージョンの完全なパッケージを選んでください。

アプリイメージで手動更新する前に、[対象バージョンのリリースノート](https://github.com/autumnc/YanReader-pico/releases)で、現在のパーティション構成との互換性を確認してください。確認できない場合は、そのバージョンの完全イメージを使います。異なるバージョンのブートローダー、パーティションテーブル、アプリを混在させないでください。

端末の画面は現在中国語です。本棚とメモの検索には対応しますが、本の全文検索には対応していません。

## その他のインストール方法

リポジトリの Releases から完全なパッケージを入手し、各バージョンの説明に従って USB 書き込みを行えます。リポジトリをクローンまたは Fork して、自分でビルドすることもできます。

ビルドには ESP-IDF v6.1 と `read_pico_firmware` の依存部品が必要です。入力方式の辞書などのリソース生成とビルド設定は、リポジトリの説明に従って準備してください。
