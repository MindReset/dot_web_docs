# Security

Report suspected vulnerabilities or exposed credentials privately to [security@mindreset.tech](mailto:security@mindreset.tech), following the [official Dot responsible disclosure policy](https://dot.mindreset.tech/docs/security_policy).

Include the affected page or component, a description of the issue, and reproduction details where safe. Do not post live credentials, device identifiers, personal information, or vulnerability details in a public issue or pull request.

Ordinary documentation mistakes and broken links belong in the [documentation issue tracker](https://github.com/MindReset/dot_web_docs/issues/new/choose). See [Support](SUPPORT.md) for product or account help.
