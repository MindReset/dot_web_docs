Pocket Prophet Dashboard 是一个面向口袋先知 200 × 200 墨水屏的本地 Web 服务。它使用设备官方壁纸接口与云端图片转换能力，将摇卦、奇门遁甲、天气、股票行情、今日要闻和 Claude Code Token 用量生成图片并推送到设备，无需刷写或修改固件。

### 功能特性

- **摇卦**：使用三枚铜钱法生成本卦、变卦与简短判断
- **奇门遁甲**：按当前时间起盘，以 3 × 3 九宫格展示门、星与干支
- **天气**：通过 wttr.in 展示天气图标、温度、体感温度与降水概率
- **股票行情**：通过 Yahoo Finance 展示多只股票概览或单只股票详情
- **今日要闻**：合并 RSS、Atom 与今日头条热榜，并支持自定义信息源
- **Token 用量**：读取本机 Claude Code 转录文件，展示相对自设预算的当日消耗、近 5 小时用量与近似成本
- **自动轮换**：设备停留在更换壁纸界面时，可按周期轮换推送选定页面

### 使用前准备

- 口袋先知设备与同一 Wi-Fi 下的电脑或手机
- Python 3 与项目依赖
- 设备在更换壁纸界面显示的局域网 IP；也可配置 MAC 地址辅助重新发现
- 从 `config.example.json` 创建的本地配置

运行 `python3 app.py` 后，通过局域网访问端口 `5151`。摇卦和奇门遁甲可以直接推送；天气、行情、新闻与用量页面支持先生成预览，再决定是否更新设备。

<Callout type="warn" title="设备在线方式">
  口袋先知平时不会连接局域网，只有手动打开更换壁纸界面时才会上线。自动轮换要求设备持续停留在该界面，期间其他壁纸推送可能被覆盖；长期联网对续航的影响尚未确认。
</Callout>
