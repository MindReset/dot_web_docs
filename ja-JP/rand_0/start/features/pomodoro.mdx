## ポモドーロ

集中と休憩を自動で切り替え、スマートフォンを確認せずにシンプルな作業リズムを保てます。

## リズムを設定する

1. **Pomodoro** を開き、下ボタンを長押しします。
2. 初回は集中時間を **15〜60 分**の範囲で **5 分刻み**に設定します。
3. 休憩時間を **5〜60 分**の範囲で **5 分刻み**に設定します。
4. 下ボタンを長押しして最初の集中時間を開始します。

初期設定は **集中 25 分、休憩 5 分**です。設定を保存した後は、**Repeat last** で同じ時間の次のラウンドを始めるか、**Set new time** で設定し直せます。

## ポモドーロの動作中

- 集中と休憩は、ポモドーロを終了するまで自動的に切り替わります。
- 上ボタンまたは下ボタンを短押しすると静止した残り時間を確認できます。もう一度短押しすると状態表示へ戻ります。
- 下ボタンを長押しすると一時停止します。一時停止中にもう一度長押しすると **Resume** または **Exit** を選べます。
- 上ボタンを長押しするとポモドーロを終了して More フォルダーへ戻ります。

集中または休憩の各フェーズが終わると短いアラートが鳴ります。集中フェーズの開始時に次のラウンドへ進みます。ポモドーロの動作中または一時停止中は、通常のスリープタイムアウトで停止しません。
