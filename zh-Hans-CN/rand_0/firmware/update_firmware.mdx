## 更新设备

开始前，请确认 Rand/0 已记住可用的 Wi-Fi 且电量充足。电量较低时，请先接入电源。

1. 在 Rand/0 上进入 **设定**。
2. 选择 **系统版本**。
3. 长按下键进入 Wi-Fi OTA。
4. 等待更新完成，设备提示重启时按下下键确认。

更新会使用已记忆的 Wi-Fi。更新期间请保持网络可用，不要关闭 Rand/0 的电源。

## 添加或更换 Wi-Fi

如果设备没有已记忆的网络，或你想改用其他网络：

1. 进入 **设定** → **Wi-Fi** → **连接网络**。
2. 完成 Wi-Fi 配置并连接网络，请参阅 [Wi-Fi](/docs/rand_0/start/wifi)。
3. 返回 **系统版本**，长按下键开始更新。
