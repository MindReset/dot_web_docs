### List response

`items` contains the current page in reverse creation order. `totalCount` counts all matches. `status` is the release channel. `state` describes review and distribution.

| `state` | Meaning |
| --- | --- |
| `draft` | Ready to publish to a test channel or submit for stable-release review. |
| `pending` | The stable release is in review. |
| `rejected` | Changes were requested. Review feedback is available in the details. |
| `published` | Live and available to device queries. |
| `disabled` | Public distribution is paused. |
| `revoked` | This version record has been withdrawn from distribution. |

For a published version, read its URLs from `downloads` in the list or version details. Use the same file type key in `artifacts` for its `name`, `size` in bytes, and `sha256` checksum. The example version has all three file types.

## Check a version and its review status

Use the project’s `firmwareId` and the version `id` from the list or upload completion response. The detail response includes `releaseNotes` with `zh-Hans-CN`, `en-US`, and `ja-JP`. When a stable release has state `rejected`, read `reviewReason` and the current `reviewId` before [resubmitting it](/docs/service/open/organization_software/review).

## Check available version numbers

### Query parameters

<TypeTable
  type={{
    firmwareId: {

      description: 'The 24-character hexadecimal firmwareId returned when you create or list software projects.',
      required: true,

  }}

Before uploading, use `GET /versions` to check available version numbers. Each item in the response array has `channels.ALPHA`, `channels.TESTING`, and `channels.RELEASED` for its device. A channel’s `latest` is the highest recorded version, or `null` if there are no versions. Choose a higher version or one listed in `reusable`. If the upload returns `409`, query the ranges again before choosing a version.

Once you have an available version number, [upload a new version](/docs/service/open/organization_software/upload). To see which version is currently distributed, [query published versions from your server](/docs/service/open/organization_software/organization_version_query).
