## 通用问题

| 问题 | 处理方式 |
| --- | --- |
| 未检测到 SD 卡 | 请插入自行购买的 microSD 存储卡，最大支持 512 GB，需使用 FAT32 格式。 |
| 找不到串口 | 换一根支持数据传输的 USB 数据线，尝试另一个 USB 接口，并关闭占用串口的其他网页、刷写工具或终端。 |
| 无法连接设备 | 使用电脑上的 Chrome 或 Edge；手机浏览器和微信内置浏览器不适用于网页刷写。尚未开始写入时，可重新连接设备；若页面要求进入下载模式，请按该系统的说明操作。 |
| 安装完成后页面卡顿、卡住或仍显示旧画面 | 确认刷写已经完成后，先短按电源键；若仍无响应，再长按电源键，等待屏幕切换显示后松手。 |
| 安装中断或校验失败 | 保持连接，按刷写页面提示重新尝试。写入未完成时，不要拔线或强制重启；页面提供操作记录时，可保存后向该系统开发者反馈。 |

## 按系统进一步排查

### kiikoread 无法连接

已运行 kiikoread 的设备，可通过「设置 → Pico 设备卡片 → 升级 → 进入 BOOT 模式」进入下载模式，等待电脑重新识别串口后重试。首次安装时，按 [kiikoread 安装步骤](/docs/read_0/start/pico_reader)直接连接设备。

### kiikoread 书架中没有图书

系统不附带书籍，请将 EPUB 或 TXT 文件放入 microSD 存储卡的 `books` 文件夹，再从设备书架打开。

### RickyOS 检查后无法安装

按安装页面的提示处理。可在「查看本次操作记录」中保存记录，再前往 [RickyOS 官网](https://chinoryunqin.github.io/RickyOS-site/)查找反馈入口，将记录提供给 RickyOS 团队。
