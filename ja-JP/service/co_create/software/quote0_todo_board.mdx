パソコンでタスクを編集し、表示を確認してから未完了のタスクを Quote/0 に同期できます。1 画面に収まらない場合は複数のカードに分け、端末で順番に表示します。

### 主な機能

- Web 版はローカルの HTML ファイルから利用できます。期限、繰り返し、検索、絞り込み、優先表示に対応します。
- 手動同期や編集後の自動送信を使えます。天気と名言を表示する場合は、それぞれに Canvas API カードが必要です。
- Windows 版はソースコードからビルドできます。常に手前に表示される半透明のウィジェットで、タスクの完了操作と自動送信ができます。

### はじめるには

1. リポジトリから `Quote0-待办看板.html` をダウンロードし、ブラウザーで開きます。
2. 登録済みの Quote/0 とそのシリアル番号、[Dot. API キー](/docs/service/open/get_api)を用意します。Dot. アプリのコンテンツスタジオで、表示したいページごとに Canvas API カードを端末のローテーションへ追加します。
3. ツールの設定にキーとシリアル番号を入力し、Canvas API カードを検出して順番を確認します。設定を保存して、すべてのページを同期してください。

Web 版はタスクと設定を使用中のブラウザーに保存します。すべてのデータをエクスポートした JSON には API キーも含まれるため、安全な場所に保管してください。
