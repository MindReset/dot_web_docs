## 快速指引

### 必要条件

1. 确保您已在 Dot. App 中<Link href="/docs/service/studio/api/get_api">获取并保存了 API 密钥</Link>；
2. 确保您至少有一台所属于自己的设备并已<Link href="/docs/service/studio/api/get_device_id">获取设备序列号</Link>；
3. 确保您的设备已接入电源；
4. 确保您的设备已接入网络；
5. 确保已从 Dot. App 内容工坊中添加 `图像 API` 内容到设备的**循环列表或固定列表**中。

<Callout type="info" title="图像 API 的用途">
	图像 API 适合把海报、截图、仪表盘或一张喜欢的图片送到设备上。它会尽量保留图片本身的视觉关系，适合您已经准备好完整画面的场景。
</Callout>

<Callout type="info" title="选择内容列表与显示时机">
	可选择循环列表或固定列表，省略时使用循环列表。任务唯一标识只在所选列表中查找；省略时更新该列表中的第一个同类 API 内容，不会查找其他列表。

	立即显示设置仅对循环内容有效：开启时请求立即显示，关闭时仅保存。设备需要在线；电池供电且睡眠时，内容先保存，待设备自动唤醒后获取。固定内容始终按 App 中设置的时间显示，即使当前正在显示该固定内容，也要等下一次计划刷新。API 不改变固定内容的时间设置。详见<Link href="/docs/quote_0/faq/refresh_timing">时间机制</Link>。
</Callout>

<Callout type="info" title="关于图像输入">
	图像为必填内容，可使用 PNG Base64 数据或完整的在线 `http(s)` 图片 URL。PNG Base64 可传裸 Base64，也可带 `data:image/png;base64,` 前缀，解码后最大 3MB。远程图片链接必须可匿名访问、无需鉴权或特殊 Referer，URL 长度不超过 2048 个字符，响应体最大 3MB，并直接返回 `image/*` 内容。
</Callout>

<Callout type="info" title="可用于调试的测试图片链接">
	以下链接当前可直接匿名访问，并返回可用于 Image API 的图片内容：

	- `https://placehold.co/600x400/png`
	- `https://httpbin.org/image/png`

	如果您想先验证自己的图片链接是否可用，可以先执行：

	```bash
	curl -I 'https://your-image-url'
	```

	通常需要确认响应中至少满足两点：

	- HTTP 状态码为 `200`
	- `Content-Type` 为 `image/*`，例如 `image/png` 或 `image/jpeg`
</Callout>

### 更新固定列表中的内容

先查询固定列表，从返回数组中找到 `IMAGE_API` 内容，并将它的 `key` 作为 `taskKey`：

```bash
curl 'https://dot.mindreset.tech/api/authV2/open/device/{{deviceId}}/fixed/list' \
  -H 'Authorization: Bearer dot_app_{{apiKey}}'
```

再调用同一接口，在请求顶层传入 `taskType: "fixed"` 和该 `taskKey`。以下请求只保存内容，`refreshNow: true` 不会提前显示或刷新固定内容：

```bash
curl -X POST 'https://dot.mindreset.tech/api/authV2/open/device/{{deviceId}}/image' \
  -H 'Authorization: Bearer dot_app_{{apiKey}}' \
  -H 'Content-Type: application/json' \
  -d '{
  "taskType": "fixed",
  "taskKey": "{{taskKey}}",
  "refreshNow": true,
  "image": "https://placehold.co/600x400/png"
}'
```

## 图像抖动

图像抖动是指在图像中使用特定算法来减少颜色带来的视觉噪点，从而使图像看起来更加平滑。常见的抖动算法包括 Floyd-Steinberg、Atkinson 和 Sierra 等。在墨水屏中，图像抖动可以将黑白墨水屏的显示效果进一步优化，使得图像在不同的灰阶之间过渡更加自然。

在使用图像 API 时，**当不传递 `ditherType` 参数时，图像抖动将会默认使用误差扩散抖动中 Floyd-Steinberg 算法**，您也可以通过参数将其关闭或调整抖动类型与算法。

### 开启图像抖动

#### 误差扩散抖动（默认）

误差扩散抖动是通过将每个像素的误差分配给周围像素来减少颜色带来的视觉噪点，从而使图像看起来更加平滑。该算法可以有效地处理图像中的高对比度区域，使得图像在不同的灰阶之间过渡更加自然。通常呈现出点分布较为自然、无明显规则网格的效果，细节表现丰富，灰阶过渡平滑。

#### 有序抖动

有序抖动是一种通过将规则的抖动矩阵应用于图像像素来实现灰阶或颜色近似的算法。与误差扩散抖动不同，有序抖动并不根据像素误差动态调整周围像素的值，而是预先定义一个固定的抖动矩阵，将其周期性地叠加到整幅图像上。这种方法能够有效地减少大面积的色块和条带现象，使图像在视觉上呈现出较为均匀的点阵分布。由于抖动矩阵的周期性，有序抖动生成的图像通常会带有一定的规则性和网格感

### 响应说明

| HTTP 状态码 | 含义             | 描述                                                                                                                |
| ----------- | ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| `200`       | 成功             | 设备图片 API 内容已切换/数据已更新但未切换内容                                                                      |
| `400`       | 参数错误         | 内容列表类型无效<br/>设备序列号缺失或格式错误<br/>无效的图像格式<br/>边框颜色无效<br/>无效的抖动类型<br/>无效的抖动算法 |
| `403`       | 权限不足         | 您没有权限操作此设备                                                                                                |
| `404`       | 设备或内容不存在 | 设备不存在或未注册<br/>所选列表中未添加对应 API 内容，或任务唯一标识与该列表中的对应 API 内容不符                                                               |
| `500`       | 设备响应失败     | 设备图片 API 内容切换失败                                                                                           |

### 列表与显示时机排查

- `400`：确认 `taskType` 只使用 `loop` 或 `fixed`。
- `404`：确认请求的 `taskType` 与查询列表一致，且 `taskKey` 来自该列表中的对应 API 内容；省略 `taskType` 会查询循环列表。
- 固定内容已保存但画面未变化：检查 App 中的时间设置，并等待下一次计划刷新；`refreshNow: true` 不会触发固定内容立即刷新。
