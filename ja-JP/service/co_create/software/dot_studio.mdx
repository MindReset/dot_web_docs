Dot Studio は Quote/0 向けのローカルファーストなコンテンツコンソールです。1 つのブラウザ画面から、テキストカードの作成、電子ペーパー向け画像の調整、Canvas ダッシュボードの設計、デバイス状態の確認、次画面への切り替えを行えます。Dot API Key はブラウザに公開されず、ローカルサーバー側に保持されます。

### 主な機能

- **テキストカード**：タイトル、本文、署名、任意の NFC リンクを編集し、電子ペーパー表示をリアルタイムでプレビュー
- **画像処理**：PNG、JPG、WebP、HEIC をドラッグ＆ドロップし、296 × 152 のモノクロ画面へ自動変換。フィット方法、ディザリング、枠線も調整可能
- **Canvas ダッシュボード**：指標、フォーカス、システム状態のテンプレートを編集し、Canvas JSON を直接扱うことも可能
- **状態確認と操作**：オンライン状態、バッテリー、Wi-Fi、描画時間を確認し、次の画面へ切り替え
- **確実な更新**：古い画像が新しい内容を上書きすることを防ぎ、タスク保存とデバイス描画の両方を確認してから完了を通知
- **Codex 完了通知**：プロジェクト内の Skill を使い、Codex のタスク完了時に Quote/0 を点滅させて短い通知カードを表示

### 事前準備

- Node.js 22.13 以降
- Dot Open Platform の API Key
- Dot に接続済みの Quote/0
- Dot App コンテンツ工房のデバイス Loop に追加した Text API、Image API、および任意の Canvas API コンテンツ

リポジトリをクローンしたら、`.env.example` から `.env.local` を作成し、`DOT_API_KEY` と `DOT_DEVICE_ID` を設定します。依存パッケージと開発サーバーを起動し、`http://localhost:3210` を開いてください。デバイス Loop を変更した場合は、Dot Studio を再読み込みすると最新のコンテンツが検出されます。

<Callout type="warn" title="認証情報とコンテンツ設定">
  `.env.local` をコミットしたり、実際の API Key をクライアントコードへ記述したりしないでください。テキスト、画像、Canvas
  の操作には、デバイス Loop 内の対応する API コンテンツが必要です。
</Callout>

<Callout type="info" title="Codex 通知の適用範囲">
  リポジトリ内の完了通知 Skill と `AGENTS.md` はこのプロジェクト内だけで有効であり、Codex
  のグローバル設定は変更しません。`--no-flash` で点滅を無効にでき、`--dry-run` では Dot
  に接続せずローカル設定を確認できます。
</Callout>
