## 快速指引

设备设置 API 用于读取或更新一台归属于当前 API key 用户的设备设置。写入只支持 `POST`，未传入的字段会保持不变。

### 读取设置

<ApiPlayground
	baseUrl="https://dot.mindreset.tech"
	endpoint="/api/authV2/open/device/:deviceId/settings"
	method="GET"
	pathParams={{
		deviceId: {
			type: 'string',
			required: true,
			name: '设备序列号',
		},
	}}
	auth={true}
	defaultOpen={false}
/>

### 自动切换间隔

| 设备 | 插电范围 | 电池范围 |
| --- | --- | --- |
| Quote/0、Quote/1 | 1 分钟～12 小时 | 1 分钟～12 小时 |
| Rand/0 | 15 分钟～12 小时 | 1 小时～12 小时 |
| 秒秒测 M401 | 1 分钟～12 小时 | 30 分钟～12 小时 |

范围针对自动切换。主动刷新不受此间隔限制。超出范围的设置请求会被拒绝。

### 时区

设备设置 API 的 `timezone` 字段只接受「获取时区」接口返回的 key。请先查看「获取时区」页面了解当前服务支持的时区列表。
