在电脑上编辑待办、查看预览，再把未完成的任务同步到摘录 Quote/0。待办超过一屏时，工具会将它们分成多页，设备按循环列表依次显示。

### 功能特性

- 网页版使用本地 HTML 文件，支持截止日、重复任务、搜索、筛选和置顶。
- 可手动同步或在编辑后自动推送。可选的天气页和金句页各占一张画板卡。
- Windows 桌面版提供透明置顶小组件，支持勾选待办和自动推送。可按仓库说明从源码构建。

### 开始使用

1. 从仓库下载 `Quote0-待办看板.html`，用浏览器打开。
2. 准备已绑定的 Quote/0、设备序列号和 [Dot. API 密钥](/docs/service/open/get_api)。在 Dot. App 的内容工坊里，为每个要显示的页面向设备循环列表添加一张「画板 API」卡片。
3. 在工具的设置中填写密钥与设备序列号，点击「发现画板卡」并确认绑定顺序。保存后点击「同步全部页」。

网页版将待办和设置保存在当前浏览器中。完整 JSON 导出含 API 密钥，请妥善保存。
