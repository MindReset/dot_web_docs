## 時計

時計は、日付、時刻、曜日を表示します。

-   日付、時刻、曜日を表示。
-   時計でネットワーク接続が必要な場合は、短い案内の後に Wi-Fi 接続へ進みます。
-   初回使用時には、電力消費に関する注意が表示される場合があります。いずれかのボタンを押して続行します。

## 操作

1. 下ボタンを長押しして入ります。
2. 現在の日付、時刻、曜日を確認します。
3. 端末が Wi-Fi 接続を案内した場合は、案内に従って操作します。上ボタンを長押しするとキャンセルしてメニューへ戻ります。
4. 上ボタン長押しでホームに戻ります。

時計は表示を続け、時刻の変化に合わせて更新されます。通常のロック画面より待機時の電力を多く使いますが、通常のスリープタイムアウトではロックされません。
